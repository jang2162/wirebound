# 단축키 · 클립보드 · 여러 노드 선택 — 설계

에디터에서 키보드로 편집하고(되돌리기 · 삭제 · 복사 · 붙여넣기 · 복제 · 옮기기 · 고르기), 노드를 여럿 골라 한꺼번에 지우거나 같은 타입의 속성을 한꺼번에 바꾼다.

이 문서는 발행 시점의 기록(spec)이다. 구현이 병합되면 정본 설계서(`docs/superpowers/specs/2026-08-03-wirebound-design.md`)의 「설계서 화면 구조」 · 「소프트 잠금」 · 「개인 undo/redo」 절과 `apps/api/README.md` 의 WS 계약이 지금 참인 것을 갖는다.

---

## 목적과 범위

**목적:** 지금은 되돌리기가 머리의 단추로만 되고, 단축키는 구조 트리에 포커스가 있을 때만 몇 개(삭제 확인 · 순서 · 계층)가 먹으며, 복사 · 붙여넣기가 없다. 노드는 하나씩만 고를 수 있어 같은 것을 여러 번 고치려면 같은 조작을 노드마다 되풀이한다.

**범위 안:**

- 에디터 어디서나(구조 트리 · 캔버스 · 패널 바깥) 먹는 단축키 — 되돌리기 · 다시 하기 · 삭제 · 복사 · 잘라내기 · 붙여넣기 · 복제 · 선택 해제 · 순서 · 계층 · 선택 이동 · 단축키 도움말
- OS 클립보드로 주고받는 노드 복사 · 붙여넣기(같은 페이지 · 다른 페이지 · 다른 탭 · 다른 프로젝트)
- 구조 노드 여럿 고르기(Cmd/Shift+클릭 · Cmd+A · 캔버스 사각형)와 고른 서브트리마다 소프트 잠금
- 여럿 고른 판의 일괄 삭제 · 복사 · 잘라내기 · 복제 · 같은 타입 일괄 속성 편집

**범위 밖:**

- 여러 노드를 한꺼번에 끌어 옮기기(손잡이는 하나 골랐을 때만)
- 타입이 섞인 선택의 공통 속성 편집
- 메뉴 · 페이지 트리의 여러 개 선택
- 단축키 사용자 정의

## 단축키

### 표 하나

에디터 단축키는 **표 하나**(`editor-shortcuts`)에 둔다. 구조 트리의 지금 단축키 표(`panels/structure-tree.tsx` 의 `SHORTCUTS`)도 이 표로 옮긴다 — 두 벌이면 한쪽만 고쳐진다. 메뉴 트리의 단축키(`panels/menu-tree.tsx`)는 메뉴 · 페이지 줄의 것이라 그대로 둔다.

리스너는 호스트 문서와 캔버스 iframe 문서 **양쪽**에 건다 — 호스트에 건 리스너는 캔버스 안의 키를 못 받는다(`canvas/canvas-document.tsx` 의 `useCanvasDocument` — 페이지를 옮기면 iframe 이 새로 서므로 이펙트의 의존에 둔다).

**서지 않는 때:**

- 포커스가 글 입력 표면이다(`panels/typing-surface.ts` 의 `isTypingSurface` — 편집 가능성으로 가른다) — 입력 칸의 Delete · Cmd+Z · Cmd+C 는 그 칸의 것이다.
- 한글 조합 중(`isComposing`)
- 모달이 열려 있다
- 메뉴 트리 상자에 포커스가 있다(그 상자의 단축키가 받는다)
- 편집 단축키는 뷰 모드 · viewer · 고른 노드를 남이 잡은 판에서 안 선다 — 고르기 · 선택 이동 · 도움말 · 복사는 선다

macOS 는 Cmd, 그 밖은 Ctrl 이다(`event.metaKey` / `event.ctrlKey` — 플랫폼으로 가른다).

### 키

| 키 | 동작 |
|---|---|
| Cmd+Z | 되돌리기 — 머리 «되돌리기» 단추와 같은 함수 |
| Cmd+Shift+Z · Cmd+Y | 다시 하기 — 머리 «다시 하기» 단추와 같은 함수 |
| Delete · Backspace | 고른 노드(들) 삭제 — **확인 없이 바로**(되돌리기로 복구한다). 줄 행동 `…` 의 «삭제»는 지금의 두 번 누르기 확인을 그대로 둔다 |
| Cmd+C | 복사 |
| Cmd+X | 잘라내기(복사 + 삭제 — 편집은 삭제 하나) |
| Cmd+V | 붙여넣기 |
| Cmd+D | 복제 — 고른 노드마다 제 바로 뒤에 사본 |
| Escape | 선택 해제(열린 메뉴 · 고르개가 있으면 그것을 먼저 닫는다) |
| Alt+↑ / Alt+↓ | 위로 / 아래로 — 줄 행동과 같은 판정 · 같은 편집 |
| Alt+Shift+← / Alt+Shift+→ | 내어쓰기 / 들여쓰기 — 줄 행동과 같은 판정 · 같은 편집 |
| ↑ / ↓ | 이전 / 다음 노드 고르기 — 구조 트리의 보이는 차례(접힌 줄은 건너뛴다) |
| ← / → | 부모 / 첫 자식 고르기 |
| ? (Shift+/) | 단축키 목록 대화 상자 — 이 표를 그대로 그린다(표 하나에서 짓는다) |

Alt 조합은 `event.key` 가 아니라 `event.code` 로 읽는다 — macOS 에서 Alt+문자는 특수문자가 된다(구조 트리의 지금 처리 그대로).

## 클립보드

### 담기 · 꺼내기

키(keydown)가 아니라 브라우저의 `copy` · `cut` · `paste` 이벤트로 받는다 — `clipboardData.setData` · `getData` 는 사용자 몸짓 안에서 권한 묻기 없이 Chrome · Safari · Firefox 에서 된다(`navigator.clipboard.readText` 는 브라우저에 따라 권한을 묻는다). 이벤트는 위 «서지 않는 때»와 같은 조건을 지난다 — 입력 칸의 복사 · 붙여넣기는 그 칸의 것이다.

담는 것은 `text/plain` 하나다 — 봉투:

```jsonc
{
  "wirebound": "nodes",
  "version": 1,                // 문서 봉투의 schema version(§13.1 — 마이그레이션 진입점)
  "nodes": [ { "id": "…", "type": "…", "props": { … }, "children": [ … ] } ]  // 서브트리, 문서 차례
}
```

### 붙이기

- 봉투를 `schema` 의 검증기로 읽는다(옛 version 이면 마이그레이션 체인). wirebound 봉투가 아닌 글이면 아무것도 안 한다 — 통지도 없다(다른 앱의 글을 붙인 것은 실수가 아니다).
- **노드 id 를 새로 짓고 상호작용 대상도 함께 바꾼다** — 페이지 JSON 가져오기와 같은 규칙이고 같은 함수를 쓴다. 대상이 붙이는 노드들 밖인 동작은 붙이는 문서에 그 노드(페이지 대상이면 지금 프로젝트에 그 페이지)가 있으면 남기고, 없으면 빼고 뺀 수를 통지 줄에 알린다 — 동작이 다 빠진 상호작용은 상호작용째 뺀다.
- **자리:** 기준 노드(아래 «선택») 바로 뒤 형제로, 봉투의 노드들을 차례대로 연달아 넣는다. 고른 것이 없거나 루트면 페이지 끝. 부모가 그 타입을 자식으로 안 받으면(검증) 아무것도 안 하고 이유를 통지한다.
- 다른 프로젝트 · 다른 테마에서 온 봉투도 그대로 붙는다 — 카탈로그가 닫혀 있다. 코멘트는 따라가지 않는다.
- 붙인 노드(들)가 고른 노드가 된다.

복사 · 잘라내기는 고른 것이 여럿이면 문서 차례대로 봉투 하나에 담는다.

## 선택

### 모델

스토어의 고른 노드 하나(`selectedNodeId`)를 **선택 목록 + 기준 노드**로 바꾼다. 기준 노드는 마지막으로 고른 것이고, Shift 범위 · 화살표 이동 · 붙일 자리 · 속성 패널(하나일 때)의 기준이다. 하나 고른 판은 목록 길이 1 이라 지금 동작이 그대로다.

- **조상과 자손은 함께 안 선다** — 서브트리 잠금이 이미 덮는다. 고른 노드의 조상이나 자손을 더하면 새로 누른 것이 관련된 쪽을 대신한다.
- **루트는 여럿 고르기에 안 든다** — 루트를 Cmd+클릭하면 선택이 루트 하나가 된다.
- 고른 노드가 지워지면(남의 편집 · 되돌리기) 목록에서 빠진다. 기준 노드가 빠지면 목록의 마지막이 기준이 된다.

### 고르는 법

| 몸짓 | 동작 |
|---|---|
| 클릭 | 그것 하나 |
| Cmd+클릭(트리 · 캔버스) | 더하기 · 빼기 |
| Shift+클릭(트리) | 기준 노드부터 누른 줄까지 보이는 차례로 — 조상 · 자손 규칙으로 걸러 가장 바깥 것들 |
| Cmd+A | 기준 노드의 형제 모두(기준 노드가 루트면 루트의 자식 모두) |
| 캔버스 사각형 | 아래 |

**캔버스 사각형:** 캔버스 문서에서 누르고 4px 넘게 움직이면 사각형이 선다 — 캔버스에서 노드를 눌러 끄는 동작이 없으므로 어디서 시작해도 된다(노드를 옮기는 길은 손잡이 하나). 그려진 상자가 사각형 안에 **완전히** 든 노드 가운데 조상이 이미 든 것을 뺀 가장 바깥 것들을 고른다. Shift 를 누른 채 그리면 기존 선택에 더한다. 4px 안에서 떼면 지금처럼 클릭(고르기)이다. 칸 끝에 닿으면 끌어 놓기와 같은 끝 스크롤을 쓴다.

**보이는 것:** 캔버스는 고른 것마다 외곽선, 기준 노드는 진하게. 손잡이는 하나 골랐을 때만. 구조 트리는 고른 줄을 모두 강조한다.

### 잠금 — 고른 서브트리마다 하나

- 서버 잠금 저장소(`apps/api/src/lock`)는 연결마다 **서브트리 여럿**을 쥔다.
- WS 프로토콜(`apps/api/src/ws/protocol.ts` · `ws/lock.ts`): 고르기 하나가 «내 잠금을 이 집합으로»를 보낸다. 서버는 페이지 행을 쥔 채(편집 커밋과 같은 줄) **더해지는 것만** 지금의 겹침 판정으로 묻고, 받은 것만 쥐고, 거절된 것은 노드 id 와 함께 `lock-denied` 로 답하고, 빠진 것은 놓는다.
- 화면은 거절된 노드를 선택에서 빼고 «○○님이 편집 중이라 고를 수 없습니다» 한 줄을 세운다. 남의 화면에는 고른 것마다 «○○ 편집 중» 배지.
- 하트비트 · TTL · 연결 종료 해제는 집합 전체에 건다.
- 2차 방어(편집 묶음의 잠금 판정 `lockConflictOfOps`)는 «남의 잠금 여럿»을 이미 다루므로 그대로다 — 내 잠금은 내 것이라 판정에 안 든다.
- **상한:** 연결당 잠금 수에 상한을 둔다(값은 E2 가 재서 정한다 — 첫값 200). 넘으면 Cmd+A · 사각형 · Shift 범위가 더 고르지 않고 그렇다고 알린다.
- 같은 사람의 다른 탭 · MCP · 토큰 편집은 지금처럼 사람 단위라 서로 막지 않는다.

## 여럿을 고른 판의 동작

| 동작 | 여럿일 때 |
|---|---|
| 삭제(Delete · `…` «삭제») | 고른 서브트리를 모두 지운다 |
| 복사 · 잘라내기 | 문서 차례대로 봉투 하나 |
| 붙여넣기 | 기준 노드 뒤에 차례대로 |
| 복제 | 노드마다 제 바로 뒤에 |
| 위로 · 아래로 · 들여쓰기 · 내어쓰기 · 화살표 고르기 | 하나 골랐을 때만 — 여럿이면 끈 채 이유를 단다 |
| 속성 패널 — 같은 타입 | 그 타입의 패널 · 값이 갈리는 칸은 «여러 값» · 바꾼 칸만 모두에 쓴다 |
| 속성 패널 — 타입이 섞임 | «N개 고름 — 일괄 속성 편집은 같은 타입끼리만» · 삭제 |
| 상호작용 · 코멘트 탭 | 하나 골랐을 때만 |

### 편집 하나 = 되돌리기 하나

일괄 삭제 · 붙여넣기 · 복제 · 일괄 속성 변경은 **연산 묶음 하나(revision 하나)** 로 보낸다 — Cmd+Z 한 번에 통째로 돌아오고 남의 화면에도 한 번에 반영된다. 묶음은 서버의 2차 방어와 화면이 편집을 미리 묻는 자리(`lockConflictOfOps`)를 지난다 — 하나라도 남의 잠금에 부딪치면 묶음째 거절되고 통지 줄이 이유를 말한다. 묶음 크기 한도는 E2 가 서버에 있는지 재고, 없으면 정해 서버와 화면에 함께 둔다(화면이 미리 막는다).

## 테스트

- **jsdom:** 단축키 표(입력 표면 · 조합 · 모달 · 뷰 모드 · viewer 에서 안 섬 · 메뉴 트리 상자) · 봉투 읽기 · id 재발급 · 상호작용 대상 바꾸기 · 버린 수 · 선택 목록 규칙(조상/자손 · 루트 · Shift 범위 · Cmd+A · 지워진 노드) · 일괄 연산 묶음 · «여러 값».
- **실브라우저(`apps/web/build-test/`):** 캔버스 iframe 안에 포커스가 있을 때의 단축키 · 실제 클립보드 복사 → 다른 탭 · 다른 프로젝트에 붙여넣기 · 사각형 고르기(줌 · 칸 스크롤 · 끝 스크롤) · 여럿 고른 채 다른 계정이 그중 하나를 노리는 판(배지 · 거절) · Cmd+Z 한 번에 일괄 편집이 통째로 돌아오는 판 · 키보드 Delete 와 줄 `…` «삭제»의 확인 차이.
- **api:** 잠금 집합 획득 · 부분 거절 · 겹침 경주(페이지 행 줄 서기 — 두 연결이 겹치는 집합을 동시에 청함) · 연결 종료 시 집합 해제 · 상한 · 하트비트가 집합 전체를 갱신.

## 진행 단계
