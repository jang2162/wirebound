# 트리 접기 · 노드 별칭 · 줄 요약 · 컴포넌트 목록 줄바꿈 · 배치 선 — 설계

구조 트리에서 어느 줄이 어느 요소인지 알아보기 쉽게 하고(별칭 · 속성 요약 · 접기), 하단 컴포넌트 목록과 캔버스의 배치 확인을 다듬는다.

이 문서는 발행 시점의 기록(spec)이다. 구현이 병합되면 정본 설계서(`docs/superpowers/specs/2026-08-03-wirebound-design.md`)의 「설계서 화면 구조」 · 노드 모델 절과 `apps/api/README.md` 가 지금 참인 것을 갖는다.

---

## 목적과 범위

**목적:** 구조 트리 줄이 타입 이름만 보여 같은 타입이 여럿이면 어느 것인지 가르기 어렵다. 깊은 트리는 접을 수 없어 길다. 하단 컴포넌트 목록은 카드 한 줄이 판 높이를 채운다. 캔버스에서 배치(Flex · Grid)의 경계와 방향이 안 보인다.

**범위 안:** 메뉴 · 구조 트리 줄마다 접기 · 노드 별칭(저장 · 고치기 · 노드를 가리키는 곳 모두에 보이기) · 구조 트리 줄의 `타입 (별칭) 요약` · 컴포넌트 목록의 줄바꿈 배치 · 상단 바 «배치 선» 토글.

**범위 밖:** 접힘 상태를 서버 · 다른 기기에 기억하기 · 별칭으로 노드 찾기(검색) · 배치 선을 Flex · Grid 밖의 컴포넌트로 넓히기 · 요약 규칙을 테마가 바꾸기.

---

## 트리 줄마다 접기

- 메뉴 트리는 메뉴마다, 구조 트리는 자식이 있는 노드마다 줄 앞에 펼침 단추(▸ / ▾ — 아이콘 표의 chevron)를 둔다. 트리 머리에 «모두 접기» · «모두 펴기».
- 접힘 상태는 화면의 상태다 — 세션 동안 페이지(구조 트리) · 프로젝트(메뉴 트리)마다 기억하고, 새로 고침 뒤 모두 펼친다. 서버에 안 간다.
- **고른 노드가 접힌 줄 안이면 그 조상을 저절로 편다** — 캔버스에서 고름 · 붙여넣기 · 복제 · 화살표 이동 · 사각형 고르기 · 남의 편집으로 기준 노드가 옮겨 감.
- 키보드(표준 트리): → 접혔으면 펴고 펴졌으면 첫 자식 · ← 펴졌으면 접고 접혔으면 부모 · ↑ ↓ 는 접힌 줄 안을 건너뛴다(선택 이동의 보이는 차례).
- 끌어 놓기: 끄는 포인터가 접힌 줄 위에 0.7s 머물면 그 줄을 편다. 접힌 줄에 «안»으로 놓으면 그 안 끝.
- Shift+클릭 범위는 보이는 차례 — 접힌 줄 안은 들지 않는다.

## 노드 별칭

- 노드에 선택 필드 `alias` — 글, 앞뒤 공백을 걷은 1 ~ 60자. 빈 값은 필드를 지운다. 봉투 검증(`packages/schema`)이 모양을 본다 — 옛 문서는 그대로 읽히고 마이그레이션은 없다. 문서마다 유일할 필요는 없다.
- **고치는 자리:** 속성 패널 맨 위 «별칭» 칸 · 구조 트리 줄의 더블클릭 · F2 · 줄 `…` «별칭 바꾸기». 고침은 편집 하나(`replace` / `add` / `remove` `/…/alias`) — 되돌리기 · 실시간 방송 · 잠금 판정을 지금 편집 길 그대로 탄다.
- **보이는 자리 — 노드를 가리키는 곳 모두:** 구조 트리 줄 · 속성 패널 제목 · 상호작용 문장과 대상 고르개(«'저장 버튼'을 누르면 …» — 별칭이 없으면 지금 이름) · 코멘트의 노드 표시 · 내보낸 HTML 설계서의 상호작용 목록 · MCP 의 트리 읽기. 이름을 짓는 함수는 하나(`packages/schema` — `nodeDisplayName(node)`)이고 모든 자리가 그것을 부른다.
- 복사 · 붙여넣기 · 복제 · 프리셋 · 가져오기에서 별칭은 노드와 함께 간다.

## 구조 트리 줄 — `타입 (별칭) 요약`

- 줄은 `타입 이름` + 별칭이 있으면 ` (별칭)` + 요약(흐린 글 · 한 줄에 맞춰 줄임표로 자름). 줄의 접근 이름도 같은 글이다.
- 요약 규칙은 카탈로그 정의마다 하나(`summary: (props) => string | null` — `packages/schema` 의 순수 함수). MCP 도 같은 글을 쓴다.

| 타입 | 요약 |
|---|---|
| Flex | 가로 · 세로(줄바꿈이면 «· 줄바꿈») |
| Grid | «N열» |
| Button · Link · Placeholder | 라벨 |
| Field | 라벨 · 컨트롤 종류 |
| Card · EntryForm | 제목 |
| Text | 내용 앞 20자 |
| Tabs | 탭 이름 앞 셋(« · »로 잇고 더 있으면 «…») |
| List | 컬럼 이름 앞 셋 |
| KeyValue | «N쌍» |
| Media | 종류 · 설명 |
| Divider | 방향 |
| Tree | «항목 N» |
| Page · Slot · Section · SearchForm | 없음 |

## 컴포넌트 목록 — 줄바꿈 배치

- 카드는 정해진 크기(지금 카드 크기)이고 판 폭에 맞춰 여러 줄로 감싼다. 넘치면 판이 세로로 스크롤한다. 카드는 판 높이를 따라 늘어나지 않는다.
- 판 높이 손잡이 · 갈래 탭 · 검색 · «넣기» 단추 · 끌기는 그대로. 축소판은 지금처럼 판 하나에 iframe 하나를 카드 판 뒤에 깔고 2차원 배치에 맞춘다.

## 상단 바 «배치 선»

- 머리에 아이콘 토글(누름 상태를 `aria-pressed` 로) — 편집 모드에서만 선다.
- 켜면 캔버스의 Flex · Grid 노드마다 점선 테두리와 모서리 표시(Flex → · ↓ — `direction` 과 `*-reverse` 는 그려진 배치로 읽는다 · Grid «N열»)를 셸 겹에 그린다 — 선택 외곽선 · 번호 마커와 같은 측정(줌 · 칸 스크롤 · 다시 잼)을 쓴다. 캔버스 문서에는 아무것도 넣지 않는다(테마 CSS 와 안 섞임). 미리보기 노드(`wb:preview:`)에는 안 그린다.
- 켬 · 끔은 사람마다 브라우저에 기억한다(`localStorage` — 못 읽으면 끔).

## 테스트

- **jsdom:** 요약 함수 표(타입마다 · 빈 props · 긴 글) · `nodeDisplayName` · 별칭 봉투 검증(0자 · 61자 · 공백만) · 별칭 편집 연산(넣기 · 바꾸기 · 지우기) · 접기 상태 · 저절로 펴짐 · 키보드 ← → · 보이는 차례 · 배치 선 토글 기억.
- **실브라우저:** 접힌 줄 위 끌기의 펼침 · 캔버스에서 고른 노드의 조상 펼침 · 별칭을 트리에서 F2 로 고침 → 남의 화면 · 상호작용 문장 · 되돌리기 · 컴포넌트 목록의 줄바꿈과 축소판이 카드에 맞음(창 1440 · 900 · 700) · 배치 선이 줌 · 스크롤에서 노드에 맞음(시스템 테마 다섯).
- **api · exporter · MCP:** 별칭이 든 문서의 저장 · 검증 거절(61자) · 내보낸 설계서의 상호작용 문장 · MCP 트리 읽기.

## 진행 단계

| 트랙 | 무엇 | 리뷰 |
|---|---|---|
| F1 | 트리 접기 · 목록 줄바꿈 · 배치 선(web) | 스크린숏 |
| F2 | 별칭 · 요약(schema + web + exporter + MCP — 한 브랜치) | 리뷰어 한 번 |

둘은 나란히 돈다. 겹치는 파일(`panels/structure-tree.tsx` 의 줄)은 뒤에 병합하는 쪽이 앞 병합 위로 리베이스한다.
