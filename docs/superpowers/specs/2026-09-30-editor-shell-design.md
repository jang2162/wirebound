# 에디터 셸 개편 — 설계

에디터 셸의 머리에 몰린 기능을 `…` 메뉴와 하단 바로 나누고, 트리의 툴바를 노드별 `+` · `…` 와 드래그로 바꾸고, 프로젝트 설정 페이지에 멤버 · 삭제를, 새 계정 설정 페이지에 비밀번호 · API 토큰을 둔다.

이 문서는 발행된 시점 기록(spec)이다. 구현이 병합될 때 정본 설계서(`docs/superpowers/specs/2026-08-03-wirebound-design.md`)의 「설계서 화면 구조」 절(머리 · 트리 · 셸 밖의 화면)과 「권한 모델」 절(비밀번호 바꾸기)을 이 문서에 맞춰 고친다.

---

## 목적과 범위

**목적:** 머리 한 줄에 열 가지 넘는 도구와 통지가 몰려 있고, 좌측 트리는 툴바 단추가 메뉴 8 · 구조 7 개라 화면이 붐빈다. 자주 쓰는 편집 도구만 눈앞에 두고, 프로젝트 · 계정 단위의 일은 한 메뉴 뒤로, 캔버스를 다루는 도구는 캔버스 곁으로 옮긴다.

**범위 안:**

- 머리: 로고(아이콘 + wirebound) · 프로젝트 이름 · 되돌리기 · 모드 · `…`
- `…` 메뉴: 계정 설정 · 프로젝트 설정 · 스냅샷 · 프로젝트 내보내기 · 로그아웃. 스냅샷 · 내보내기는 대화 상자로
- 하단 바: 통지 줄 · 뷰포트 · 줌
- 우측 패널 폭 조절
- 트리: 툴바를 노드별 `+` · `…` 로, 드래그로 옮기기
- 프로젝트 설정: 멤버 절 · 위험 구역(프로젝트 삭제)
- 계정 설정(새 페이지): 내 정보 · 비밀번호 바꾸기(새 api) · API 토큰
- 프로젝트 목록 머리의 `…`
- 화면 맞춤일 때 가로 스크롤(재현 먼저)

**범위 밖:**

- 하단의 컴포넌트 목록과 트리 · 캔버스로 끌어 놓는 배치 — 뒤 과제 D. 이 과제는 하단 바와 드래그 장치를 D 가 얹을 수 있게 짓는 데까지다.
- 이름 바꾸기 · 이메일 바꾸기 · 비밀번호 찾기(메일).
- 모바일 · 좁은 창. 에디터는 데스크톱 창을 전제한다(정본 「설계서 화면 구조」).

## 셸의 머리

한 줄이다.

| 자리 | 내용 |
|---|---|
| 왼쪽 | 아이콘 + «wirebound» — 프로젝트 목록으로 가는 링크(`<Link>`, 주소가 있는 이동). 그 옆에 프로젝트 이름(`<h1>`) |
| 가운데 | 되돌리기 · 다시 실행(편집 모드이고 `canEdit` 일 때만 — 지금 규칙), 모드(편집/뷰) |
| 오른쪽 끝 | `…` 단추 |

로고 링크의 접근 이름은 «프로젝트 목록»이다 — 글자 «wirebound» 는 갈 곳을 말하지 않는다. 아이콘은 저장소 안 SVG 하나다(외부 글꼴 · 아이콘 묶음을 들이지 않는다).

머리 폭 표(`shell.css` 의 «머리가 한 줄에 들어가는 폭»)는 새 머리로 다시 잰다.

## `…` 메뉴

모든 역할에게 선다. 항목 차례: **계정 설정 · 프로젝트 설정 · 스냅샷 · 프로젝트 내보내기 · 로그아웃.** 메뉴 머리에 로그인한 사람의 이름을 보인다.

- 계정 설정 · 프로젝트 설정은 링크(`/account` · `/projects/:id/settings`)다.
- 스냅샷 · 프로젝트 내보내기는 에디터 위 **대화 상자**를 연다(아래).
- 로그아웃은 지금 계정 묶음의 동작 그대로다 — 보낸 편집의 답을 한도(3s)까지 기다린 뒤 나가고, 막지 않는다.
- 메뉴 역할(`menu` · `menuitem`): 단추로 열고, 화살표로 옮기고, Enter 로 고르고, Escape · 바깥 누름으로 닫는다. 닫히면 포커스가 `…` 로 돌아온다.

지금 머리의 스냅샷 팝오버 · 내보내기 팝오버 · «설정» 링크 · 계정 묶음(이름 · API 토큰 · 로그아웃)은 이 메뉴로 들어가 머리에서 빠진다.

## 대화 상자

앱의 첫 모달이다. 공용 대화 상자 하나(`<dialog>` 의 `showModal`)를 세우고 스냅샷 · 내보내기가 함께 쓴다.

- 포커스를 안에 가두고, Escape 로 닫고, 닫히면 연 단추(`…`)로 포커스를 돌려준다.
- 제목(`aria-labelledby`)과 닫기 단추가 있다.
- **안의 내용 · 동작은 지금 팝오버 그대로 옮긴다** — `SnapshotsPanel` 의 복원 콜백(`onRestoreSent` · `onRestored` · `onRestoreRefused` · `onRestoreUnanswered`)과 셸 세대(`shellGeneration`)로 거르는 장치, `ExportPanel` 의 내려받기 흐름. 겉 상자만 바뀐다. 대화 상자는 에디터 셸 안에서 그려지므로 셸이 내려가면 함께 내려간다.
- 복원을 보낸 뒤 대화 상자를 닫아도 복원 답은 지금처럼 셸이 받는다.

이것으로 스냅샷 팝오버가 머리 단추를 덮던 겹침이 없어진다(팝오버가 없다).

## 하단 바

캔버스 칸 아래 한 줄이다(좌 · 우 사이드바 사이, 캔버스와 같은 폭).

| 자리 | 내용 |
|---|---|
| 왼쪽 | 통지 줄 — 편집 실패(`EditAlert`) · 경고(`EditWarnings`) · 남의 변경(`RemoteAlert`) · 테마 못 실음(`ThemeAlert`) · 권한 바뀜 · 세션 전환 · 로그아웃 실패 |
| 오른쪽 | 뷰포트 폭 고르개 · 줌(− / 값 / + / 화면 맞춤) |

- 통지의 `role`(`alert` · `status`)과 문안은 그대로다. 자리만 머리 아래 줄에서 하단 바로 옮긴다. 통지가 여럿이면 하단 바가 위로 자란다(캔버스가 그만큼 준다) — 잘라 숨기지 않는다.
- 캔버스 칸이 좁아 통지가 읽을 폭(320px)을 못 받으면 도구가 통지 아래 줄의 오른쪽 끝으로 내려간다 — 도구가 제 폭을 지키고 통지가 남은 폭만 받으면, 창 1024 에서 통지 한 줄이 한두 낱말이 되어 바가 캔버스를 먹는다.
- **D 를 위한 자리:** 하단 바는 캔버스 칸의 아래 영역(그리드 한 칸)이다. D 가 그 위에 펼쳐지는 판(컴포넌트 목록)을 얹을 수 있게, 하단 바와 캔버스 사이에 다른 칸을 끼울 수 있는 그리드로 짓는다.

**화면 맞춤 가로 스크롤:** 워커가 지금 판(캔버스 iframe · 표준 모드)에서 먼저 재현한다 — 뷰포트 프리셋 여섯 × 사이드바 폭 기본 · 최대에서 «화면 맞춤» 뒤 캔버스 칸의 `scrollWidth > clientWidth` 를 센다. 재현되면 원인(`fitZoom` 의 여백 · 스크롤바 폭 · 반올림)을 찾아 고치고 실브라우저 케이스로 잠근다. 재현되지 않으면 고치지 않고 잰 표를 보고에 적는다.

## 우측 패널 폭

좌측과 같은 손잡이(`ShellResizer`)를 캔버스와 우측 패널 사이에 둔다 — 끌기 · 화살표 · Home/End · 두 번 눌러 기본값.

- 기본 300px · 최소 300px. 폭은 사람마다 `localStorage` 에 기억한다(좌측과 같은 장치 · 접근이 던지면 기본값).
- 두 사이드바의 최대 폭은 서로를 본다 — 좌측 최대 폭이 «우측 300px 고정»을 전제로 세는 자리(`SIDE_RESERVED_WIDTH`)를 «우측의 지금 폭»으로 바꾼다. 어느 쪽을 넓혀도 캔버스 몫(`CANVAS_MIN_WIDTH`)이 남고, 창을 줄이면 두 폭이 함께 조여진다.

## 트리

### 툴바 대신 노드별 `+` · `…`

줄에 마우스를 올리거나, 그 줄을 고르거나, 키보드 포커스가 오면 줄 오른쪽 끝에 `+` · `…` 가 선다. 편집할 수 없는 판(뷰 모드 · viewer — 지금 `editable` · `canEdit`)에서는 서지 않는다.

| 트리 · 줄 | `+` | `…` |
|---|---|---|
| 메뉴 트리 · 메뉴 | 하위 메뉴 · 페이지 추가 | 이름 변경 · 옮기기 · 위로 · 아래로 · 들여쓰기 · 내어쓰기 · 삭제 |
| 메뉴 트리 · 페이지 | — | 이름 변경 · 옮기기 · 위로 · 아래로 · 삭제 |
| 구조 트리 · 노드 | 안에 추가 · 아래 추가(타입 · 패턴 · 프리셋 고르개가 그 줄 곁에 뜬다) | 위로 · 아래로 · 들여쓰기 · 내어쓰기 · 삭제 |

- 페이지 줄의 `…` 에서 들여쓰기 · 내어쓰기가 빠지는 것은 지금 판정(`treeAbilities`)이 페이지에 그것을 안 주기 때문이다 — 구현이 판정을 따라 항목을 끄거나 뺀다.
- 두 트리의 맨 위에는 뿌리에 더하는 `+` 가 하나씩 있다(메뉴 트리: 최상위 메뉴 · 구조 트리: 페이지 바로 아래).
- 할 수 없는 항목은 끈다(`treeAbilities` · `edit/structure-actions.ts` 판정 그대로). 삭제의 두 번 누르기 확인과 지금 있는 키보드 단축키는 그대로다.
- `…` 는 머리의 `…` 와 같은 메뉴 부품을 쓴다.

### 드래그로 옮기기

줄을 끌어 다른 줄의 **위 · 아래(형제로)** 나 **위에 겹쳐(자식으로)** 놓는다. 놓을 자리는 가는 선(형제) · 줄 강조(자식)로 보인다.

- **놓을 수 있는지는 지금의 이동 판정을 쓴다** — 메뉴는 메뉴 안으로, 페이지는 메뉴 안으로(다른 메뉴로 옮기기 포함), 구조 노드는 카탈로그가 자식을 받는 컴포넌트 안으로만, 자기 자손 안으로는 못 간다. 못 놓는 자리에서는 표시를 안 세우고, 놓아도 아무 일도 없다.
- **놓으면 지금 «옮기기 · 위로 · 들여쓰기» 가 보내는 것과 같은 편집을 보낸다** — 되돌리기 · 실시간 방송 · 서버 거절 수습이 지금 길을 탄다. 드래그만의 새 편집 종류를 만들지 않는다.
- 남이 잡은 노드(노드 잠금 · `use-node-lock`)는 끌지 못하고 그 안으로 놓지도 못한다.
- 끄는 동안 Escape 는 취소다. 트리 끝에 닿으면 저절로 스크롤한다. 끌기는 몇 px 움직인 뒤에 시작해 클릭(선택)과 가른다.
- **포인터 이벤트로 짓는다(HTML5 DnD 가 아니다)** — `setPointerCapture` 로 붙잡는다. D 의 «목록 → 트리 · 캔버스(iframe)» 드래그가 같은 장치를 쓰게 하려는 것이다. 기본 DnD 는 same-origin iframe 경계에서 이벤트가 끊기고 끄는 모양을 다루기 어렵다. 장치는 트리에 매이지 않는 부품(끌기 상태 · 놓을 자리 판정 입구 · 표시)으로 둔다.

정본 「설계서 화면 구조」 는 이미 «드래그로 정렬한다»고 적는다 — 이 과제가 코드를 그 문장에 맞춘다. 「캔버스 직접 드래그 편집은 지원하지 않는다」 문장은 D 가 다룬다.

## 프로젝트 설정 페이지

`/projects/:id/settings` 에 두 절을 더한다(지금 «일반» · «테마» 뒤).

### 멤버

- 모든 역할이 목록(이름 · 이메일 · 역할)을 본다(`GET …/members` 는 viewer 부터).
- owner 에게만 초대(이메일 + 역할) · 역할 바꾸기 · 제외가 열린다 — api 는 이미 있다(`POST` · `PATCH` · `DELETE …/members`).
- 서버의 답을 화면 문장으로 옮긴다: 없는 계정 404 · 이미 멤버 409 · 역할 부족 403 · 마지막 owner 를 강등 · 제외(`LastOwnerError`). 문장은 api 의 오류 봉투를 따른다.
- 내 역할이 바뀌거나 내가 빠지면 지금의 권한 변경 통지 길을 따른다(설정 페이지가 그 신호를 받는지 먼저 센다 — 안 받으면 다시 읽기로).

### 위험 구역

맨 아래 · owner 만. **프로젝트 삭제** — 지금 목록 줄의 확인 방식(`projects/delete-confirm.tsx` — 프로젝트 이름을 정확히 쳐야 확정이 열림)을 옮긴다. 삭제 뒤에는 프로젝트 목록으로 간다. **목록 줄의 삭제는 뗀다.**

## 계정 설정 페이지

새 라우트 `/account`. 셸 밖 화면이다. 세 절:

### 내 정보

이름 · 이메일을 읽기로 보인다(`GET /api/auth/me`).

### 비밀번호 바꾸기

지금 비밀번호 · 새 비밀번호 · 새 비밀번호 확인을 받는다. 새 api **`POST /api/auth/password`** `{ currentPassword, newPassword }`.

- **세션으로만 부른다.** API 토큰으로 부르면 거절한다(토큰은 프로젝트 범위이고 계정 자격을 바꾸지 않는다).
- **지금 비밀번호를 견주는 시도는 로그인 시도 한도에 함께 센다** — 같은 계정 키 · 주소 키(`auth/login-limit.ts`). 훔친 세션으로 비밀번호를 맞혀 보는 창구가 되지 않게 한다. 한도 안에서 틀리면 로그인 실패와 같은 코드 · 문장이고, 한도를 넘으면 429 + `Retry-After` 다.
- 새 비밀번호의 규칙과 해시는 `reset-password` 명령과 같은 함수(`auth/credentials.ts` 의 `NewPassword` · `auth/password.ts` 의 `hashPassword`)다.
- **바꾸면 이 세션만 남기고 그 사용자의 다른 세션을 모두 지운다.** 지운 세션의 WS 연결도 지금 세션 삭제 길로 권한을 잃는다. API 토큰은 그대로다 — 비밀번호와 따로 발급한 자격이고, 거두는 길은 같은 페이지의 토큰 절이다.
- 쓰기는 커밋 직전에 자격(세션)을 다시 본다(정본 「권한 모델」 의 쓰기 규칙). 권한을 줄이는 쓰기가 아니므로 예외가 아니다.

### API 토큰

지금 `/tokens` 화면(`routes/tokens.tsx`)의 내용을 이 페이지의 절로 옮긴다. 옛 주소 `/tokens` 는 `/account` 로 넘겨 준다.

## 화면 사이의 길

| 어디서 | 무엇으로 | 어디로 |
|---|---|---|
| 에디터 `…` | 계정 설정 · 프로젝트 설정 | `/account` · `/projects/:id/settings` |
| 프로젝트 목록 머리의 `…` | 계정 설정 · 테마 관리(인스턴스 관리자만) · 로그아웃 | `/account` · `/admin/themes` |

프로젝트 목록 머리의 `…` 는 지금 목록 머리의 계정 묶음과 «테마 관리» 링크를 대신한다.

---

## 테스트

- **jsdom:** `…` 메뉴의 항목 · 역할별 표시 · 키보드, 트리 줄의 `+` · `…` 가 판정대로 켜지고 꺼지는지, 대화 상자의 포커스 가둠 · 돌려줌, 설정 · 계정 페이지의 폼 · 오류 문장.
- **api:** `POST /api/auth/password` — 옳은 · 틀린 지금 비밀번호, 토큰으로 부름(거절), 한도(로그인과 같은 키에 셈 · 429), 다른 세션 삭제 · 이 세션 유지 · 토큰 유지, 커밋 직전 재확인(세션이 겹쳐 지워진 판).
- **실브라우저(`apps/web/build-test/`):**
  - 트리 드래그 — 메뉴 · 페이지 · 구조 노드를 형제 · 자식 자리로 끌어 놓아 서버 문서가 바뀌는지, 못 놓는 자리 · 남이 잡은 노드 · Escape 취소, 되돌리기로 돌아오는지.
  - 대화 상자 안의 스냅샷 복원 — 지금 팝오버 케이스들(복원 뒤 다시 읽기 · 통지 가르기)을 대화 상자 판으로 옮겨 그대로 초록.
  - 우측 · 좌측 폭 — 두 폭을 최대로 밀어도 캔버스 몫이 남는지, 창을 줄이면 함께 조여지는지.
  - 화면 맞춤 — 재현 판을 잠금(재현되면).
- 게이트: `pnpm typecheck` · `pnpm build` · `pnpm test` · `pnpm test:build` · `pnpm test:browser` · `EDITOR_STACK_BUNDLE=build pnpm test:browser`.
