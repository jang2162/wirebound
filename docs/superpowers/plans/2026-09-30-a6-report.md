**표지를 고른 까닭:** 다섯 `theme.css` 가 저마다의 규칙으로 주 단추를 `var(--wb-semantic-primary)` 로 칠하고 기본값이 테마마다 다르다. SDK 기본 뷰 CSS 는 단추에 바탕을 안 준다(`actionCssBlocks` 가 빈 목록) — 테마 시트가 안 실리면 표지가 설 길이 없다(아래 M1 · M2 의 실패 값 `rgb(239, 239, 239)` 가 기본 뷰의 값이다). 기대값은 manifest 에서 읽고 색을 글자로 적지 않는다.

**0.1.0 판을 세운 법 — 저장소에 픽스처로 얼렸다**(`apps/web/build-test/fixtures/system-admin-0.1.0.wbtheme`, 3812 바이트). admin 트랙 병합 전 소스(`git archive 29bc91b7 system-themes/admin` — 임시 디렉터리에 풀고 `node_modules` 를 `system-themes/admin` 것으로 심링크)를 지금 kit 의 `wb-theme build` 로 지었고, sha256 `5ff20aed…c431` 이 `checksums.json` 의 `system-admin@0.1.0` 줄과 같았다(사용자 DB 의 판이다). 케이스가 스스로 짓는 길은 버렸다 — git 이력 · 옛 소스 빌드에 기대 무겁고, 이력이 없는 사본(`git archive` 판)에서 못 선다. 픽스처의 sha256 을 케이스 첫 단언으로 체크섬 줄과 견주므로 픽스처가 조용히 바뀌지 않는다. 판 DB 에는 기동 시딩과 같은 행 꼴로 SQL 로 넣었다(관리자 업로드는 `system-` 접두어를 `reserved-id` 로 거절한다).

**변조**(스크래치 `t6/mutate.py` — 백업(경로 전체 이름) → 한 곳 치환(맞은 수 1) → 필요하면 그 테마만 빌드 → 이 파일 → 복원 · `filecmp` 같음 → 빌드한 변조면 다시 빌드 · sha256 = 체크섬 표):

| 변조 | 죽은 케이스 | 실패 값 |
|---|---|---|
| M1 portal `theme.css` 의 `[data-wb-component="Button"]` 에서 `background: var(--wb-semantic-primary)` 뗌(portal 빌드) | portal 한 줄만 | `캔버스 — system-portal: expected 'rgb(239, 239, 239)' to be 'rgb(19, 73, 126)'` · 복원 뒤 sha256 `541cb598…` = 표 |

## A6 이월 장부

A6 의 보고 여덟에서 모았다 — 닫힌 것(리뷰 D1 ~ D5 · G1 · T1, build-test 의 `?raw` 빈 글자, admin 세로 Divider, SKILL 의 세로 Divider 문장, `CLAUDE.md` 에 넣을 문장들)은 뺐다. 앞 차수(A1 ~ A5)의 이월은 각 차수 보고의 「이월」 절이 갖는다.

| # | 무엇 | 낸 보고 | 무게 | 고칠 자리 · 닫히는 조건 |

## 계획 · 브리프와 달라진 것

- 정본의 다섯 절은 이미 코드 테마 체계였다 — «옛 JSON 테마 체계의 문장을 걷는다» 는 할 것이 없었고, 지금 코드와 어긋난 문장(다섯 테마 · 의존 · 속성 표 · 없는 테마 이름)을 고쳤다. 「패키지 구조」 · 「각 패키지의 책임과 의존」 은 다섯 절 밖이지만 테마 줄이 틀려 함께 고쳤다.
- 표지는 뷰 DOM 이 아니라 `theme.css` 규칙의 계산값 하나(주 단추 바탕)로 했다 — 번들 · 캔버스 모두 번들 적재가 실패하면 테마 시트도 걷으므로 이 값 하나가 «번들 · 시트가 그 테마로 섰다» 를 함께 잰다. 뷰가 서는지는 테마마다 `bundle-views` 가 잰다.
- 다섯 줄이 확인 상자 = impact 도 함께 본다(판 올림 줄만이 아니라). 테마를 바꾸는 줄은 토큰이 비어 이어짐이 늘 0 이다 — 토큰 수의 구분력은 판 올림 줄(이어짐 2)이 갖는다.

## 띄운 것 · 치운 것

에디터 판(api · vite · Chromium · 판 DB)은 케이스마다 띄우고 거뒀다(각 파일의 `afterAll` 이 거두기 뒤 `{ processes: 0, listeningPorts: [], databases: 0 }` 을 단언). 0.1.0 을 지은 임시 디렉터리(`system-themes/.t6-old-admin`)는 지웠다. 끝에 `ps` 로 이 워크트리 경로 · headless Chrome 을 찾아 0 건. 이 워크트리의 Postgres(5460)는 그대로 둔다(폐기 때 코디네이터).
