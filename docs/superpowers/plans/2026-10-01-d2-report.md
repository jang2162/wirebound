- **고침:** 고른 노드의 `lockedBy` 를 판정 앞에서 먼저 본다 — `+` 가 그 판에 항목을 다 끄는 것(`structureAbilities` — 잠금이면 전부 거짓)과 같이 간다. 대가: 뿌리를 고른 채 페이지 어디든 남의 잠금이 있으면(`lockedBy(뿌리)` 는 자손의 잠금도 본다) 페이지 끝 넣기도 거절된다 — `+` 와 같다(이월 6).

## 계획과 달라진 것

1. **축소판은 A(같은 좌표 — 트랙 안 깔개)** — 위 표. 카드 «30 개» 는 카탈로그에 없어 18(둘 수 있는 타입 전부)로 쟀다.
2. **`CanvasIframe` 이 `className` · `title` 을 받는다** — Task 7 발견. 계획의 «`CanvasIframe` 를 쓴다» 를 그대로 짜면 판이 열린 화면에서 캔버스 iframe 을 클래스로 찾는 도구가 둘을 잡는다.
3. **공유 판정 `structureDropTarget` 이 바뀌었다** — 앞 · 뒤가 부모의 자식 허용을 본다(Task 8 발견 2). 트리 줄 끌기 · 캔버스 손잡이에도 선다(검증 전 문서에서만 갈린다).
4. **거절 문장 표에 한 줄 더** — Q1 답의 표에 없는 «넣을 부모가 자식을 안 받음» 판은 `STRUCTURE_WHY_DISABLED.addInside`. Q1 표대로면 «고른 노드가 문서에 없습니다» 가 서서 거짓이다. 고른 노드의 잠금은 판정 앞에서 먼저 본다(발견 1).
5. **판의 높이 · 열림은 사이드바와 같은 저장 키**(`StoredLayout` 에 두 필드) — 따로 키를 두면 같은 장치(필드마다 버림 · 두 번 조임)가 두 벌이다. 한 훅이 같은 키를 쓰므로 둘이 서로 덮지 않는다.
6. **카드 목록은 `+` 고르개의 `placeableGroups` 를 내보내 같이 쓴다** — 그래서 `Page` 카드도 선다(고르개에도 있다). 갈래 안 차례는 고르개처럼 한국어 이름순.
7. **경로 층에 `scrollContainerAt(point)`** — 끌기 장치의 `scrollContainer` 는 좌표를 안 받아, 카드 끌기가 마지막 좌표로 트리 · 캔버스 중 끝 스크롤할 상자를 고른다. 이름표 자리도 같은 `onOver` 감쌈이 쥔 좌표다.
8. **«끄는 중 단축키로 페이지 옮김»** — D1 과 같이 페이지를 옮기는 앱 단축키가 없어 뒤로 가기로 쟀다.
9. **탭 줄도 로빙 탭 인덱스** — 계획은 카드 줄만 적었다.

## 이월 후보

1. **`+` «아래 추가» 는 판정 `null` 인 판(잎 바로 뒤 형제를 남이 잡음)에서도 켜져 있고 서버 423 으로만 막힌다** — 판의 클릭 추가는 같은 판에서 거절 문장을 세운다(Q1 답 — 이번 과제 밖).
2. **카드 끌기의 표시는 캔버스가 다시 잴 때 다시 묻지 않는다** — 손잡이는 캔버스의 `layoutKey` 로 `refresh` 를 부르지만 판은 캔버스의 형제라 그 값을 안 받는다. 남의 편집이 노드를 밀면 표시가 옛 좌표에 남을 수 있다(놓는 순간 견줌 `sameDrop` 이 막아 데이터는 안 잃는다 — 재지 않았다). D1 이월 1(트리 줄 끌기)과 같은 꼴. 닫는 길: 경로 층의 영역 칸에 캔버스의 `layoutKey` 를 싣고 판이 구독.
3. **판에서 캔버스로 올라가는 끌기는 캔버스 칸 아래 끝 24px(`EDGE_ZONE`)을 지난다** — 지나는 동안 칸이 아래로 민다. 재지 않았다.
4. **축소판은 기본 variant · 표본 첫째만** 그린다 — 입력 필드 · 구분선처럼 얇은 표본은 창 안에서 작게 보인다(스크린숏). variant 고르기 · 표본 고르기는 범위 밖.
5. **축소판 iframe 의 폭이 트랙 폭(카드 18 이면 2500px 가까이)** — 테마의 `@media` 가 넓은 뷰포트로 판정한다. 표본은 제 폭 360 상자 안이라 그 안의 배치는 360 이지만 `@media` 로 갈리는 규칙은 넓은 쪽이다.
6. **뿌리를 고른 채 페이지 어디든 남의 잠금이 있으면 클릭 추가가 거절된다**(발견 1의 대가 — `+` 와 같다). 끌어 놓기로는 페이지 끝에 놓인다.
7. 토큰 · 테마가 바뀌면 표본 전부를 다시 그린다 — 비용은 안 쟀다. 카드 30 개 판의 첫 그림도 못 쟀다(카탈로그 18).
8. jsdom 셸 케이스가 판을 열면 축소판 iframe 에 표본 18 을 그린다 — 지금 판 케이스의 시간은 수십 ms 다.
