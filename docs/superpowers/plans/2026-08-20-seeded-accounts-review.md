## 5. 파라 4 — **`helpers.ts` 의 계약과 그 근거 (D2)**

### 5.1 판정: **머리말의 근거는 참이다. 시딩은 프로덕션 경로다 — 테스트 전용 우회가 아니다**

머리말이 든 근거는 *"픽스처가 비밀번호 해시·세션 발급을 **실제 경로가 하는 그대로** 거친다"*
이고, 오늘 그 두 일의 주인이 갈렸다. **갈린 뒤에도 픽스처는 양쪽 다 프로덕션 것을 부른다:**

| 옛 라우트가 하던 일 | 오늘의 프로덕션 경로 | 그것이 프로덕션인 근거(내가 잰 것) | 픽스처가 부르는 것 |
|---|---|---|---|
| 해시 · `users` 삽입 | `db/seed-user.ts` 의 `seedUser` | `migrate.ts:109` 이 `runSeedStep` → `seedUserFromEnv` → **같은 `seedUser`** 를 부른다. 그리고 `insertUser` 를 부르는 자가 저장소 `src/` 에 **이 함수 하나뿐**이다(§2.1) | `seedUser` 그대로 |
| 세션 발급 · 쿠키 | `POST /api/auth/login` | 쿠키를 내는 라우트가 저장소에 그것 하나다 | `app.inject()` |

**"테스트 전용 우회"의 정의(프로덕션이 안 지나는 길을 테스트만 지난다)에 해당하지 않는다.**
반대로 **옛 판보다 좁아졌다** — 예전에는 픽스처가 라우트를 지나며 zod 본문 검증까지 태웠고
지금은 함수를 직접 부르지만, 그 함수가 **자기 게이트를 스스로 갖는다**(`validateInput`,
`seed-user.ts:166`) — 환경변수를 안 지나는 호출자도 같은 규격을 지난다. `seed-user.test.ts:207`
이 그것을 든다.

**계약도 그대로다**(내가 확인): 돌려주는 것은 `{ user, cookie, password }` 셋, 첫 `inject` 가
인스턴스를 부팅시키는 순서 제약도 그대로(`roles.test.ts` 가 기댄다), **쓰는 파일 쉰은 한 글자도
안 고쳐지고 전부 통과**한다.

### 5.2 다만 — **그 근거를 드는 자는 없다**(퇴행은 아니다)

**변이 R6**: 픽스처가 `seedUser` 를 안 지나고 `hashPassword` + `insertUser` 를 직접 부르게 했다.
→ **74 파일 · 1454 케이스 전부 초록.** 근거는 **소스 글자로만** 서 있다.

**이것을 퇴행으로 치지 않는다.** 변경 전 머리말의 주장(*"라우트를 실제로 호출한다"*)도 같은
상태였다 — 픽스처가 몰래 `insertUser` 를 부르도록 바꿔도 죽는 케이스가 없었다. **상태가 안
바뀌었으므로 이 슬라이스가 만든 빚이 아니다.**

### 6.2 ✱ **구현자 보고의 수 하나가 틀렸다 — "import 하는 파일 28"**

| 무엇 | 구현자 | **내가 잰 값** |
|---|---|---|
| `helpers.ts` 에서 `signup` 을 **import 하는** 파일 | **28** | **53** |

**원인은 셈법이다.** `import { … } from './helpers'` 가 **여러 줄에 걸친** 파일이 **23개** 있다
(`pages.test.ts`·`restore.test.ts`·`ws-*.test.ts` 등). 한 줄짜리 grep 으로 세면 30, 여러 줄을
이어 세면 **53** 이다. 즉 **`signup` 을 든 `.test.ts` 53 개는 전부 그것을 import 한다.**

**그래서 보고 §1.1 의 설명 문장이 거짓이다:**

> *"28 과 53 의 차이는 `signup` 을 import 하지 않고 `createProject` 등 다른 픽스처만 쓰면서
> 주석·변수명에 그 낱말이 든 파일들이다."*

**그런 파일은 0개다.** 같은 문장이 **이월 장부 §3.11 에도 옮겨 적혀 있다** — 거기까지 고쳐야 한다.

## 8. 파라 7 — **D7: 기존 사용자로 로그인이 여전히 되는가**

**변경 전 코드가 만든 것과 같은 행을 만들어 로그인시켰다.**

먼저 **옛 경로가 무엇을 했는지 확정했다** — `git show 01de1a7:apps/api/src/routes/auth.ts` 의
`POST /signup` 은 두 줄이다:

```ts
const passwordHash = await hashPassword(body.password, scryptParams(config))  // {...DEFAULT_SCRYPT_PARAMS, N: 32768}
user = await insertUser(app.db, { email: body.email, name: body.name, passwordHash })
```

그리고 **그 두 함수의 파일이 이 브랜치에서 한 줄도 안 바뀌었다**(내가 쟀다:
`git diff 01de1a7..HEAD` 가 `auth/password.ts`·`repos/users.ts`·`db/tx.ts`·`config.ts` 넷에
대해 **0줄**). 그래서 같은 두 줄을 그대로 불러 만든 행은 **옛 라우트가 만든 행과 같다.**

| 무엇 | 기대 | 관측 |
|---|---|---|
| 그 행의 해시 | `scrypt$32768$8$1$…` | **`scrypt$32768$8$1$YVXas…`**(운영 비용 N) |
| 그 계정으로 로그인 | 200 | **200** |
| 그 계정으로 프로젝트 생성 | 201 | **201** |
| 그 계정을 프로젝트에 초대 | 201 | **201** |
| 없는 계정으로 로그인 | 401 | **401**(대조 — 하네스가 아무거나 200 을 내는 것이 아니다) |

**이 변경은 만드는 길만 없앴다.** (임시 파일은 만들고 지웠고 `git status` 가 그 자리에서
비었다 — §10.)

> 다만 구현자 보고 §5.5 는 *"원본을 `:ro` 로만 마운트했다"* 고 적는데 `:ro` 마운트는 mtime 을
> 안 바꾼다. **원인을 단정하지 않는다** — 코디네이터가 알아 둘 값으로만 적는다.
> (파일이 바뀌었다는 것이 데이터가 상했다는 뜻은 아니다. postgres 가 정상적으로 떴다 내려가도
> `pg_control`·`pg_wal`·`pg_stat` 은 갱신된다.)

### 12.3 워크트리 컨테이너 — **지웠다**

브리프가 *"끝나면 네가 지워라"* 라고 했으므로 `CLAUDE.md` 의 "워크트리 폐기" 절차대로
**컨테이너와 그 볼륨을 먼저** 지웠다(워크트리 디렉터리 자체는 코디네이터 것이라 안 건드렸다).

| 무엇 | 처리 | 확인 |
|---|---|---|
| 컨테이너 `feat-seeded-accounts-postgres-1` | `docker compose --env-file apps/api/.env down`(**`-v` 안 붙였다**) | `Stopped` → `Removing` → `Removed`, 네트워크도 제거. `docker ps -a` 에 seeded 이름 **0건** |

## 13. 병합 판정

### **병합 가능.**

**막는 것 0건.** 계획서가 확정한 D1~D7 이 전부 서고, 게이트 넷이 0이고, 문서의 거짓 문장이
고쳐졌고, 설계 문서는 안 고쳐졌다. **구현자 보고와 갈린 값은 둘이고 둘 다 수(數)이지 성질이
아니다**(§1 의 1448 → **1454**, §6.2 의 28 → **53**).

### 병합 전에 고쳤으면 하는 것 — **문서 두 줄** (막지는 않는다)

| 무엇 | 지금 | 고칠 값 |
|---|---|---|
| 보고 §1.1 의 표와 그 아래 인용 설명 · **이월 장부 §3.11** | *"import 하는 파일 **28**"* 과 *"28 과 53 의 차이는 … import 하지 않고 주석·변수명에 든 파일들"* | **53** 이고, **그런 파일은 0개다**. 여러 줄 import 23개를 한 줄 grep 이 놓쳤다 |
| 보고 §3·§8 · **이월 장부 §3.11** | api 케이스 **1448** | **1454** (`a3ba686` 이 더한 여섯이 빠졌다) |

### 이월 후보 — **코디네이터가 지금 닫을지 넘길지 고른다**

| # | 무엇 | 왜 | 닫는 값 |
|---|---|---|---|
| **가** | ✱ **가입의 부재를 드는 자가 글자에 묶여 있다** | 저장소가 세 곳에 *"계정을 만드는 길은 하나다"* 라고 적는데 그 문장을 드는 자가 없다. `/register` 로 되살리면 **1454 케이스가 전부 초록인 채** 계정이 생긴다(§2.3, 런타임 실증) | 소스 인구조사 한 줄(*"`src/` 에서 `insertUser` 를 부르는 파일은 `db/seed-user.ts` 하나다"*). `test/source-census.ts` 가 이미 있다 |
| **나** | ✱ **`migrate:down` 이 계정을 안 건드린다를 드는 자가 없다** | 문서 셋이 계약으로 적는데 산문뿐이다. `direction === 'latest' &&` 를 지우면 초록인 채 `down` 이 계정을 만든다(§7.2, 런타임 실증) | `shouldSeed(direction)` 로 빼고 케이스 한 줄, 또는 소스 인구조사 |

**전부 이 슬라이스가 만든 빚이 아니다** — **가**·**나** 는 새로 세운 성질에 자가 안 따라온 것이고,
