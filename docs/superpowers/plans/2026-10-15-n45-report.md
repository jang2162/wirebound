# N45 보고 — 실시간 프레임에서 `actor` 를 걷는다(L-114 · 사용자 결정 2026-10-15)

브랜치 `feat/n45-actor`(main `abddab06` 위). 게이트 `node -v` = **v24.21.0**. 장부 · `.ruler/` 는 안 고쳤다.

## 결과 한 줄

**방송 프레임 넷(`page-changed` · `restored` · `theme-changed` · `menu-changed`)에서 `actor` 를 걷었다** — 웹 파서를 먼저 풀고(커밋 `77b67100`) 서버에서 걷었다(`c635f8f7`). 기록(`revisions.actor_*`)과 이력 응답(`actorType` · `actorLabel`)은 그대로다. 읽는 자는 걷기 전에 두 방법으로 다시 세어 N24 와 같은 **6 줄 · 전부 파서**였다. 새 케이스 `apps/api/test/frame-no-actor.test.ts`(8)가 프레임 종류 × 입구마다 «`actor` 칸 없음 · 토큰 이름 없음» 을 잠그고, 변조 17 종이 전부 **값으로** 죽었다.

## 3. 걷은 자리

- **웹(`77b67100`):** `apps/web/src/realtime/protocol.ts` — `EventActor` 타입 · 세 프레임 타입의 `actor` 칸 · 필수 검증 3 곳(`isRecord(value.actor)`) · 옮겨 담기 3 곳. 파서 머리말에 «선언에 없는 필드는 옮기지 않고, 있다고 버리지도 않는다 — 옛 서버의 `actor`» 를 적었다. 주석 셋을 지금 참으로(`shell/remote-alert.tsx` «프레임은 누가 했는지 싣지 않는다» · `panels/comment-panel.tsx` 커밋 뒤에 도는 것 «셋 → 둘» · `test/realtime/protocol-parity.test.ts` 범위를 좁히는 예를 `ClientFrame` 으로). 웹 테스트 픽스처 16 파일 36 자리에서 `actor` 를 뺐다(서버가 보내는 프레임의 거울).
- **서버(`c635f8f7`):** `ws/protocol.ts`(`EventActor` · 네 프레임의 `actor` · `ServerFrame` 머리말에 «방송 프레임은 누가 했는지를 싣지 않는다» 한 절) · `ws/notify.ts`(입력 넷) · `auth/actor.ts`(`requestEventActor` 삭제 · «조작보다 먼저» 절을 지금 참으로 — 복원은 이제 `requestActor` 를 아예 안 부른다) · 호출 16 곳 · `ws/patch.ts` · 재생 재방송(`routes/comments.ts`)과 그것만 읽던 `repos/comments.ts` `PostRevision.actorType` · `actorLabel`(select 에서도 뺐다) · `services/tree-write.ts` 의 `runTreeTransaction` 이 `actor` 를 만들려고만 받던 `request` 인자(호출 8 곳).
- **문서:** 설계서 「7.4 LLM 편집 경로」 — `actor_type='mcp'` 표시는 revision 에 남고 실시간 프레임은 누가 했는지를 싣지 않는다. `apps/api/README.md` — 프레임 표 넷 · `theme-changed` 방송 줄 · 재생 표 · actor 절의 «프레임의 `actor`도 같은 값이다» 를 지금 참으로.
- **덤(`96b77902`):** `apps/api/test/pg-fault-proxy.ts` 의 `holdQuery` 설명에 «붙잡힌 질의는 칸을 비운다 …» 를 더했다. 인용한 케이스는 있다(`git grep -n holdQuery apps/api/test/n41-failure-recheck.test.ts` — 767 첫 붙잡기 · 772 둘째 붙잡기 · 773 첫 것 풀기). **브리프 문장 «붙잡힌 질의가 나가면 칸이 빈다» 를 코드에 맞춰 «붙잡는 순간 빈다(놓기 전에도)» 로 적었다** — `delayQuery`/`holdQuery` 의 칸은 질의를 붙잡는 자리(`pg-fault-proxy.ts` 의 `delay = null`)에서 비고, 그 케이스도 첫 것을 놓기 **전에** 둘째를 건다.

## 4. 케이스

- **서버 — 새 파일 `apps/api/test/frame-no-actor.test.ts`(8):** 쓰기는 토큰 + `x-wb-client: mcp`(WS `patch` 만 세션), viewer 가 받은 프레임에 `actor` 칸이 없고 프레임 JSON 어디에도 토큰 이름이 없다. revision 을 남기는 판은 이력에 토큰 이름이 남았는지를 카나리아로 함께 본다. 판: `PATCH …/ops` · `PUT …/schema` · 코멘트 게시 + 같은 키 재생의 재방송 · WS `patch` · 메뉴 + 페이지 생성(`menu-changed` 둘) · **COMMIT 답을 잃은 트리 쓰기가 확인 뒤 낸 신호**(`pg-fault-proxy` 의 `dropCommitReplyAfter`) · 테마 바인딩 저장 · 복원의 `restored` · `menu-changed` · `theme-changed`.
- **기존 단언을 고친 곳:** `ws-broadcast`(줄 삭제) · `ws-patch`(`actor.label` → `pageId` · `seq`) · `menu-changed` · `project-theme` · `late-commit-stale`(프레임 `toEqual` 의 기대에서 `actor` 를 뺐다 — 이제 `actor` 가 다시 실리면 이 셋도 값으로 죽는다).
- **웹 — `apps/web/test/realtime/protocol.test.ts`:** `'actor'` 행을 «필드가 없으면 버린다» 표에서 뺐다. 새 `it.each` 넷(`page-changed` · `restored` · `theme-changed` · `menu-changed`) — `actor` 없는 프레임을 그대로 읽고, `actor` 가 실린 옛 프레임(객체 · 글자 · `null`)도 같은 프레임으로 읽고 `actor` 를 안 옮긴다.
