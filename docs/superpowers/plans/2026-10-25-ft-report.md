# FT 보고 — 라벨|값 폼 표 — 1부(설계)

설계 문서: `docs/superpowers/specs/2026-10-25-form-table-design.md`. 이번 디스패치는 설계만 했다 — 코드 · 정본은 안 고쳤다. 기준 main `8769757a` · node v24.21.0 · 자기 DB 5501(설계라 안 썼다).

## 설계 요약

| 결정 | 이유 |
| --- | --- |
| 새 컴포넌트 `FormTable`(폼 표 · `title` · `columns` 1 ~ 4 · 기본 1 · 구역 «머리 오른쪽» · «옆 칸» · «칸») — `EntryForm` 은 그것을 품고, 새 입력폼은 몸통에 1쌍 폼 표(필드 셋)를 들고 선다 | 설계서 등록 화면은 «표 여럿 · 구역 제목 · 그리드 · 단추줄 하나» 다 — 표와 폼을 한 노드로 묶으면(가) 그 꼴이 안 선다. `Grid` · `KeyValue` 를 넓히는 길(다)은 범용 배치가 폼 규칙을 품거나 쌍이 노드가 아니다 |
| 칸 흐름 — 행은 노드가 아니다 · 자식의 몫 = 차지할 쌍 수 · 전폭은 몫 ≥ 열 수 | `SearchForm.columns` 와 같은 꼴 · 몫 · 자르기 · «몫» 칸이 이미 있다 |
| 빈 쌍은 뷰가 저절로 채운다 — 렌더러가 `ViewItem.span`(자른 몫)을 싣고 SDK `pairRows` 가 줄 끝 · 넓은 칸이 남긴 구멍에 `filler` 쌍을 끼운다 | 설계서의 빈 쌍은 거의 다 «칸이 모자란 오른쪽» — 걸음 0. CSS 만으로는 남는 트랙에 상자가 없다 |
| 라벨 칸 · 값 칸 = `Field` 의 `label` · `value` 조각 · 폼 표 안 `Field` 뿌리는 **CSS subgrid** 로 표의 두 트랙에 조각을 놓는다 | 3단계가 남긴 두 길 가운데 `display: contents` 는 뿌리 상자를 없애 외곽선 · 놓기 판정 · 마커를 깨고, 뷰가 나눠 그리는 길은 계약이 크게 바뀐다. subgrid 는 DOM · 뷰 계약 · 접근 이름이 그대로다 |
| `<table>` 이 아니라 격자 `div` + 이름 붙은 `group` | `Field` 뿌리가 `<tr>`/`<td>` 가 못 되고 값 칸에 그리드 · 하위 표가 든다 |
| «세로로 긴 라벨» 은 키 큰 행(장치 없음) · 진짜 rowspan(사진 칸)은 «옆 칸» 구역(Q3) | 분석에서 rowspan 이 사진 칸 한 곳뿐이다 |
| 열을 정한 검색폼도 같은 쌍 격자(라벨 왼쪽)(Q1) — 문서 모델이 이미 같아 옮길 것 없음 | 설계서 검색폼이 `라벨\|컨트롤\|라벨\|컨트롤` 다 |
| 표 밖 구역 제목은 폼 표 `title` + «머리 오른쪽»(Q4) | `List` 결과 머리줄 · `Card` 머리와 같은 꼴 · 표지 하나 |
| 좁은 창은 테마 몫 — 기본테마 640px 아래 한 줄에 쌍 하나 · 라벨 위 · 빈 쌍 숨김 · 옆 칸 위로 | 지금 좁은 창 규칙들과 같은 자리 |
| `accepts` 를 안 둔다 · lint `structural-gap` 에 폼 표 줄 · `LABEL_PROPS` · `/llms.txt` 영어 표 · SDK 1.6.0 · 기본테마 판 | 받는 규칙이 없어 부모를 바꾸는 입구를 다시 셀 일이 없다 |
| `0031` 이 입력폼 몸통의 잇단 필드를 폼 표로 감싸고 `head_seq` 를 올린다(Q2) | 감싼 뒤 옛 좌표가 다른 노드를 가리킬 수 있다(2단계 이월 «`head_seq` 안 올림» 이 여기서는 엉뚱한 노드를 고친다) |

### 설계 중 찾은 것 — 지금 main 에도 서는 결함(재현 안 함)

`--wb-node-weight`(몫 변수 — `packages/theme-sdk/src/root.tsx` 가 몫이 있는 노드 뿌리에 인라인으로 싣는다)는 `@property` 등록이 없어 **자손에게 상속된다**. 열을 정한 검색폼에서 몫 2 인 필드의 값 칸 조각(제 몫 없음)이 `flex: var(--wb-node-weight, 0 1 auto)`(`inputCssBlocks`)로 2 를 물려받아 늘어날 것이다. CSS 규칙으로 읽은 것이고 실브라우저로 재지 않았다 — 구현 차수의 첫 걸음으로 재현하고 `@property --wb-node-weight { syntax: '*'; inherits: false; }` 로 고치게 적었다(설계 «7» «몫 변수»). 폼 표는 전폭 행이 흔해 이 길이 자주 선다.
