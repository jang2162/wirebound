## 4. 판 올림 0.1.0 → 1.0.0 (admin)

판: `system-admin@0.1.0` 산출물을 옛 소스(`git archive 29bc91b7 system-themes/admin` — admin 트랙 병합 전 main)로 지어 sha256 이 체크섬 줄 `5ff20aed…` 와 같은 것을 확인하고, 스크래치 `SYSTEM_THEMES_DIR`(다섯 산출물 + 0.1.0)로 에디터 판을 띄움. 프로젝트를 `0.1.0` · 토큰 넷(`semantic.primary` `#ff5500` · `semantic.danger` `#aa0000` · `radius.md` `12px` · `radius.lg` `20px`)으로 고정하고, 없는 variant 대조군으로 목록 페이지 `List` 에 saas 의 `cards` · `Section` 에 `hero`(선언 안)를 달았다. 설정 페이지에서 «버전» 을 `1.0.0` 으로 → 확인 상자 → «바꾸기». 탐침: 스크래치 `rv-a6/p4-upgrade.test.ts`.
