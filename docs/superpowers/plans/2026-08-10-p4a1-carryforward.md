# P4a-1 이월 사항

`feat/p4a1-theme-engine`이 남긴 것. 계획은 `2026-08-09-p4a1-theme-engine-core.md`,
브랜치는 커밋 28개 · **1799 tests / 94 files** · typecheck·build 전부 통과다.

`packages/themes`가 생겼다. **화면도 서버도 없다** — 컴파일된 CSS를 쓰는 곳이 P4a-2, 저장이 P4a-3이다.

---

## 이 패키지가 하는 일

```
Theme(JSON) ──resolve──> ResolvedTheme ──emit──> CSS 문자열
                  ↑
            extends 병합 · 토큰 참조 풀기 · 화이트리스트 검증
```

- **`themes`는 `renderer`가 아니라 `schema`를 본다.** `ComponentDef`가 `structures`·`parts`·
  `variants`·`states`를 **선언**하므로 테마의 `components` 절을 그것만으로 검증할 수 있다.
  §3.3의 의존표가 지켜진다.
- **검증은 이슈로 내고 던지지 않는다.** `validatePage`와 같은 형식이고, 여러 이슈를 한 번에 낸다.
- **`Theme`(병합 결과)이 저장 대상이고, `ResolvedTheme`은 컴파일의 중간 산물이다.** 아래 2번.

---

## 다음 단계가 전제할 것

### 1. 미명세를 재서 정한 것 — 이제 계약이다

설계 §6이 답하지 않은 자리들이다. **바꾸려면 여기 적힌 근거를 먼저 반증해야 한다.**

| 무엇 | 정한 것 | 근거 |
|---|---|---|
| **토큰 참조 문법** | `scale.` 접두어는 **없다**(`space.6`·`radius.lg`) | §6.11의 `--wb-space-6`이 참조 경로를 역으로 증명한다 |
| **`space.unit` 파생** | 수치×배수. **단위 없는 값은 이슈** | `4px`·`0.25rem`·`1em`을 재서 |
| **브레이크포인트** | `max-width` · 값 그대로 · **폭 내림차순** | 폭을 넣어 겹침·틈을 쟀다. 순서가 곧 우선순위다 |
| **`states` 순서** | 문서 순서 | **정수형 키가 먼저 도는 갈래에 안 걸리는 것**을 재서 확인했다 |
| **`variants` vs `states`** | **`states`가 이긴다** | jsdom 캐스케이드로 쟀다 |
| **`null` 삭제** | 규격은 `null`을 안 받는다. **병합 지시로 보고 결과를 `ThemeSchema`가 검사** | 평행 규격을 만들지 않아 규격이 하나로 남는다 |
| **`bgGradient`·`bgImage`** | 프로퍼티별 함수 allowlist. **인자 안쪽도 검사, 중첩 함수는 이슈** | §6.8의 금지 이유(검증 가능·GUI 편집)를 둘 다 지킨다 |
| **패턴 `props`** | 카탈로그 zod로 검증한다 | §3.2가 카탈로그를 단일 진실로 못박았다 |
| **`assets.fonts`** | **`@font-face`를 내지 않는다** | P8이 URL을 다시 써야 하므로 지금 만들면 되돌려야 한다 |

### 2. 저장할 것과 컴파일할 것이 다르다 — **계획서 D2가 틀렸다**

계획서가 *"`ResolvedTheme`이 그 자체로 §4.5의 산출물이다"*라고 적었는데 **거짓이다.**

- **`ResolvedTheme`은 직렬화되지 않는다.** 다섯 절이 `Map`이라 `JSON.stringify`에서 전부 `{}`가
  되고, 되읽어 컴파일하면 던진다. `Map`을 쓴 것 자체는 옳다(순서가 계약이고 정수형 키 갈래를
  피한다) — **틀린 것은 그것을 저장 대상이라고 적은 문장이다.**
- **§4.5의 "병합된 결과"는 `mergeTheme`이 내는 `Theme`이다.** JSON 왕복이 바이트 동일이고
  되읽어 컴파일하면 `base + patch` 경로와 **같은 CSS**가 나온다.
- **그 성질은 병합 결과에서 `extends`를 뺀 뒤에만 성립한다.** 지닌 채 저장하면 그것은 여전히
  참조이고 복원이 그때의 base를 다시 요구해 **§4.5가 막으려던 일이 그대로 일어난다.**
  그래서 `mergeTheme`이 결과에서 `extends`를 뺀다.

> **유래는 파생 테마에 산다.** `extends`를 잃는 것은 **병합 결과**뿐이고, 편집되는 파생 테마는
> 그대로 지닌다. **산출물이 둘이고 서로 다른 일을 한다.**

### 3. 산출물이 오염되는 경로를 막았다

방출이 문자열을 만드는 순간 드러난 것들이다.

- **값이 CSS 블록을 깨고 나가던 것** — 열아홉 형태 × 열다섯 자리(285조합)로 재서 닫았다.
  **`</style>`이 특히 실재한다** — CSS 안에서는 유효하지만 HTML 파서가 스타일 블록을 끝내고
  나머지 CSS를 본문으로 흘린다(jsdom으로 확증: `sheet.cssRules`가 0이 된다). **P4a-2가
  `<style>`로 주입하므로 도달한다.**
- **홀수 따옴표가 자기를 무효화하던 것** — 밖으로 새는 것이 아니라 **시트 자체가 안 만들어진다.**
  중괄호만 세는 얕은 검사로는 안 잡힌다.
- **서로 다른 경로가 같은 변수 이름으로 접히던 것** — `blue.500`과 `blue-500`. **조용한 충돌은
  마지막 값이 이기고 아무도 모른다.**
- **프로토타입 키가 검증기를 죽이거나 표를 오염시키던 것** — 물려받은 이름 18개 × 층 17곳
  (306조합)에서 던진 입력 0 · 표 오염 0 · 과도 차단 0.

## P4a-2가 받을 것 (캔버스에 CSS 주입)

| 무엇 | 답해야 할 것 |
|---|---|
| **컴파일된 CSS가 실제로 먹히는가** | P0 이월 #7(구조가 inline style을 방출해 테마가 캐스케이드에서 진다)이 화면에서 어떻게 나타나는가. **`!important`는 쓰지 않았다** — 결함을 코드에 새기지 않기 위해서다 |
| **`assets.fonts`가 아무 데도 안 쓰인다** | 웹폰트가 로드되지 않는다(`font-family`는 나가므로 **시스템 폰트로 눈에 보이게 폴백**한다). 주입 시점에 폰트를 어떻게 싣는가 |
| **`url()`의 대상을 검증하지 않는다** | 외부 호스트·`data:` URI가 그대로 나간다. CSP가 무엇을 막는가 |
| **위험 문자 목록의 근거** | `<`·`>`를 막은 근거는 **jsdom으로 쟀고 실제 브라우저에서는 못 쟀다.** 대괄호·널·`@`는 깨지는 것을 관측하지 못해 막지 않았다 |
| **`bgGradient`와 `bgImage`가 같은 CSS 프로퍼티** | 한 스타일 맵에 둘 다 쓰면 `background-image` 선언이 둘 나간다 |
| **`@media`가 맨 뒤라 `responsive.base`가 `states`를 덮는다** | §6.5가 그 상호작용을 말하지 않는다 |
| **이슈 폭포** | 토큰 하나가 깨지면 그것을 가리키는 스타일마다 이슈가 따라 나온다 |

## P4a-3이 받을 것 (테마·레이아웃 저장)

| 무엇 | 답해야 할 것 |
|---|---|
| **`jsonb`가 문서 키 순서를 정규화한다** | **`states` 순서 계약을 저장이 지운다**(컨테이너에서 직접 쟀다 — `selected`/`disabled`가 뒤집힌다). 순서를 배열로 옮길지, 계약을 버릴지, `json`을 쓸지. `states`·`variants`·`parts`·`components`가 노출된다 |
| **어느 산출물을 어디에 저장하는가** | 파생 테마(편집용, `extends` 있음)와 병합 결과(스냅샷용, 홀로 섬)가 **둘 다** 저장되는가. **§4.2의 `themes` 테이블이 어느 쪽인가** |
| **`ResolvedTheme`을 저장하지 마라** | 직렬화되지 않는다. 저장 대상은 병합 결과 `Theme`이다 |
| **`meta.version`이 해석 대상이 아니다** | 형식을 강제하지 않았다(§4.5가 테마를 통째로 얼리므로 복원이 버전 비교에 기대지 않는다) |
| **깊이 상한** | `safeParse`가 깊은 트리에서 `success: false`가 아니라 **던진다.** 경계는 그 순간 스택의 것이라 **여기서 잰 수를 옮겨 적을 수 없다** |

## 어느 쪽도 아닌 것

- **패턴 슬롯 타입이 노드 타입과 대조되지 않는다** — §16이 슬롯 타입 체계를 열어 뒀다.
  대응표를 지으면 P4b가 정할 것을 앞지른다.
- **한 슬롯을 노드 둘이 쓰는 경우**가 정해져 있지 않다.
- **§6.11의 `--wb-container-max`** — 규격 경로 `container.maxWidth`에서 **어느 규칙으로도
  나오지 않는다.** 예시의 축약으로 보고 설계 문서는 고치지 않았다 — **P4b가 판정.**
- **§6.6 예시의 `Grid.props.gap`** — 카탈로그가 `gap`을 선언하지 않아 예시가 이슈가 된다 —
  **P4b가 판정.** 곁들여 **'테마 어휘 ∩ 노드 props'가 실재한다**: `Flex`의 `direction`·`align`·
  `justify`·`wrap`, `Divider`의 `direction`, `Placeholder`의 `height`. 경계가 깔끔하지 않다.
- **프로퍼티별 이름공간 제한이 없다** — `bg`·`zIndex`가 `space.6`을 받는다. 지금 있는 규칙은
  `palette` 직접 참조 금지뿐이다.
- **점이 든 이름의 경로 손실** — `tokens.palette.blue.500`에서 이름의 끝을 경로로 알 수 없다.
- **브레이크포인트 값 중복** — 두 이름이 같은 폭을 가리키면 `@media`가 둘 나간다.
- **`TOKEN_FUNCTIONS`·위험 문자 목록이 손으로 적혔다** — `oklch` 같은 계열 밖 표기는 이슈다.

## 이 사이클에서 배운 것

### 설계 문서의 예시가 **네 번** 규격과 어긋났다

`bgGradient`/`bgImage` vs 함수 금지 · `Grid.props.gap` · `--wb-container-max` ·
`scale.` 접두어. **어느 것도 코드로 옮겨지기 전에 물어서 잡혔다.**

> **판정 원칙이 섰다: 규격이 이기고 예시가 틀린 것으로 본다.** 예시는 아무도 실행하지 않는다 —
> 이 프로젝트가 계속 겪은 *"산문은 아무도 재지 않는다"*와 같은 부류다.

### *"재지 못했다"*가 정직했지만 **재는 수단이 이미 있었다**

구현자가 *"jsdom은 캐스케이드를 계산하지 않으므로 이 패키지가 잴 수 없다"*(계획서 D9의 문장을
그대로)고 적었는데, **리뷰어가 워크스페이스에 이미 있던 `postcss`·`jsdom`을 프로브로 써서
실측했다.** 그 뒤 구현자가 같은 방법으로 재라 #7까지 실측으로 바꾸고 **거짓이 된 문장 둘을
걷어냈다.**

> **"못 쟀다"고 적기 전에 무엇으로 잴 수 있는지 한 번 더 보라.** 테스트에서만 쓰는 프로브는
> 런타임 의존이 아니다.

### 같은 측정이 **세 번 뒤집혔다**

깊이 한계: 리뷰어 주장 → 구현자 반증 → 리뷰어 철회 → **구현자가 자기 결론도 무너뜨렸다**
(같은 프로세스에서 두 번째 측정에 경계가 두 배 가까이 올랐다).

**P2b-4의 JIT 예열 관측과 같은 부류다.** 결론은 같다 — **절대값을 계약에 적지 않는다.**
지금 남은 문장은 *"`safeParse`가 던진다"*와 *"깊이 상한은 그 순간 스택의 것이다"* 둘뿐이고,
그것이 세 라운드를 살아남은 전부다.

### 수정 커밋이 새 거짓을 만들지 않은 것이 **두 웨이브 연속**

이 프로젝트에서 처음이다(P2b-4 1차 수정에서 넷, P2b-5에서 둘). 웨이브 1 수정 열넷 중 0,
웨이브 2 열여섯 중 0. **X를 심어 Y를 관측하고 쓰는 것이 실제로 작동한다.**

### 구현자가 리뷰 범위를 넓힌 것이 **다섯 번 더**

F1의 갈리는 이름 여덟 → 열둘 · F3 경로 여덟 → 아홉 · F7 다섯 · F8 여덟, 그리고
**리뷰어의 "병합 결과가 왕복한다"가 바이트까지만 참**이라는 것(base 없이 해석하면 실패한다).

**리뷰 지적을 그대로 받아 적지 말라는 규칙의 근거가 또 쌓였다.**

### 계획서가 확정해 적은 산문이 또 반증됐다

**D2**(`ResolvedTheme`이 저장 대상이다)와 **D9**(jsdom은 캐스케이드를 계산하지 않는다) 둘.
**"재라"로 넘긴 자리는 매번 걸렸고, 확정해 적은 것은 구현 중에야 드러났다.**
