## 4. 새 이월 · 지침 보고

- **N25-3(정보)을 새 행으로 안 올렸다.** N25 보고가 새 이월로 적은 것 — `edit-lost-commit` «한도 끝에서» 케이스가 `slowCommit` 950ms 와 `LOST_COMMIT_PROBE_MS` 1000ms 사이 50ms 틈에 기댄다. 코디네이터가 확정한 새 이월 목록(N24-1~4 · N25-2)에 없어 L-260 행의 값에 적었다. 새 행이 필요하면 코디네이터가 판단한다. N25-1(L-261 을 고치라는 이월)은 이 갱신이 L-261 을 닫아 반영했다.
- **지침 보고 — 장부 (a) 의 다시 세는 명령은 상태 칸에 `|` 가 있으면 그 행을 놓는다.** 장부 (a) 「다시 세는 명령」 문장 끝에 한 문장을 더하면 좋다: «행의 칸 안에는 `|` 를 쓰지 않는다 — 상태별 세기(`grep -cE "\| 열림[^|]*\|$"`)가 그 행을 놓는다.» (이 갱신은 내 두 행에서 `|` 를 걷어 해결했고 문장은 안 더했다 — 장부는 시점 기록이라 코디네이터 판단에 맡긴다.) 셸 반복문에서 쓸 때 zsh 는 `$k[^|]` 를 첨자로 읽어 `bad math expression` 을 낸다 — `${k}` 로 쓴다.
- **지침 보고 — `docker` 가 PATH 에 없다.** 브리프가 이미 알려 준 `/opt/homebrew/Cellar/docker/*/bin/docker` 로 해결했다 — 문서 쪽 조치는 없다.
- **띄운 것.** 자기 Postgres 컨테이너 `feat-n26-ledger-postgres-1`(5528, 이미 떠 있었음 — 그대로 둠). dev 서버 · vitest · chromium 프로세스는 없다(끝에 `ps` 로 확인).
