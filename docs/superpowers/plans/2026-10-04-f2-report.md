# F2 보고 — 노드 별칭 · 구조 트리 줄 요약

브랜치 `feat/f2-alias`(main `ef0d7b32` 위). spec `docs/superpowers/specs/2026-10-04-tree-alias-guides-design.md` · 계획 `docs/superpowers/plans/2026-10-04-f-tree-alias-guides.md` 「F2 태스크」.

## 요약

- 노드에 선택 필드 `alias`(앞뒤 공백 없는 한 줄 1 ~ 60자 — 봉투 `WbNodeSchema` 가 본다)를 더했고, 노드를 부르는 이름 하나(`nodeDisplayName` → `describeNode`)가 별칭을 읽어 문장 · 대상 고르개 · 코멘트 · 내보낸 설계서 · CLI `page get` · MCP `get_page` 가 함께 따라간다.
- 고치는 자리 넷 — 속성 패널 맨 위 «별칭» 칸 · 트리 줄 더블클릭 · F2(트리 · 캔버스) · 줄 `…` «별칭 바꾸기». 편집 하나(`add` · `replace` · `remove` `/…/alias`)라 되돌리기 · 방송 · 잠금이 지금 길 그대로다.
- 구조 트리 줄은 `타입 (별칭) 요약`(요약은 흐림 · 한 줄 줄임표)이고 **접근 이름도 같은 글**이다(코디네이터 답 «A»). 줄 행동 토글 이름은 줄 글 전체 + «추가» · «더 보기».
- 스크린숏에서 결함 둘을 찾아 고쳤다 — 긴 별칭이 든 상호작용 대상 고르개가 우측 패널 밖으로 나감 · 속성 제목 · 상호작용 머리 · 문장이 긴 한 낱말 별칭에서 패널 밖으로 나감.

커밋(차례): `3bde927b` schema · `0f877552` api 케이스 · `af02a3ea` 고치는 자리(web) · `dc20839f` 트리 줄 글 + 찾기 옮김 · `4f5f0b36` 이름 짓는 자리 · `30776c10` 실브라우저 · `0b5732c2` 패널 넘침 고침 · `909bdefa` 문서 · `57a76aa7` 실브라우저 기존 케이스 셋 옮김.

## 태스크마다 — 무엇 · 케이스 · 변조

변조는 모두 백업(경로 전체 이름) → 한 곳 치환(맞은 수 1 확인) → 그 태스크의 케이스 파일만 돌림 → `cmp` 복원. 실패 수는 그 케이스 파일들의 것이다.

### 지침 보고

1. **도구 입력이 숨은 글자의 이스케이프를 날글자로 푼다.**
   - 무엇이 틀렸나: 이 세션에서 파일 쓰기 도구의 내용과 셸 heredoc 안의 `\u2028` · `\u202a` ~ `\u202e` · `\u200b` 같은 이스케이프가 날글자로 파일에 들어갔다(일부만 — `\u007f` 는 안 풀렸다). 정규식 리터럴 안의 날 U+2028 은 구문 오류이고, 케이스 · 문서에는 눈에 안 보이는 방향 제어 글자가 섞인다. 변조 스크립트의 찾는 글자가 날글자가 되어 맞은 수 0 으로 두 변조가 안 돌았다(맞은 수 확인이 잡았다). 커밋 전에 바뀐 파일의 숨은 글자를 세어 이스케이프로 되돌렸다 — `git diff --name-only main HEAD` 의 파일에서 이번에 든 날 숨은 글자 0(남은 것은 리뷰 문서의 인용 7 · F2 원래 케이스 `packages/schema/test/node-alias.test.ts` 의 U+2028 1).
   - 어느 문서 어느 절: `CLAUDE.md` 「검증」 — 새 절.
   - 넣을 문장: «**숨은 글자(제어 · 방향 제어 · 폭 없는 글자 · 서로게이트)를 이스케이프로 쓴 파일은 쓴 뒤 바이트로 센다** — 도구 입력 층이 `\uXXXX` 를 날글자로 풀어 쓰는 판이 있다(정규식 안의 U+2028 은 구문 오류 · 케이스와 문서에 안 보이는 방향 제어 글자). 커밋 전에 바뀐 파일에서 그 글자 범위를 파이썬으로 세고, 0 이 아니면 이스케이프로 되돌린다. 스크립트로 넘길 때는 `chr(92) + 'u2028'` 처럼 글자 조합으로 짓는다.»
2. **jsdom 의 접근 이름은 안쪽 요소마다 공백을 끼운다.**
   - 무엇이 틀렸나: jsdom 은 UA 기본 `display` 를 계산하지 않아(빈 글) dom-accessibility-api 가 inline 아닌 자식 앞뒤에 공백을 끼운다 — 단추 안에 `<bdi>` · `<span dir="auto">` · `<i>` 를 넣으면 jsdom 이름이 `Flex ( 머리 줄 ) 가로` 로 Chrome(`Flex (머리 줄) 가로`)과 갈린다. 앞뒤가 공백인 조각은 공백이 겹쳐 안 보일 뿐이다.
   - 어느 문서 어느 절: `CLAUDE.md` 「메인 세션은 디스패치·판정·병합만 한다」의 «jsdom 은 좌표 · 상속 계산도 없다» 문단 끝.
   - 넣을 문장: «**jsdom 은 UA 기본 `display` 도 없다** — 접근 이름 계산이 안쪽 요소 앞뒤에 공백을 끼워, 이름이 든 단추 안에 새 인라인 요소를 넣으면 jsdom 이름만 Chrome 과 갈린다. 그 요소의 UA 기본값을 `apps/web/test/setup.ts` 에 둔다(지금 `bdi`) — node 환경 파일에는 `document` 가 없으니 가드한다.»
