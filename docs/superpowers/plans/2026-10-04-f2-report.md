# F2 보고 — 노드 별칭 · 구조 트리 줄 요약

브랜치 `feat/f2-alias`(main `ef0d7b32` 위). spec `docs/superpowers/specs/2026-10-04-tree-alias-guides-design.md` · 계획 `docs/superpowers/plans/2026-10-04-f-tree-alias-guides.md` 「F2 태스크」.

## 요약

- 노드에 선택 필드 `alias`(앞뒤 공백 없는 한 줄 1 ~ 60자 — 봉투 `WbNodeSchema` 가 본다)를 더했고, 노드를 부르는 이름 하나(`nodeDisplayName` → `describeNode`)가 별칭을 읽어 문장 · 대상 고르개 · 코멘트 · 내보낸 설계서 · CLI `page get` · MCP `get_page` 가 함께 따라간다.
- 고치는 자리 넷 — 속성 패널 맨 위 «별칭» 칸 · 트리 줄 더블클릭 · F2(트리 · 캔버스) · 줄 `…` «별칭 바꾸기». 편집 하나(`add` · `replace` · `remove` `/…/alias`)라 되돌리기 · 방송 · 잠금이 지금 길 그대로다.
- 구조 트리 줄은 `타입 (별칭) 요약`(요약은 흐림 · 한 줄 줄임표)이고 **접근 이름도 같은 글**이다(코디네이터 답 «A»). 줄 행동 토글 이름은 줄 글 전체 + «추가» · «더 보기».
- 스크린숏에서 결함 둘을 찾아 고쳤다 — 긴 별칭이 든 상호작용 대상 고르개가 우측 패널 밖으로 나감 · 속성 제목 · 상호작용 머리 · 문장이 긴 한 낱말 별칭에서 패널 밖으로 나감.

커밋(차례): `3bde927b` schema · `0f877552` api 케이스 · `af02a3ea` 고치는 자리(web) · `dc20839f` 트리 줄 글 + 찾기 옮김 · `4f5f0b36` 이름 짓는 자리 · `30776c10` 실브라우저 · `0b5732c2` 패널 넘침 고침 · `909bdefa` 문서 · `57a76aa7` 실브라우저 기존 케이스 셋 옮김.

## 태스크마다 — 무엇 · 케이스 · 변조

변조는 모두 백업(경로 전체 이름) → 한 곳 치환(맞은 수 1 확인) → 그 태스크의 케이스 파일만 돌림 → `cmp` 복원. 실패 수는 그 케이스 파일들의 것이다.
