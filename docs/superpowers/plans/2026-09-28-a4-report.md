- kit 빌드의 작성자 코드 `process.env.NODE_ENV` 갈래는 셸의 값으로 풀린다(`2edb611e` 에서 치환을 안 잰 장치로 걷었다) — NODE_ENV 로 가르는 픽스처를 세운 뒤 `define` 을 넣을 것.
- 테마 토큰이 바뀌어(`theme-changed`) 테마의 `transition` 이 노드를 옮길 때 외곽선 · 마커는 전이가 끝난 뒤 다시 재지 않는다 — 이번 멈춤은 link 시트가 새로 실릴 때만 선다. 재는 케이스가 없다.
- 에디터 머리의 아이콘 · 하단 바 · 머리 폭 표 — C. 멤버 관리 · 프로젝트 삭제를 설정 페이지로 옮기는 것.
