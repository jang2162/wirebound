# TP 보고 — 테마 패턴 기능 제거

브리프: `.worktrees/.coord/brief-tp.md` · 공통 `common-w4.md`. 기준 main `a091b5a9`, 브랜치 `feat/no-theme-patterns`.

## 바꾼 것

**걷은 것.** 테마 manifest 의 `patterns`(구성 레시피 · `PatternNode` · `<범주>.<변형>` 이름 · 전개 `expandPattern`)와 그것을 쓰는 길 전부.

| 층 | 걷은 것 |
|---|---|
| `packages/themes` | `spec/patterns.ts`(규격 · `checkPatterns` · `checkNewPatterns`) · `pattern/expand.ts` · `issue.ts`(`ThemeIssue` — 패턴 이슈 전용이었다) · `index.ts` 의 export 열하나 · manifest 이슈 코드 `'pattern'` · `newManifestIssues` · `readNewWbtheme`(빈 껍데기가 되어 부르는 곳 둘 — 업로드 라우트 · `wb-theme build` — 을 `readWbtheme` 로 옮김) |
| `packages/theme-sdk` | `ThemeManifest.patterns` |
| `packages/theme-kit` | `check` 의 `undeclaredVariantsUsedByPatterns`(보고 필드 · 문구 · `ok` 판정 · `UndeclaredPatternVariant` export) · 스타터 `SKILL.md` 의 「패턴」 절과 표 줄 |
| `packages/schema` | `ignoredVariantMessage` 의 공개 export(패턴 검사와 문장을 나누려고 냈던 것 — 이제 `validate.ts` 안에서만 쓴다) · 패턴을 가리키던 주석 |
| `apps/web` | `palette/theme-patterns.ts` · `edit/pattern-insert.ts` · «모듈» 탭의 «테마 패턴» 묶음(카드 · 빈 줄 · 전개 · 표본) · `module-insert.ts` 의 `kind: 'pattern'` 갈래(묶음 타입 `ModuleBundle` 도 걷고 `nodes` 를 바로 받는다) · 주석(`paste-ops` · `structure-actions` · `structure-drop` · `shell.css`) |
| 문서 | 정본 설계서 §6.2 통째 · §2 · §3 · §4 · §5 · §6.0 · §9 «하단 판의 탭» · §11.1 · §14 · §15 · §16 의 패턴 줄, `apps/api/README.md` 의 `manifest` 이슈 줄 · 모듈 절, `.ruler/AGENTS.md` 의 `packages/themes` 설명 |

**더한 것.** `validateManifest` 가 맨 위의 `patterns` 키를 모양 검사 앞에서 짚어 `{ code: 'shape', path: 'patterns', message: PATTERNS_RETIRED }`(«patterns 는 더 지원하지 않습니다 — …») 로 거절하고, 그 키를 뺀 나머지로 모양 검사를 이어 이슈를 한 번에 모은다(`packages/themes/src/manifest/schema.ts`).

화면: 하단 판 «모듈» 탭은 «개인 모듈» · «프로젝트 모듈» 둘이다.

## 결정과 이유

- **거절은 `validateManifest` 한 곳이다** — 빌드 · 업로드 · 저장된 패키지의 다시 읽기(내보내기 · 시딩 · CLI lint)가 모두 그것을 지난다. «아는 키가 아니면 거절» 은 `ManifestSchema` 가 엄격 객체라 이미 서 있지만 그 문장(«알 수 없는 키») 은 까닭을 모른다 — 그래서 모양 검사 앞에서 그 키 하나만 짚는다. 과거 호환은 고려하지 않으므로(브리프) `patterns` 를 실은 옛 패키지는 다시 읽기에서도 거절된다.
- **`readNewWbtheme` 은 걷었다** — `readWbtheme` 에 더하던 검사(`Page` 가 든 패턴)가 유일한 차이였다. 공개 표면 계약(`packages/themes/test/public-api.test.ts`)에서도 뺐다.
- **`ignoredVariantMessage` 는 함수로 남기고 export 만 걷었다** — `validatePage` 가 쓴다. 공개했던 까닭(패턴 검사와 문장을 글자까지 맞춤)이 사라졌다.
- **`module-insert` 의 묶음 타입을 걷었다** — 갈래가 하나 남은 판별 유니온은 빈 껍데기라 `nodes` 를 바로 받는다.

## 잰 값

**기본테마 `.wbtheme` 바이트 — 그대로라 판을 올리지 않았다.** 고치기 전 산출물(`system-admin-1.2.1.wbtheme` · 5379 바이트 · sha256 `3712cd2a…5fc4` — `checksums.json` 의 1.2.1 줄과 같다)을 스크래치에 떠 두고, 고친 뒤 `pnpm -r --filter '@wirebound/system-theme-admin...' build`(theme-sdk · schema · themes · renderer · theme-gallery · theme-kit · admin 순 — 새 `themes/dist` 에 `readNewWbtheme` · `expandPattern` 0 건)로 다시 지어 `cmp` 했다 — 바이트가 같다. 기본테마 manifest 에 `patterns` 가 없었고(`system-themes/admin/src/manifest.ts`) `theme.js` 는 SDK 의 타입만 바뀌어 번들이 같다. `checksums.json` 은 고치지 않았다.
