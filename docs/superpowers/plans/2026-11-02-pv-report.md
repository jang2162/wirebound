브랜치 `feat/theme-preview` · 기준 `88c4505d` · 계획 `docs/superpowers/plans/2026-11-02-theme-preview-and-project-cards.md` 트랙 P.

## 바꾼 것

### P1 · 그룹 격자

- `@wirebound/theme-gallery` 가 `GalleryLayout`(`list` · `grid`) · `GalleryGroup` · `galleryGroups` 를 낸다. `ThemeGallery` 의 `layout` 없으면 `grid`.
- 격자: 그룹마다 `section[data-wb-gallery-group]` · 머리 `[data-wb-gallery-group-label]`(이름 · 칸 수) · `repeat(auto-fill, minmax(min(320px, 100%), 1fr))` · 간격 16px. 칸 표지 `data-wb-gallery-item` 그대로.
- `wide: true` 를 단 표본(28): `DataGrid` 8 · `GridColumnGroup` · `GridColumn` · `GridRow` · `GridCell` 각 1 · `Pagination` 3 · `KeyValue` 1 · `SearchForm` 3 · `EntryForm` 1 · `FormTable` 4 · `FileAttach — 셋 · 긴 이름` · `Popup — 검색 팝업` · `Popup — 폼 팝업`. 차례 · 첫 표본은 그대로(팔레트 축소판).

### P2 · 예제 페이지

- `packages/theme-gallery/src/examples/documents.ts` — `EXAMPLE_LAYOUT`(왼쪽 메뉴 `Link` 둘 + `Button` «주문 등록» · 머리 · Slot) · `EXAMPLE_PAGES`(대시보드 · 주문 목록 · 주문 상세 · 주문 등록) · `EXAMPLE_POPUPS`(주문 삭제). 타겟은 `page:주문 관리/<제목>`. 노드 id 접두 `ex-l` · `ex-d` · `ex-o` · `ex-od` · `ex-of` · `ex-pd`(문서 사이 겹침 0 을 케이스가 잰다).
- `packages/theme-gallery/src/examples/theme-examples.tsx` — `ThemeExamples`: `renderComposed` 로 그리고, `navigate` → `onPageChange`, `openModal` → `usePopupStack().push`(`popupOpener` · `galleryAssetUrl`), `closeModal` → `pop`. 없는 타겟 · 겹 초과 · 닫을 팝업 없음은 뿌리 위 한 줄(`[data-wb-examples-notice]`, `role="status"`). 뿌리의 `onClick` 이 `a[href]` 누름의 기본 동작을, `onSubmit` 이 제출을 막는다. 장(`page` prop)이 바뀌면 팝업을 걷고 겹layer 를 처음 판으로.
- 처음 쓴 판의 «이동 때 `stack.clear()`» 줄은 변조로 살았다(장 바뀜 이펙트가 같은 일을 한다 · 같은 장으로 가는 이음은 문서에 없다) — 걷었다.

### P3 · 웹 — 토큰 탭 · 넓은 미리보기 · 두 보기

- `settings/token-editor.tsx` — 무리(`groupsOf` 그대로)가 `role="tablist"`(«토큰 무리») 의 탭이다. 안 고른 탭의 칸은 지우지 않고 `hidden`(반쯤 친 값이 남는다). 탭 줄 오른쪽에 «전부 기본값으로» · «토큰 저장». 사유가 든 무리의 탭은 접근 이름이 `<무리> — 고칠 칸 있음` 이고 오류 색 점이 선다. ← → · Home · End 로 옮긴다(설정 절 탭과 같은 말투).
- `settings/theme-preview.tsx` — 머리에 `role="radiogroup"`(«미리보기 보기») 라디오 «컴포넌트» · «예제 페이지», 예제일 때 `nav`(«예제 페이지») 장 단추 넷(`aria-current="page"`). 보기 · 장은 부품 상태(토큰을 고쳐도 남는다). iframe 폭은 상자 안쪽 폭(`clientWidth` − 좌우 여백)을 `ResizeObserver` 로 재어 넘긴다(못 재면 640). 팝업 구간은 캔버스의 `usePopupArea(frame, 1, 예제 보기)`.
- 관리자 › 테마(`routes/admin-themes.tsx`)는 이미 같은 `ThemePreview` 를 토큰 없이 쓴다 — 소스를 안 고쳤다.
- `shell.css`(`.wb-shell-settings-*` 묶음 안만): `.wb-shell-settings-tokens` 를 세로로, 탭 줄 · 탭 · 칸 격자(`minmax(min(240px, 100%), 1fr)`) · `[hidden]` 규칙, 미리보기 머리 · 보기 전환 · 장 단추. 틀의 `sticky` 를 걷었다(세로 배치에서 붙을 자리가 없다). 쓰는 곳이 0 이 된 `.wb-shell-settings-token-group` · `.wb-shell-settings-legend` 를 걷었다(`git grep` 0).
- 기존 `token-editor.test.tsx` 의 넷(«무리 차례» · «반쯤 친 값» · «기본값으로» · «422»)은 칸을 찾기 전에 그 탭을 고르는 걸음(`openTab`)만 더했다 — «무리 차례» 는 `legend` 대신 탭 글을 견준다.

- **실브라우저가 찾은 결함 — 팝업이 창 밖에 섰다.** 미리보기 상자가 창 아래로 뻗은 판(1440×900 · 토큰 칸 밑)에서 예제 상세의 «삭제» 가 연 팝업이 상자의 가운데 = 창 밖에 서서 «취소» 를 못 눌렀다(playwright `click` 이 30s 동안 «`main` intercepts pointer events»). 캔버스의 `usePopupArea`(`canvas/canvas-popups.tsx`)가 보이는 구간을 스크롤 상자만으로 셈해서다 — 상자와 창(뷰포트)이 겹친 곳으로 고치고, 상자의 조상이 굴러도 다시 재도록 호스트 문서의 `scroll` 을 캡처로 듣는다. 캔버스 칸은 늘 창 안이라 캔버스에는 같은 값이다.
- `apps/web/build-test/theme-preview.test.ts`(새로 · 실브라우저 5): «한 화면» · «폭을 따라간다» · «뒤로» · «팝업이 보이는 구간에 선다» · «좁은 창». 첫 판은 «뒤로» · «팝업이» 둘이 빨강이었다 — 앞은 위 결함, 뒤는 판 카나리아(1280×640 에서 상세 장 379px 이 상자 403px 에 들어 구를 자리 0 — 창을 320 으로 낮췄다).
