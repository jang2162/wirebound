## 결정

1. **예제 장의 문서 안 틀(`ex-l-*`)은 남겼다** — `q-lt.md` Q1, 코디네이터 답 «기본값대로». 레이아웃 뷰가 없는 테마(2.1.0 포함)에서는 SDK 기본 레이아웃 뷰가 내용만 그려, 걷으면 미리보기 · dev 예제의 왼쪽 메뉴 · 머리가 사라진다. 걷기는 기본테마가 레이아웃 뷰를 내는 T9 몫(그때 GNB · LNB 와 문서 안 메뉴가 겹친다).
2. **SDK 는 schema 에 기대지 않으므로 `PageLayout` · `LayoutNavItem` 을 따로 적었다** — 두 값이 갈리면 `LayoutFrame` 의 `Same<SchemaPageLayout, PageLayout>` 이 `pnpm typecheck` 에서 걸린다(양방향). `LayoutNavItem` 은 구조가 같아 schema 의 `buildLayoutNav` 결과를 그대로 넘긴다.
3. **`LayoutRegion` · `LayoutLink` 는 `LayoutFrame` 밖에서 던진다**(`Zone` 과 같은 자세). 선언 밖 id 의 `LayoutRegion` 은 켠 것으로 그리고 kit 가 경고한다.
4. **`LayoutLink` 는 `href` 없는 호스트에서도 `<a href="#">` 로 그리고 누름에서 기본 동작을 막는다** — `href` 없는 `<a>` 는 링크 역할이 아니다. `aria-current="page"` 는 페이지 항목에만(조상 메뉴의 `current` 는 뷰가 제 마크업으로 쓴다).
5. **`LayoutFrame` 의 영역 입력은 «끈 id 목록»(`hiddenRegions`)이다** — 호스트가 맵을 짓지 않고 선언을 렌더러가 읽어 `regions` 를 짓는다(선언 밖 id · `toggle: false` 는 끄라고 해도 안 든다). T6 의 `hidden_regions` 를 그대로 넘기면 된다.
6. **뷰가 던진 틀은 겉 상자에 `data-wb-error` 를 단다** — `wb-theme check` 의 폴백 셈이 줍고 화면에도 남는다. 노드가 아니라 `data-wb-id` 는 없다.
7. **kit check 의 넷째 검사(«틀의 배치 규칙이 형제 구조로 안 가른다»)는 짓지 않았다** — kit 은 노드 뷰 CSS 의 형제 셀렉터도 안 본다(기본테마는 `system-themes/admin/test/admin.test.ts` 가 따로 센다). 늘리려면 CSS 파서가 든다 — «남은 것».
8. **SKILL.md 는 `isolateBidi` 대신 `<bdi>` 를 권한다** — 작성자 프로젝트는 SDK 만 싣고 `@wirebound/schema` 가 없다.
9. `wb-theme dev` 의 체크는 서브페이지 선언의 끌 수 있는 영역만 띄운다 — 예제 장이 모두 서브페이지다.

3. **메뉴 밖 페이지 판의 이름** — 정본상 메뉴에 안 든 페이지는 없지만(`pages.menu_node_id` NOT NULL), 막 만들어 트리가 아직 안 온 페이지 · 트리 조회 실패 판이 같은 꼴이라 그 판을 잰다(문장은 브리프대로 «메뉴 밖 페이지 판»). 정본 · 설계에는 «트리에 없는 페이지의 내비» 로 적었다.
4. **F2 는 `LayoutLink` 의 `<bdi>` 가 아니라 이름 값 자체를 가둔다** — SDK 는 schema 에 기대지 않아 `isolateBidi` 를 못 부르고, `<bdi>` 는 `LayoutLink` 기본 글만 막는다(뷰가 `item.title` 을 한 글로 이어 붙이면 뚫린다). 이름을 짓는 자리(`buildLayoutNav` · `LayoutFrame`)에서 가두면 `LayoutLink` · 이어 붙인 글 · 제목이 다 막히고, 제어 글자가 없는 이름은 글자 그대로라 DOM 꼴이 안 바뀐다. `LayoutFrame` 을 부르는 자리(갤러리 예제 · kit check · kit dev — `git grep -n "LayoutFrame\b" -- 'packages/**/src/**' 'apps/**/src/**'`)는 모두 `buildLayoutNav` 의 내비를 넘긴다 — 기본 레이아웃 뷰(내용만)는 이름을 안 그린다.
5. **F5 는 토큰을 걷는다** — 템플릿의 뷰는 SDK 기본 뷰를 옮긴 것이라(`pack-template.ts`) 템플릿 쪽에서 `useToken` 을 쓰게 하려면 SDK 기본 뷰를 바꿔야 하고, select 토큰을 CSS 로 읽을 길은 스타일 질의뿐이다.
