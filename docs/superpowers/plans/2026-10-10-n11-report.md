## `CLAUDE.md` 에 넣은 문장 (코디네이터가 사용자에게 보고할 것)

- **L-161** — 절 «경주를 재는 케이스는 두 요청이 겹친 판만 센다» 끝: «**두 사람의 겹침을 세울 때 한 사람이 조상(상태 영역 등)을 고른 채 남이 그 안을 고치는 판은 겹치지 않는다** — 고른 것의 잠금이 서브트리를 쥐어 남의 편집이 그 잠금이 풀릴 때까지(29.3s) 기다린다. 열어 둔 확인 상자 아래의 문서 변경은 같은 사람의 다른 탭(REST)으로 세운다(`apps/web/build-test/view-states-review.test.ts` H3).»
- **L-162** — 절 «서로 다른 연결로 가는 두 메시지의 도착 순서에…» 끝: «**REST 로 서버 값을 기다린 뒤 키를 누르는 케이스는 ack(WS)가 아직 안 닿은 판을 낸다** — 되돌리기 단추 · 화면 같은 상태를 기다린 뒤 누르거나, `startDownDelay` 판을 따로 세운다.»
- **L-163** — 절 «변이마다 전량을 돌리게 하지 않는다…» 안, «배경 탐침을 띄운 채 케이스를 돌리지 않는다.» 뒤: «**부하판은 api 를 뺀 프로젝트로 겹친다**(`pnpm vitest run --project unit --project web …`) — `pnpm test` 셋을 겹치면 한 워크트리의 테스트 DB 를 셋이 내렸다 올려 api 가 깨진다.»
- **L-164** — 같은 절 끝: «**게이트가 시간 상한 케이스 하나(`ws-lock-cost` 의 max < 100ms 등)로 빨강이면** 그 파일을 혼자 세 번 돌려 값을 적고 게이트를 한 번 다시 돈다 — 두 판 다 보고에 적는다.»
