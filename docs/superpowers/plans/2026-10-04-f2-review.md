### 봉투 · 클립보드 · 화면 (schema 탐침)

| 입력 | 봉투 | 클립보드 봉투 읽기 | 화면이 보내는 것(`aliasOps`) |
|---|---|---|---|
| 61자 · 이모지 61 | 거절 | 무시(`null`) | 60자에서 자름 |
| 빈 글 · 공백만 · BOM 만 | 거절 | 무시 | 안 보냄 / `remove` |
| 앞 공백 · NBSP 앞 | 거절 | 무시 | 걷어 보냄 |
| 줄바꿈 · 탭 · CR · U+2028 · ESC | 거절 | 무시 | 공백으로 |
| 숫자 · `null` · 배열 | 거절 | 무시 | — |
| C1(U+0085 · U+009B) | **받음** | 받음 | 그대로 |
| U+200B 만 · RLO · RLI | **받음** | 받음 | 그대로 |
| 외짝 서로게이트 | **받음** | 받음 | 그대로 |
| `<script>` · `</script><script>` | 받음 | 받음 | 그대로 |

- **거절 · 정규화가 입구마다 같은가(I1):** 서버 입구는 모두 같은 봉투(`WbNodeSchema`)를 불러 같은 값을 거절한다. 화면의 두 칸(속성 «별칭» · 트리 입력)은 둘 다 `aliasOps` 로 정규화한다. 클립보드는 «봉투 아님»과 같은 `null` 이라 통지 없이 무시한다(다른 틀린 노드와 같은 길 — `readNodesEnvelope` 머리말). 테마 패턴은 `PatternNodeSchema` 가 `strictObject` 라 별칭 키를 실으면 manifest 가 거절되고, 전개(`pattern/expand.ts`)도 별칭을 옮기지 않는다 — spec 의 «별칭이 함께 가는 곳»에 패턴은 없다. «한 입구는 걷고 다른 입구는 거절»해서 같은 문서가 길에 따라 다르게 저장되는 판은 없다 — 화면은 서버가 거절할 값을 안 보내고, 서버는 어느 입구든 같다.
- **옛 문서 · 별칭 문서 읽기:** 옛 문서(별칭 없음)는 봉투의 `optional` 로 그대로 지난다. 별칭 문서는 api GET · 스냅샷 복원 · exporter(`packages/exporter/dist` — 실브라우저 탐침의 내보내기) 에서 별칭째 읽혔다. MCP `get_page` 는 보고의 `packages/mcp/test/read-tools.test.ts` 케이스가 갖는다(다시 재지 않음).

### R3 — 외짝 서로게이트 → 500

- **값:** 위 표 — 다섯 입구 500, 응답 본문 `{"error":{"code":"internal",…}}`, 저장 안 됨(뒤 GET 200 · 문서 그대로).
- **원인:** 봉투 `AliasSchema`(`packages/schema/src/envelope.ts`)가 짝 없는 서로게이트를 안 본다(`[...value].length` 는 외짝도 한 글자로 센다). Postgres `jsonb` 가 `\ud800` 이스케이프를 거절해 쓰기에서 죽는다 — `apps/api/src/db/nul-guard.ts` 가 NUL 만 400 으로 옮기고 서로게이트는 안 본다.
- **원래 길:** `props.label` 의 같은 값이 같은 다섯 입구에서 500(대조 줄). 별칭은 그 길을 물려받았다.
- **화면이 내는가:** `aliasOps` 는 코드 포인트로 잘라 짝을 안 쪼갠다 — 친 글이 외짝이 아니면 화면이 외짝을 짓지 않는다.
- **고칠 방향:** 봉투 별칭 규칙에 `value.isWellFormed()`(또는 `/\p{Surrogate}/u`)를 더하고, 넓게는 `nul-guard` 옆에 문서 전체의 외짝 서로게이트를 400 으로 옮기는 가드를 둔다(라벨 몫은 이월).

### R4 — C1 · 보이지 않는 글

- **값:** `a\u0085b`(NEL) · `a\u009b31mb`(CSI) · `​`(폭 없는 공백만) 이 봉투 · 화면 · 서버 다섯 입구를 지난다(위 표). U+200B 만인 별칭은 트리 줄에 `Button () 저장` 꼴로 빈 괄호를 남긴다(`nodeAlias` 는 `trim` 으로 걷지 못한다).
- **원인:** 봉투 `ALIAS_BREAKING` 과 화면 `ALIAS_BREAKING`(`apps/web/src/edit/ops.ts`)이 둘 다 `[\u0000-\u001f\u007f  ]` — C1 이 빠졌다. 보고 · 머리말의 «제어 문자 거절»과 어긋난다.
- **원래 길:** 라벨 · 제목은 이 거름도 없다. 다만 CLI `page get` 은 별칭을 터미널에 그대로 찍는다(C1 을 해석하는 터미널이면 그 글자가 출력 제어가 된다 — 이 기계에서는 안 쟀다).
- **고칠 방향:** 두 `ALIAS_BREAKING` 에 `\u0080-\u009f` 를 더한다(한 집합을 schema 에서 내보내 웹이 읽게 하면 두 벌이 안 갈린다). 폭 없는 글자만인 별칭은 «걷은 뒤 보이는 글자가 없으면 빈 값»으로 볼지 정한다.

## 2. 편집 연산 · 잠금 · 되돌리기

### 잠금 판정 (`lockConflictOfOps`, 남 = bob)

| bob 이 잠근 노드 | `/root/alias` | `/root/children/0/alias`(Card) | `/root/children/0/children/0/alias`(Card 안 Button) |
|---|---|---|---|
| Card | 통과 | 막힘 | 막힘 |
| Card 안 Button | 통과 | **통과** | 막힘 |
| Page(뿌리) | 막힘 | 막힘 | 막힘 |

`add` · `remove` 가 같은 값이다. 잠긴 노드 자신 · 자손은 막히고 조상은 통과한다 — `props` 편집과 같은 규칙(`property-panel.tsx` 의 `blocked` 머리말 표 «잠긴 노드의 조상 200 / 막는다»). 화면은 조상을 **고르지** 못해(`selectionConflicts` — 자손이 잠긴 Card · Page 를 고르면 bob 의 잠금이 돌아온다) 조상의 별칭 칸 · F2 · 더블클릭에 닿지 않는다. 서버만 받는 «조상 별칭»은 props 와 같은 «선택이 편집보다 엄격하다»의 대가다 — 새 구멍이 아니다.

### R2 — 트리 입력이 사라진 노드를 기억한다

**판(실브라우저 · 같은 사람의 다른 탭 = alice 세션의 REST):**

| 판 | 입력 | 하단 바 | 서버 · 편집 |
|---|---|---|---|
| F2 · `지움 중` 침 → 다른 탭이 그 노드 `remove` | 사라짐 · `activeElement` = `BODY` | 빈 글 | 편집 0 — 친 글이 말없이 사라짐 |
| 이어 다른 탭이 같은 id 로 그 노드를 `add`(되돌리기 꼴) | **다시 선다** — `value: ""` · `focused: true` | 빈 글 | — |
| F2 · `옮김 중` 침 → 다른 탭이 그 노드를 다른 부모로 `move` | 새 자리에 다시 서며 `value: ""`(친 글 잃음) · 포커스는 그 입력 | 빈 글 | Enter → 편집 0 |

같은 판의 속성 칸은 `DROPPED_DRAFT_NOTICE` 를 말한다(위 표) — E2 의 «친 글을 남은 노드에 쓰거나 버린다고 말함»이 트리 입력에는 안 선다.

- **원인:** 입력이 서는 조건이 «그 줄의 id = `useAliasEdit().nodeId`»(`panels/structure-tree.tsx` 의 `StructureNode` — `open && row.alias.nodeId === node.id`)이고, 그 상태(`panels/alias-edit.tsx`)는 `close()` 로만 비워진다. 노드가 문서에서 빠지면 `StructureNode` 가 내려가며 `TreeInput` 도 내려가지만 `onCancel` 이 안 불려 `nodeId` 가 남는다 — 같은 id 의 줄이 다시 그려지는 순간(되살림) 입력이 `initial` 로 새로 서고 포커스를 가져간다. 다른 부모로 옮기면 `StructureNode` 가 새로 마운트돼 `TreeInput` 의 상태(친 글)가 `initial` 로 돌아간다. 메뉴 «이름 변경»은 입력이 **선택**에 붙어(`menu-tree.tsx` 의 `RowPanel` — 고른 것이 사라지면 트리 아래로 옮겨 선다) 이 꼴이 아니다.
- **닿는 사람:** 남은 그 노드를 못 지우고 못 옮긴다(423 · 줄 단추 꺼짐). 같은 사람의 다른 탭 · 같은 계정 토큰의 MCP 에이전트 · 소유자의 스냅샷 복원이 닿는다(복원은 재지 않았다).
- **고칠 방향:** 입력을 «열린 노드가 지금 문서에 있고 고른 노드와 같다»일 때만 그리고, 그 노드가 문서에서 빠지면 상자를 닫으며 친 글이 있으면 하단 바에 `DROPPED_DRAFT_NOTICE` 와 같은 한 줄을 세운다. 친 글은 `TreeInput` 밖(상자)에 들어 옮김의 재마운트를 견디게 한다.

### 남의 화면 · 내보낸 설계서

F2 로 고친 별칭이 bob 의 트리 줄 · 상호작용 문장에 서고 되돌리기 한 번에 돌아오는 판은 보고의 실브라우저 케이스(`apps/web/build-test/node-alias.test.ts` «F2 로 고친 별칭이 …»)가 갖는다 — 다시 재지 않았다. 내보낸 설계서는 서버 문서를 그대로 읽는다(렌더 탐침의 내보내기에서 별칭이 상호작용 목록 · 코멘트 탭에 섰다).

### R1 — bidi 제어 글자가 뒤따르는 글을 뒤집는다

- **값:** RLO 별칭의 뒤 글 두 글자의 화면 x(논리 차례 첫째 → 둘째).

| 자리 | 첫째 x | 둘째 x | 뒤집힘 |
|---|---|---|---|
| 트리 줄 `Button (a‮b) 저장하기` 의 `저장` | 136 | 124 | 예 |
| 상호작용 문장 `① a‮b 클릭 시 ④ …` 의 `클릭`(머리 · 목록 두 줄, 1440) | 1388 · 1379 | 1377 · 1368 | 예 |
| 내보낸 HTML 상호작용 목록의 `클릭` | 1364 | 1352 | 예 |
| RTL 별칭(제어 글자 없음) 뒤의 `클릭` | 1218 | 1230 | 아니오 |

  스크린숏(`.coord/rv-f2/out/render/crop-sentence.png` · `crop-tree2.png`): 문장이 `① a<1=tih__=rorreno x=crs gmi> ④ 시 릭클 b 다니집겨숨 가<tpircs/>…` 로, 트리 줄이 `Button (a기하장저 (b` 로 보인다 — 뒤집힌 것은 그 별칭 뒤의 **다른 노드 이름**(④ 의 별칭)과 문장 끝까지다.
- **원인:** 별칭 · 요약 · 이름이 들어가는 자리에 bidi 격리가 없다 — 트리 줄의 `.wb-shell-structure-alias` · `.wb-shell-structure-summary` 는 평범한 인라인 `span`(인라인 요소 경계는 embedding 을 끝내지 않는다), 문장은 `describeNode` 의 결과를 글 하나로 잇는다(`packages/schema/src/interaction/describe.ts`). 봉투도 Cf 글자(U+202A ~ U+202E · U+2066 ~ U+2069)를 안 막는다.
- **새 길 / 원래 길:** 문장 · 내보낸 목록은 라벨(`readLabel`)이 이미 같은 글을 싣는다 — 원래 길. **트리 줄은 이 트랙에서 처음 사람 글(별칭 · 요약의 라벨 · 제목)을 싣는다 — 새 길**이고, 그 글은 라벨로도 들어온다.
- **무게:** 낮음 — 일부러 제어 글자를 넣어야 한다. 다만 결과가 남의 화면 · 내보낸 설계서(넘겨줄 산출물)의 문장을 바꿔 보인다(규칙 «높음 = 남의 화면»의 경계 — 코디네이터 판정).
- **고칠 방향:** 화면은 별칭 · 요약 조각과 문장 안 이름을 `<bdi>`(또는 `unicode-bidi: isolate`)로 감싸고, 글로만 나가는 자리(CLI · MCP · PPTX)는 `describeNode` 가 이름을 U+2068 … U+2069 로 감쌀지 정한다. 또는 봉투 · 화면이 별칭의 bidi 제어 글자를 거절 · 걷는다(라벨은 이월).
