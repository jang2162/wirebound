## 결정과 이유

1. **R-4a 는 «칸마다 정적 라우트» 로 저절로 안 풀렸다 — 뼈대가 경로를 보고 접는다.** RV-WS 는 «칸마다 라우트를 달면 컴포넌트가 갈린다» 고 적었지만, 넷이 같은
   틀(`AdminScreen`)을 같은 `Outlet` 자리에 그려 React 가 재조정으로 뼈대를 이어 갔다 — 정적 라우트만 단 판에서 skip 을 뗀 실브라우저 값은 그대로 `expected 'true' to
   be 'false'` 였다. RV-WS 가 «고칠 방향» 으로 적은 꼴(`pathname` 만 본다 — `location.key` 는 검색 칸의 `replace` 마다 바뀐다)으로 고쳤다. 렌더 중에 고친다(이펙트면
   새 화면이 펴진 채 한 번 그려진다). 칸마다 `key` 를 다는 길은 버렸다 — 다음에 같은 꼴을 쓰는 화면이 또 빠뜨린다.
2. **계약 대조** — 합친 코드(`apps/api/src/routes/admin-*.ts` · `repos/*`)와 계획 «API 계약» 이 다른 칸은 owner 넘기기의 서버 파라미터 이름(`:id`) 하나였다(브리프가
   짚은 것 — HTTP 경로는 같아 웹은 바꿀 것이 없다). 응답 꼴 넷 · 쓰기 응답 · 기록 질의는 계약 그대로였다. `POST /invites` 의 `expiresInDays` 는 서버에서 선택(기본 7)이지만
   화면은 늘 싣는다(상자의 기본값이 7).
3. **확인 상자는 셋** — 비활성화 · 관리자 해제(그 사람이 만든 링크를 거둔다) · 초대 링크 거두기. 지정 · 다시 활성화는 곧바로 보낸다(되돌릴 수 있다 · 기록에 남는다).
   모달(`ShellDialog`)이고 확정은 상자 바닥 오른쪽이다 — 줄 «…» 의 항목 자리와 다른 곳에 서서 «첫 단추 자리에 바꿔 그리기» 가 아니다. 그래도 실브라우저 더블클릭을
   쟀다(«잰 값» 3).
4. **새 링크는 모달이 아니라 칸 위의 상자(`LinkReveal`)다** — 만들기 상자를 닫는 Escape 한 번에 원문을 잃지 않게, 만들면 상자를 닫고 그 칸의 위에 링크를 둔다. 원문은
   그 부품의 props(상위의 상태)에만 있다 — 저장소 · 주소 · 콘솔 0(jsdom · 실브라우저 둘 다 잰다). 화면을 떠나면 사라진다고 문장이 말한다.
5. **검색 · 거름은 칸의 상태다(주소에 안 싣는다)** — 프로젝트 목록과 달리 뒤로 가기로 돌아와 남길 까닭이 약하고, 주소에 실으면 한글 조합 · 바깥 변경 따라가기(FX-WS
   R-5a 의 장치)를 칸 넷에 또 지어야 한다.
6. **좁은 창(< 900px)에서 줄이 카드가 된다** — 칸마다 `data-label` 을 `::before` 이름표로. 문턱 900 은 사이드바 232 + 여백 64 를 빼고 칸 일곱(사용자)이 서는 폭이다.
   표 머리는 숨긴다(이름표가 그 몫).
7. **만들기 상자의 폼은 `noValidate`** — 만료 칸의 `max=90` 이 브라우저 검사로 제출을 막아(jsdom 도 같다) 화면 문장이 안 섰다. 범위는 화면 문장 하나로 말한다.
8. **«이름은 멤버일 때만 링크»** 는 내 프로젝트 목록(`listProjects`)의 id 로 가른다 — 관리자 응답에 내 멤버십이 없다. 목록을 못 받으면 링크를 하나도 안 단다(열리지 않는
   링크를 달지 않는다). 넘기기가 성공하면 목록을 다시 받아 자기에게 넘긴 프로젝트가 링크가 된다.
9. **비활성화 상자의 «마지막 활성 owner 인 프로젝트 수» 는 상자를 열 때 `listAdminProjects` 로 센 미리보기다** — 활성 owner 가 그 사람 하나인 프로젝트. 서버가 커밋
   뒤에 센 `ownerlessProjects` 가 정본이고 결과 한 줄은 그 값을 말한다.
10. **자기 줄의 «…» 에는 «재설정 링크 만들기» 만 있다** — 서버가 자기 비활성화 · 해제를 409 로 막는다. 자기 재설정 링크는 서버가 받으므로 남겼다.
11. **기록의 사람 거름에 «서버 명령» 이 없다** — 서버 질의(`actorId`)가 uuid 만 받는다. 행동 거름(관리자 지정 · 해제)으로 그 줄을 찾는다.
12. **`.role` 가드 · 소유자 비교 자는 넓히지 않았다** — 관리자 화면은 `.role` 을 안 읽고(판정은 세션 사용자의 `isInstanceAdmin` 하나), 자기 줄 판정은 `user.id === me?.id`
    다(`one-verdict` 의 `userId ===` 꼴이 아니다 — 잠금 판정이 아니다). 두 자 다 그대로 초록.

## 잰 값

1. **초대 → 가입 → 비활성화(Chrome)** — 관리자가 화면에서 만든 «여러 명» 링크의 칸 값으로 로그인 안 한 컨텍스트가 가입 → `/` 의 목록. 이브를 멤버로 넣고 에디터를
   연 뒤(실시간 `joined` 1) 관리자가 확인 상자로 비활성화 → 이브의 탭이 15s 안에 `/login`(WS 닫힘 ≥ 1). 결과 한 줄 «거둔 링크 0개 · … 0개.». 원문은
   `localStorage` · `sessionStorage` · 주소에 없다.
2. **재설정 링크(Chrome)** — 관리자가 만든 링크를 로그인 안 한 컨텍스트(창 390)가 열어 바꿈 → `/login` 의 «비밀번호를 바꿨습니다 — 새 비밀번호로 로그인하세요» ·
   옛 비밀번호 401 · 새 것 200 · 같은 링크를 다시 열면 공통 문장(«이 재설정 링크는 더 쓸 수 없습니다 …»). AC 가 jsdom 만 둔 링크 화면 둘의 실브라우저 판이다.
3. **더블클릭(Chrome)** — 줄 «…» 의 «비활성화» 를 `dblclick`: 상자만 열리고 600ms 뒤 서버 요청 0 · DB 그대로. 상자의 확정을 `dblclick`: 요청 1.
4. **넘침(Chrome)** — 창 390 · 720 · 721 · 900 · 1000 · 1920 × 칸 넷 = 24 판, 띄어 쓰지 않은 긴 이름 · 긴 이메일 · 긴 링크 이름 · 긴 프로젝트 이름을 실은 판에서
   문서 넘침 0 · 뼈대 상자 넘침 0 · 창 밖 글자 노드 0(센 글자 노드 17 – 73). 시각 상자의 꺾인 줄 최댓값: 카드 꼴(390 · 720 · 721) 1 · 표 꼴 900 · 1000 에서 2(날짜 / 시각),
   1920 에서 1. 원문 값은 실행 로그의 `[admin-screens 넘침]` 줄.
5. **R-4a(Chrome)** — 정적 라우트만 단 판: `expected 'true' to be 'false'`(빨강 그대로 — «결정» 1). 경로 접기 뒤 초록.
