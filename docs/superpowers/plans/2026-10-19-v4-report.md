### 4. 프로젝트 설정 — `84ad5c69`

- **왼쪽 세로 탭**(`role="tablist"` «설정 절» · `aria-orientation="vertical"`) — 일반(`projectSettings`) · 테마(`themes`) · 멤버(새 열쇠 `members` = Users) · 위험 구역(`warning`). 창 < 900 에서 위 가로 줄(넘치면 줄 안에서 가로 스크롤).

- 키보드: 로빙 `tabIndex` · ↑↓(←→ 도) · Home · End · 끝에서 돈다 · 고르면 포커스도 옮긴다(선택이 포커스를 따른다).
- **판 넷을 늘 그리고 안 고른 것은 `hidden`** — 탭을 옮겨도 저장 안 한 초안 · 친 값 · 열린 확인이 남는다(한 화면이던 때 잃지 않던 것). 조회도 지금처럼 화면을 열 때 절마다 한 번.
- 위험 구역 탭은 owner 에게만 — 판정은 절 파일이 내보내는 `dangerShown(project)`(안의 `projectAbilities(…).remove` 그대로). 라우트 파일에 `.role` 읽기를 더하지 않았다(역할 가드의 경로 목록 불변).
- «테마» 절: **지금 테마 요약 카드**(그림 · `이름 id@판` 한 글 · «바꾼 토큰 N / M개» · «새 버전» 알약) → **«테마 바꾸기»**(owner · 고르개 그대로) → **«토큰»**(무리마다 카드 | 미리보기). 미리보기는 바깥 틀(`.wb-shell-settings-preview-frame` — `sticky` · `max-height: calc(100vh - 32px)` · 좁은 창(< 960) `max-height: 60vh` · `static`)이 높이를 쥐고 안쪽 상자가 스크롤한다. **60vh 를 고른 값으로 적는다**(코디네이터 덧붙임) — 창 900 이면 540px.
  - 틀을 따로 둔 까닭: 안쪽 `.wb-shell-settings-preview` 는 «문서를 감싸는 상자»라 `test/shell-css-guard.ts` 의 `WRAPPER_PROPERTIES` 밖 속성(`top` · `max-height` · `border` …)을 못 건다. 허용 목록을 넓히지 않고 틀을 더했다.
- 바꾼 기존 케이스(탭 판 안의 절을 찾게): `test/settings/{members-section,theme-chooser,token-editor,danger-section}.test.tsx` 주소에 `?section=` · `danger-section` «맨 아래 절» → «목차의 마지막 탭 · 주소로 열린다» · «editor/viewer 에게는 절째 없다» 는 숨은 판까지(`hidden: true`) 없음을 잰다 · `project-abilities-wiring` 의 `dangerOpen` 은 탭이 있으면 눌러 본다 · `members-section` 강등 케이스는 «일반» 탭을 눌러 본다.
- 테스트 도우미: `test/helpers.tsx` 위치 탐침에 `data-search`(질의)와 `currentSearch()` — `currentPath()` 는 그대로.

2. **관리자 미리보기 폭** — 갤러리 문서 폭이 640 고정(`settings/theme-preview.tsx` 의 `PREVIEW_WIDTH`)이라 창 900 · 700 에서 상자 안 가로 스크롤이 선다(문서 넘침은 0). 넓은 창에서는 오른쪽이 빈다. 폭을 상자에 맞출지는 미리보기 뜻(«이 폭에서 어떻게 보이나»)의 결정이다.
