- 내어쓰기: 자리 G 마다 `[P]`, P 의 구역마다 `[x(T)]` — P × 구역 × T 전부. 편집은 `outdentSelected` 와 같은 꼴(부모 자리 + 1).
- 편집 전 문서에 error 문제가 있으면 센다만 하고 뺀다. **오라클은 서버 6단계** — 편집 뒤 문서의 `validatePage` error 문제(`ISSUE_SEVERITY`)가 0 이면 서버가 받는다.
- 화면 판정은 `structureAbilities` 의 `indent` · `outdent`(새 · `0d301bbb` 사본).

## 지침

1. **무엇이 비었나:** «놓은 뒤 화면 자리» 를 지키는 장치를 재는 판이 «놓기가 난 판» 만 세웠다(FX-ZE «L1» 은 넣기만 · 그만둔 끌기는 Escape 만). 미리보기가 선 채 놓기가 편집 없이 끝나는 판(뗀 좌표의 답 없음 · 보인 답 아님 · `onDrop` 의 거절)에서 옮기기가 원래 노드로 굴렸다. **어디:** `.ruler/30-delegation.md` 의 «L1 놓은 뒤 · 끌기를 그만둔 뒤 화면이 튀는지는 …» 을 FX-ZE 지침 2 가 넣을 자리의 바로 뒤(아직 안 들었으면 «스크롤바를 누르는 판은 이 기계(macOS)의 헤드리스 Chrome 에서 기본으로 못 잰다 …» 문단 뒤). **넣을 문장:** «**놓기 뒤의 화면 장치는 «놓기 없이 끝난 끌기» 를 끝마다 잰다 — Escape 만이 아니라 미리보기가 선 채 편집 없이 끝난 뗌도** — 뗌이 마지막 움직임에서 문턱 밖이면(CDP `Input.dispatchMouseEvent` 의 `mouseReleased` 를 움직임 없이 다른 좌표에) 다시 물은 답이 `null` 이라 편집 0 인데 미리보기는 서 있다. 옮기기 · 넣기를 따로 세운다 — 옮기기는 미리보기가 베낀 원래 노드가 늘 문서에 있어 «놓인 노드» 로 읽힌다(`docs/superpowers/plans/2026-10-23-rv2-ze-report.md` N1).»
2. **무엇이 비었나:** 캔버스 칸의 스크롤을 «몇 번 고쳤나» 로 재려면 `scroll` 이벤트는 한 프레임에 합쳐져 쓰기 수가 안 나온다. **어디:** 같은 파일 같은 자리. **넣을 문장:** «**스크롤 장치가 «한 번» 굴리는지는 `scroll` 이벤트가 아니라 그 스크롤 요소에 건 `scrollTop` setter 로 센다** — 이벤트는 프레임마다 합쳐진다. 요소에 `Object.defineProperty(el, 'scrollTop', { get, set })` 로 `Element.prototype` 의 서술자를 감싸 쓰기마다의 변화량을 모으고, 0 쓰기(다른 자리가 같은 값을 다시 씀)는 장치를 뗀 판에도 서는지로 가른다(`docs/superpowers/plans/2026-10-23-rv2-ze-report.md` 2).»
