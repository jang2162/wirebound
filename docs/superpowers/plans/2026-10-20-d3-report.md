## 고치지 않은 것 · 못 잰 것

- **「테이블 정의」 의 나머지 누락** — `comments.idempotency_key` · `comments.revision_seq` · `layouts.created_at` 칸과 표 셋(`comment_tombstones` · `page_seq_floors` · `project_menu_revs`)이 없다. 문장이 거짓은 아니고(정본이 모든 칸을 싣는다고 하지 않음) 결정 문서가 정본에 싣기로 한 것이 아니라 두었다. `page_seq_floors` 의 뜻은 「스냅샷」 이 글로 말한다. 다시 세는 법: `apps/api/src/db/types.ts` 의 `export interface *Table` 과 정본 「테이블 정의」 블록을 견준다.
- **「패키지 구조」 의 누락** — `apps/playground` · `packages/test-support` 가 그림에 없다. 개발 · 테스트 전용이라 거짓은 아니다.
- **「설계서 화면 구조」 «대화 상자» 단락** — 네 상자(스냅샷 · 프로젝트 내보내기 · 페이지 가져오기 · 메뉴 삭제)만 든다. `<ShellDialog` 를 그리는 파일은 여섯이다(`git grep -ln '<ShellDialog' -- apps/web/src` — 더해 `save-module-dialog.tsx` · `remove-state-dialog.tsx` · `shell/shortcut-help.tsx`). 단락의 행동(연 자리로 포커스 · 연 자리가 사라졌으면 메뉴 트리의 고른 줄로 등)이 그 셋에도 서는지 실브라우저로 안 쟀다 — 고치지 않았다.
- **「컴포넌트 정의 구조」 의 `defineComponent` 예** — 실제 `ListDef` 는 props 에 기본값 · 상태 prop 넷 · `summary` 가 더 있다. 예시 스케치라 두었다.
- **행동 서술(§7 실시간 · §9 포커스 · 키 · Chrome 잰 값 1078 / 945 / 858 / 687 등)** — 이름 · 상수 · 오류 코드만 셌고 행동은 실브라우저 · 서버로 다시 재지 않았다(문서 전용 트랙이라 dev 서버를 띄우지 않았다). 위 표의 «맞음» 은 «이름 · 수가 코드에 있다» 의 뜻이다.
