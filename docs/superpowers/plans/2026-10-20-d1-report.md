## 못 잰 것

- **README 머리의 측정 환경 줄(«macOS 26.6.1 · Node 22.23.1 · pnpm 10.0.0 · Docker 29.5.2»)** — 이 점검은 Node 24.21.0(`mise.toml`)으로 쟀다.
  문서의 다른 «이 기계에서 쟀다» 값을 전부 다시 재지 않았으므로 환경 줄을 바꾸면 그 값들이 Node 24 에서 잰 것처럼 읽힌다 — 그대로 뒀다.
- **도커 동작 측정**(포트 충돌 뒤 다시 친 `up` 이 포트 없이 뜸 · 볼륨 복사 절차 · `docker start` 재바인딩 · Colima 의 호스트 프로세스 판) — 남의
  컨테이너 · 포트를 건드리는 판이라 안 쟀다. 문서가 든 문장의 근거 파일(`docker-compose.yml` 머리말)과는 맞다.
- **`pnpm link --global` 갈래**(「부르는 길이 둘이고」 ㉯ · 되돌리기 표) — 기계의 전역 상태를 바꾼다.
- **`claude mcp add` · `.mcp.json` 승인**(「MCP 서버 등록」) — 이 세션의 호스트 설정을 바꾼다. MCP 의 «`.wirebound.json`을 찾을 수 없습니다» 문장은 소스로만 봤다.
- **playwright 설치 크기 · 시간**(「넣는 법」 표) · **배포 판의 잰 값**(「올린 판에서 잰 값」 · 「화면 그리기 상한」 메모리 표) · **pty 절차**(재설정 ·
  막힘 풀기의 «재는 법») — 이미지 빌드(2분 반) · 브라우저 내려받기 · pty 하네스가 드는 측정이라 이 트랙에서 다시 안 쟀다. 상수 · 문장 · 파일 이름은 소스와 맞다.
- **스타터 README 의 «Node 22 이상»** — Node 22 판으로 돌려 보지 않았다(kit · sdk tarball 에 `engines` 가 없다).
- **drag-debug 의 «줄 모양» 표본** — 실브라우저 케이스(`apps/web/build-test/drag-debug.test.ts`)를 안 돌렸다. 단계 · 까닭 값은 소스(`DropMiss` · `EndWhy` · `.line(` 호출)와 전부 맞다.
