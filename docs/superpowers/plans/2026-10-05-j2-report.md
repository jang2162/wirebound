## 표지 규칙

**화면을 바꾸는 불리언 · enum prop 가운데 상태(`data-wb-state`) · 변형(`variantFrom` → `data-wb-variant`)으로 실리지 않는 것 전부에
prop 표지를 싣는다.** 불리언은 참일 때 `data-wb-<prop>=""`(거짓이면 없음), enum 은 늘 `data-wb-<prop>="<값>"`. 상태가 참이면 루트에
`aria-disabled` · `aria-busy`(loading) · `aria-invalid` · `aria-required` 가 `"true"` 로 선다. 정본 `docs/superpowers/specs/2026-08-03-wirebound-design.md`
「노드 속성」 에 지금 참인 것으로 적었다.

- **싣는 자리는 SDK 다 — 렌더러가 아니다.** `view()` 가 노드의 `nodeId` · `type` · `props` · `states` 를 문맥(`ViewNodeContext`)으로 내리고
  `Root` 가 편다(`packages/theme-sdk/src/marks.ts` · `root.tsx`). 렌더러의 노드 속성 계약(`WbAttrs` · `contract-attrs.test.ts`)은 그대로다.
  기본 뷰 · 테마 뷰 · 스타터 템플릿 뷰가 모두 `view` · `Root` 로 짜여 있어 표지를 빠뜨릴 수 없다 — 이미 배포된 테마 번들도 공유 런타임의
  SDK 를 부르므로 `theme.js` 를 다시 짓지 않고 표지를 얻는다(번들 build-test 로 확인).
- **`Root` 는 제 노드 id 의 문맥만 읽는다** — `view()` 를 거치지 않은 맨 함수 뷰의 `Root` 가 부모 노드의 표지를 잘못 펴지 않게.
- **같은 값을 두 이름으로 싣지 않는다** — `Button.disabled` 는 `data-wb-state~="disabled"` 하나다(`data-wb-disabled` 없음).
- **속성 차례:** 뷰가 넘긴 것 → 마커 → 노드 속성(상태 뺌) → enum 표지 → 불리언 표지 → `data-wb-state` → 접근성 속성. 켜졌다 꺼지는
  것을 늘 있는 것 뒤에 둔다 — React 는 다시 그릴 때 새로 선 속성을 요소 끝에 붙여, 차례가 다르면 처음부터 켜고 그린 판과 `outerHTML`
  이 갈린다(`packages/exporter/test/runtime-bundle.test.ts` 가 글자로 견줘 4 건이 그렇게 죽었다 — 고친 뒤 초록).
- **SDK 판 1.1.0** — 표지는 새 기능이다. 시스템 테마 다섯과 스타터 템플릿이 `sdk: '^1.1.0'` 으로 기댄다.

지금 표지가 서는 prop(`MARKED_PROPS`): `Section.compact` · `Flex` 의 `direction` · `align` · `justify` · `wrap` · `List` 의 `pagination` ·
`selectable` · `SearchForm.collapsed` · `Media` 의 `kind` · `ratio`.

## prop 인구조사

카탈로그 19 타입 · prop 46 개(`Page` · `Slot` 은 prop 없음 — `prop-marks.test.tsx` 의 케이스 80 = 일반 4 + 칸마다 DOM 46 + 표지 10 + 반대 값 5 + 상태 12 + 변형 3). 같은 표가 `packages/renderer/test/prop-marks.test.tsx` 의 `CENSUS` 다 — 새 prop
이 표 없이 생기면 «표와 카탈로그가 같다» 가 죽는다.

**길:** `mark` 표지 · `state` 렌더러 `data-wb-state`(+ 접근성 속성) · `variant` `data-wb-variant` · `var` 노드 변수 · `text` 글자 ·
`markup` 마크업(행 수 · 칸 · 속성). **기본 뷰 전 → 후** 는 SDK 기본 뷰가 그 prop 으로 DOM · 모양을 바꾸는가. **테마** 칸은 다섯 테마가
그 표지 · 상태를 읽어 모양을 바꾸는가(a admin · c commerce · d docs · p portal · s saas-marketing). 근거: 테마 CSS · 뷰를 셀렉터 · `props.`
로 센 스크립트(고치기 전) · 실브라우저 자(고친 뒤).
