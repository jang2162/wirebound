### 원인 — 못 찾음

이 스택(CDP 마우스 · 헤드리스와 헤드풀 Chrome)에서는 56 판 모두 끌기가 서고 놓였다. **D2 실브라우저 케이스(`palette.test.ts` · `palette-review.test.ts`)가
못 잡은 까닭**은 그 케이스들도 같은 CDP 마우스 길로 끌기 때문이다 — 그 길로는 재현되지 않는다(D2 케이스는 검색으로 카드 하나만 세우고 카드
가운데를 쥐지만, 위 표의 넓힌 판 — 기본 탭 · 첫 카드 · 이름 줄 · 민 카드 줄 — 도 다 섰다). CDP 가 지나지 않는 길이 남는다: macOS 트랙패드의
OS 입력(강한 누름 «Force Click» 의 찾아보기 · 세 손가락 끌기 · 누른 채 다른 손가락으로 밀 때 가로 스크롤 상자인 카드 줄이 받는 스크롤 몸짓) ·
사용자 브라우저의 확장 · 사용자 DB 의 테마 판(`system-admin@0.1.0` 등 — 이 판에서는 안 쟀다) · 브라우저 확대.

**가설(재현 못 함):** 고치기 전에는 끄는 동안 보이는 것이 포인터 오른쪽 아래 14px 의 작은 이름표 하나뿐이고 카드 자체는 안 움직이며, 캔버스 위에서도
놓을 자리 위에서만 가는 선이 섰다 — «끌기가 시작 안 됨»으로 읽혔을 수 있다. 4(배치 미리보기)가 캔버스 위에서 보이는 것을 크게 바꾼다.

물음은 `q-d4.md` 에 값과 함께 적었고 코디네이터 답은 «Chrome · 트랙패드 · 눌러서 끌기»였다(테마 판 · 창 · 이름표 · 선 · 콘솔은 답이 없었다). 브리프
대로 고치지 않았고 막는 장치를 재현 없이 더하지 않았다 — 카드 몸통의 `user-select: none` 은 2 에서 카드가 `<div>` 가 되어 이름 글자가 골라질 수 있게
된 것을 막는 몫이다(고치기 전 `<button>` 의 글자는 원래 안 골라졌다).

### 접근 이름 인구조사

이름은 **«<한국어 이름> 넣기»**(예: «구분선 넣기»). 구조 트리 줄 `+` 가 `<이름> 추가` 라 «… 추가» 로 지으면 playwright 의 부분 일치가 둘을 함께 잡는다.

| 센 것(스크래치 `d4/census.py` — `apps/web/test` · `apps/web/build-test` · `apps/api/build-test` · `packages/*/build-test` 의 `name: '…'` · 템플릿 · 정규식. playwright 는 `exact: true` 가 없으면 부분 일치, testing-library 문자열은 전체 일치로 견줌) | 겹침 |
|---|---|
| 새 이름 «<카탈로그 한국어 이름 19> 넣기» | **0** |
| 대조 — «상호작용 추가»(있는 이름) | 8(자가 센다) |
| 대조 — «<이름> 옮기기»(손잡이) | 1(템플릿 `${name} 옮기기`) |
| 변수로 이름을 주는 playwright 찾기(`name: mode` · `item` · `secondTitle` 등 9) | 손으로 봄 — 모드 · 메뉴 항목 · 페이지 이름이라 0 |

### N8 — 판 최대를 잰 하단 바로

판 기본이 340 이 되어 창 700 · 통지 다섯이면 **기본 판에서도** 캔버스가 121px 로 준다(고치기 전 기본 200 일 때 261). 그래서 같이 고쳤다: 최대를

## 4. 끄는 동안 배치 미리보기

**파일:** `src/canvas/canvas-preview.ts`(새 — `previewDocument` · `applyPreviewLook` · `withoutPreview` · `isPreviewId`) · `src/canvas/canvas.tsx`(미리보기
문서를 그림 · 모양을 얹음 · 측정 이펙트 · `layoutKey` 의 의존 `rendered` · 표면의 `data-wb-preview` · `data-wb-preview-axis`) · `src/drag/use-placement.ts`
(`usePublishPlacementPreview` · `usePlacementPreview` · `PlacementDrop.region` · 판정을 미리보기를 숨기고 잼) · `src/canvas/canvas-drop.ts`(`isPreview` →
`{ preview: true }`) · `src/palette/component-palette.tsx` · `src/canvas/canvas-drag-handle.tsx`(보인 자리를 싣고 캔버스 위 선은 안 그림) ·
`src/drag/drop-indicator.tsx`(머리말).

- 놓을 자리가 서 있는 동안 캔버스가 **스토어 문서에 미리보기를 끼운 사본**을 그린다 — 새 타입은 `{ id, type }` 노드, 옮기기는 그 서브트리의 사본(원본은
  제자리에 `opacity 0.3`), 끼운 미리보기는 `opacity 0.55`. 스토어 · 서버 · 되돌리기 · 방송 · 구조 트리 · 속성 패널은 모른다. 놓거나 취소하면 걷힌다.
  사본은 렌더마다 지금 문서로 다시 지어 남의 편집 뒤 새 문서 위에 다시 선다. 페이지가 바뀌거나 iframe 이 새로 서면 경로 층의 판 검사(`live`)가 보인
  자리를 걷어 미리보기도 걷힌다.
- **미리보기 노드는 id 머리 `wb:preview:` 로 가른다** — 문서 id 의 꼴(`NODE_ID_PATTERN` — `[A-Za-z0-9_-]`) 밖의 글자(`:`)라 유효 문서의 id 와 겹칠 수
  없다. 선택 외곽선 · 번호 마커 · 손잡이 · 누름이 `data-wb-id` 로 노드를 찾으므로 사본이 원본 id 를 쓰면 그 조회가 둘을 잡는다. 렌더러의 속성 계약
  (`data-wb-*` 여섯 — «일곱째 데이터 속성이 필요해지면 멈추고 묻는다»)을 넓히지 않는 길이다.
- 반투명은 그린 뒤 인라인 `opacity` 로 얹고 되돌린다 — 캔버스 문서에 셸 CSS 를 넣지 않는다. 노드 바깥에 상자를 두르면 부모 뷰의 배치(그리드 칸 · 가로
  무리)가 그 상자를 자식으로 읽는다.
- 캔버스 위의 선 · 상자 강조는 미리보기가 대신한다. 트리 줄 위에 놓을 자리가 서면 트리의 선 · 강조와 캔버스의 같은 자리 미리보기가 함께 선다.

«N 앞» — 미리보기가 N 의 자리를 차지) 멈춘 판에서 포인터 밑에 보이는 것과 미리보기 자리는 맞는다. 밀린 노드로 포인터를 옮기면 그 순간 미리보기가

미리보기 때문이 아니다(아래 이월 1).

## 브리프와 달라진 것

1. **1 은 고치지 않았다** — 재현 실패(위). `q-d4.md` 의 답은 «Chrome · 트랙패드 · 눌러서 끌기»뿐이었다.
2. **N8 을 고쳤다**(브리프 «나빠지면 같이 다룬다 — 고치거나 값을 적는다») — 판 최대를 잰 세로로. 정본의 «최대를 창 높이로 셈하므로 … 캔버스는 그 몫 아래로
   준다»를 지금 동작으로 고쳤다.
3. **기준 배치는 «미리보기를 뺀 배치»** — 브리프가 든 후보 둘 가운데 «미리보기 위면 그 자리 유지»는 재서 버렸다(위 표).
4. **캔버스 표면에 `data-wb-preview` · `data-wb-preview-axis`** — 실브라우저 판이 보인 자리의 띠 · 축을 읽는 자리다(선택 외곽선의 `data-wb-selected-id` 와
   같은 꼴 · 셸 쪽 요소라 테마 문서의 속성 계약과 무관).
5. **구조 트리 줄 끌기(C — `panels/structure-tree.tsx`)는 미리보기를 싣지 않는다** — 브리프의 «트리 위에 놓을 자리가 서면 … 캔버스에도 같은 미리보기»는
   경로 층을 지나는 끌기(카드 · 손잡이)가 트리 위에 있을 때로 읽었다. 트리 줄 끌기는 경로 층을 안 지난다(`drag/use-placement.ts` 머리말 «트리 줄 끌기를
   이 층으로 옮기지 않는다») — 이월 후보 4.
6. 카드 몸통에 `user-select: none` — 카드가 `<div>` 가 되어 생긴 몫(1 의 «재현 없이 장치를 더하지 않는다»와 무관).
7. `panels/tree-row-actions.tsx` 의 주석 한 줄(«클릭 추가가 … `addInside` 문장을 그대로 쓴다»)은 옆 트랙(`feat-pj-ui`)의 파일이라 안 고쳤다 — 고칠
   문장: «컴포넌트 목록 카드의 «넣기» 단추가 «자식을 안 받는 자리» 에서 `addInside` 문장을 그대로 쓴다(`palette/palette-add.ts`).»
