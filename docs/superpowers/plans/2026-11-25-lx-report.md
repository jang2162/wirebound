## 결정과 이유

1. **`ExportRows` 에 칸을 안 더했다** — 메뉴 행 · 페이지 행이 이미 들어 있어 내비는 조립(`buildProjectBundle` → `projectBundle`) 안에서 짓는다. 그래서 워커로 가는 메시지 셋(`ToWorker` · `feed` · 받는 자리)도 그대로다. 표시 옵션은 읽지도 않는다.
2. **내비의 경로는 번들 안 경로(인코딩 전)이고 장이 제 자리(`path`)에서 상대 경로로 바꾼다** — 처음엔 뿌리 머리(`../`) + 뿌리 상대 경로로 지었는데 같은 디렉터리의 장에 `../pages/…` 가 붙어 번들의 다른 링크(`bundleHref` — `x.html`)와 꼴이 갈렸다. 런타임이 같은 함수를 부르게 했다.
3. **`nav.js` 는 늘 싣는다**(메뉴를 안 넘긴 번들은 빈 트리) — 장 HTML 에 스크립트 한 줄이 늘 붙어 `bundle-stateless-bytes` 해시가 바뀐다. «메뉴가 있을 때만» 으로 두면 장 HTML 이 메뉴 유무로 갈려 «내비가 한 벌» 의 크기 판이 흐려진다.
4. **`apps/web/test/canvas/bundle-parity.test.tsx` 를 한 줄 고쳤다**(lc 영역) — 번들 쪽 뿌리를 `firstElementChild`(이제 틀) 대신 첫 `[data-wb-id]` 로 집는다. 캔버스 쪽(`canvasDocumentRoot`)이 이미 그렇게 집어 lc 가 캔버스를 틀로 감싸도 맞는다.
5. **`packages/exporter/test/parity.test.tsx` 의 화면 경로를 `LayoutFrame` 으로 감쌌다** — 설계가 캔버스도 틀로 감싸게 정했고, 그 파일이 재는 것은 «번들 런타임이 렌더 경로에 더하거나 뺀 것» 이다. `runtime-bundle.test.ts` 의 `drawn()` 은 빈 틀의 내용 상자 안을 견주게 했다(빈 틀이 안 서면 던진다).
6. **PPTX 라우트 판은 두지 않았다** — PPTX zip 에는 번들 데이터가 안 실려 «표시 옵션이 없다» 를 셀 것이 없다(처음 세운 판은 어느 변조에도 안 죽을 판이라 걷었다). PPTX 화면은 같은 `projectBundle` 의 장을 찍으므로 HTML 라우트 판이 그 몫을 잰다.
7. **PPTX 캡처 폭은 720 그대로**(사용자 결정) — 코드를 바꾸지 않고 잠갔다. 설계 · 계획에 PPTX 의 1280 은 없었다(설계의 1280 은 캔버스 `viewportWidth` 줄이다).

## 잰 값

- `bundle-stateless-bytes` — 장 HTML 해시를 다시 지었다(`WB_PRINT_DIGEST=1`). 새 장 HTML 에서 `<script src="…assets/nav.js"></script>` 한 줄과 데이터의 세 칸(`"pageId":null,"pageTitle":…,"path":…`)을 걷고 해시하면 넷 다 앞 값(`57971df664af2a5a` · `d3f9228e6ff2f166` · `3c57529a0b5b606c` · `c150d92dc536c2bf`)이 선다 — 스크래치 탐침으로 쟀다. `assets/views.css` 해시는 그대로(`3620a5c4630e6ae4`), `assets/nav.js` 는 새 파일(`62616a8c3a28e33e` — 빈 트리).
- PPTX 그림 화소는 CSS px × 2(`DEVICE_SCALE_FACTOR`) — 서브페이지 장 폭 1440 · GNB 띠 1440 × 120 = 172800 화소. 줄 6 개짜리 표본은 두 장 다 뷰포트 높이(552)에 묶여 높이 차가 안 섰다 — 줄 40 개로 키우고 «빈 장 높이 > 552 × 2» 카나리아를 뒀다.
- 막 색 화소 — 찍는 판의 막 걷기를 뗀 변조에서 249600, 층을 뗀 변조(층 밖 `!important` 테마)에서 341760.
- 번들 화면(창 1000) — 막 폭 = 창 폭, 상자 위 여백 24, 좌우 여백 차 ≤ 1px. 가운데 세우기를 뗀 변조에서 좌우 차 472.
- 실브라우저 번들 — `U+202E` 를 든 메뉴 이름 다음 항목 «설정» 의 두 글자 x: 격리를 뗀 변조에서 «설» 347.95 > «정» 331.97(뒤집힘).
