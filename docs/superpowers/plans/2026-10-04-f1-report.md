## 태스크 1 — 트리 줄 접기

**무엇.**

- 접힘 저장소 `apps/web/src/tree/collapse.ts` — 구조 트리는 페이지마다(`structureKey`), 메뉴 트리는 프로젝트마다(`menuKey`) 세션 동안의 `Set`(모듈 `Map` · `useSyncExternalStore`). 트리 밖(에디터 단축키)에서도 읽고 쓴다. 새로 고침 뒤 빈 집합.
- 펼침 단추 `apps/web/src/panels/tree-fold.tsx` 의 `TreeToggle` — **포인터 몫**(`aria-hidden` · `tabIndex=-1`), 상태는 줄 단추의 `aria-expanded` 가 말한다. DOM 에서는 줄 단추 **뒤**에 두고 CSS `order: -1` 로 앞에 세운다 — 줄 상자의 첫 자식 · 첫 단추를 줄 단추로 읽는 케이스가 여럿이라(아래 인구조사).
- 제목 줄의 «모두 접기» · «모두 펴기»(`TreeFoldButtons` · 아이콘 `ChevronsDownUp` · `ChevronsUpDown`) — 읽기라 뷰 모드 · viewer 에게도 선다. 구조 트리의 «모두 접기»는 뿌리를 편 채 둔다.
- 저절로 펴짐 — 구조 트리는 고른 노드마다의 **조상 사슬**을 열쇠로 둔 레이아웃 이펙트(`chains`)라 고른 것이 어디서 왔든(캔버스 · 붙이기 · 복제 · 화살표 · 사각형 · 되돌리기) · 남의 편집이 고른 노드를 접힌 줄 안으로 옮겨도 편다. 사람이 고른 노드의 조상을 접은 판은 사슬이 그대로라 다시 펴지 않는다. 메뉴 트리는 열린 페이지와 고른 줄의 사슬.
- 키보드 — 에디터 단축키 ← → 가 먼저 접고 편다(`edit/selection-move.ts` 의 `foldStep`), ↑ ↓ · Shift 범위는 보이는 차례(`visibleNodeOrder(root, collapsed)`). 숨은 노드를 고른 채 ↑ ↓ 는 그것을 가린 보이는 조상에서 움직인다. 메뉴 트리는 메뉴 줄에 포커스를 두고 ← 접기 · → 펴기(`foldKey`).
- 끄는 중 0.7s 펼침 `apps/web/src/drag/hover-open.ts` — 구조 줄 끌기 · 메뉴 줄 끌기 · 경로 층(카드 · 손잡이 — `drag/use-placement.ts`) 셋이 포인터 밑 줄을 넘기고, 0.7s 가 지나면 그 줄에 이벤트를 쏴 트리가 편다. 뗀 이벤트 안의 다시 물음(끌기 장치가 뗀 좌표로 `onOver` 를 다시 묻는다)은 시계를 안 세운다. 끌기 장치(`use-pointer-drag.ts`)는 안 바꿨다.
- 접힌 줄에 «안»으로 놓으면 그 안 끝 — 판정이 원래 그렇다(`structureDropTarget` · `menuDropTarget`), 실브라우저로 잠갔다.

**케이스.** jsdom `apps/web/test/panels/tree-fold.test.tsx`(12 — 구조 8 · 메뉴 4) · `test/edit/selection-fold.test.ts`(8) · `test/drag/hover-open.test.ts`(4) · `test/edit/editor-keys.test.tsx` 의 ← → 케이스(옛 «← 는 부모» 를 «펴진 줄은 접고 · 접힌 줄은 부모» 로 옮김). 실브라우저 `apps/web/build-test/tree-fold.test.ts`(5).

## 태스크 2 — 컴포넌트 목록 줄바꿈

**무엇.** 카드는 264 × 200(창 264 × 176 + 이름 줄 · `box-sizing: border-box`) 고정, 트랙은 `flex-wrap` · 판 폭 · 높이는 줄 수, 스크롤 상자는 세로(`overflow-y: auto`). 판이 카드보다 좁으면(창 700) `max-width: 100%` 로 카드 폭이 준다. 축소판 깔개는 트랙 크기(`offsetWidth` · `offsetHeight`)로 서고, iframe 문서 안 표본 겹에 `min-height: 트랙 높이` — 쌓인 표본보다 트랙이 길면 아래 줄 표본이 iframe 밖으로 옮겨져 잘렸다(T2-M3). `shell/sidebar-layout.ts` 의 판 기본 · 최소 높이 주석을 지금 카드로 고쳤다.

## 태스크 3 — 배치 선

**무엇.** `apps/web/src/canvas/layout-guides.tsx` — 켬 · 끔(`localStorage` 의 `wirebound.layoutGuides` · 읽기 · 쓰기 try/catch · 모듈 값 하나를 단추와 캔버스가 구독), 머리 단추 `GuidesToggle`(아이콘 `SquareDashed` · `aria-pressed` · 이름 = `title` «배치 선»), 노드마다의 글 `guideOf`. 캔버스(`canvas/canvas.tsx`)는 외곽선 · 마커와 같은 측정(`measure` · `frameOffset`)과 같은 의존으로 Flex · Grid 마다 점선(`outline` — 주황 Flex · 보라 Grid)과 모서리 표시(줌을 걷는 `scale(1 / zoom)`)를 셸 겹에 그린다. 그린 문서(`rendered` — 미리보기 포함)를 돌되 미리보기 노드(`wb:preview:`)는 건너뛴다. 편집 모드에서만 — 단추도 그 조건(`routes/editor.tsx`). 방향은 자식 하나의 배치 부모로 `axisOf`(놓을 자리와 같은 함수 — `canvas-drop.ts` 의 `layoutParent` · `siblingRects` 를 내보냄), Grid 열 수는 그 배치 부모의 계산된 `grid-template-columns` 칸 수.

**만들며 찾은 것.** 테두리(`border` · `box-sizing: border-box`)는 높이 0 인 빈 Flex 의 선을 2px 로 부풀려 줌 1 · 1.5 · 0.5 에서 2 · 3 · 1px 어긋났다 — `outline`(`outline-offset: -1px`)으로 바꿔 0 이 됐다(T3-M7).

## 이월 후보

- **KeyValue 축소판이 거의 안 읽힌다** — 줄임 비 0.18(고치기 전 0.27). 표본(`GALLERY_SAMPLES` 의 KeyValue 첫째)이 세로로 길어 창 높이가 줄임을 정한다. 900 폭 창에서는 0.71 이다 — 축소판 iframe 폭(트랙 폭)이 테마의 미디어 쿼리를 바꿔 표본 모양이 갈리는 것으로 보인다(재지 않았다). 짧은 표본을 고르거나 표본 폭(`NATURAL_WIDTH`)을 타입마다 두는 길.
- **창 700 높이의 컴포넌트 목록** — 판 최대가 캔버스 몫에 눌려(305 · 337) 카드 한 장(200)이 다 안 보이는 판이 있다(700 × 700 은 판 머리가 줄을 바꿔 0 줄). 카드를 낮추거나 좁은 창에서 판 머리를 한 줄로 두는 길.
- **배치 선의 «그려진 배치로 읽기»를 가르는 테마가 없다** — 위 «못 재는 것». `*-reverse` 나 좁은 폭에서 접히는 Grid 를 그리는 픽스처 테마로 케이스를 세우면 닫힌다.
- **배치 선의 모서리 표시가 노드 왼쪽 위의 글을 가린다** — 스크린숏 `4-guides-on`(«저장» 단추 위). 표시를 상자 바깥 위로 올리는 길(위 끝 노드는 캔버스 칸 밖이 된다).
- **메뉴 트리에는 ↑ ↓ 줄 이동이 없다** — 이번에 ← → 접기 · 펴기만 더했다(구조 트리의 표준 트리 키를 메뉴 트리 줄 포커스로 넓히는 일).
- **펼침 단추는 키보드 정지점이 아니다** — 구조 트리는 에디터 단축키 ← →, 메뉴 트리는 메뉴 줄의 ← → 가 대신한다. 스크린 리더 사용자는 줄 단추의 `aria-expanded` 로 상태를 듣는다.
