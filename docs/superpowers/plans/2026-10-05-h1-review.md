## R1 — 같은 수 · 다른 페이지(높음 · 새 길)

**판(실브라우저 · `samecount.bprobe.ts`):** alice 가 «설정/환경» 을 열어 둔다(트리 로드). bob 이 «회원 상세(옮겨질 것)»을 «설정»으로 옮기고(`PATCH …/pages/:id { menuNodeId }` 200) «회원관리»에 «새 결제 화면(bob)»을 만든다. alice 가 «회원관리» `…` → «삭제» → «모두 삭제».

| 무엇 | 값 |
|---|---|
| 상자 문장 | «"회원관리" 메뉴와 페이지 2개가 함께 삭제됩니다» |

| 서버에 남은 페이지 | `["환경", "회원 상세(옮겨질 것)"]` |
| 본 적 없는 «새 결제 화면(bob)» | **지워짐** |
| 목록에 있던 «회원 상세» | **남음** |
| alice 화면의 `alert` · 하단 바 | 없음 · 없음 |

**같은 판정을 api 로**(`cascade.probe.ts` «2 수 재검») — 화면이 본 수 `{menus:2, pages:3}`:

| 바꾼 것(연쇄 전에 커밋) | 연쇄 답 | 지워진 본 적 없는 행 |
|---|---|---|
| 페이지 하나 밖으로 + 새 페이지 하나 안으로 | 200 | 새 페이지 |
| 하위 메뉴 하나 밖으로 + 페이지 든 다른 메뉴 하나 안으로 | 200 | 들어온 메뉴 · 그 페이지(나간 «혜택 안내»는 남음) |
| 페이지 셋 전부 지우고 같은 수만큼 새로 | 200 | 셋 다 |

**원인:**
- 서버 — `services/menu-cascade.ts` 의 `deleteMenuCascade` 가 `counts.menus` · `counts.pages` 둘만 견준다.
- 화면 — `tree/use-tree-commands.tsx` 의 `confirmCascade` 가 그 화면의 트리(`menuSubtree`)로 센 수를 싣는다. 그 트리는 마운트 · 자기 조작 뒤 · 복원 신호에서만 다시 받는다. 남의 쓰기는 방송이 없다(R3). 그래서 화면의 트리는 세션 내내 낡을 수 있고, 남이 하나 빼고 하나 넣으면 수가 맞는다.

**겹친 판:** 연쇄는 프로젝트 행을 먼저 쥐고(`lockProjectForRestore`) 그 뒤에 세므로, 겹친 쓰기는 «연쇄 앞 / 뒤»의 차례로만 끝난다. 이 판은 bob 의 두 쓰기가 다 앞에 선 차례다. 겹친 차례 각각의 판은 H1 의 `menu-cascade-concurrency.test.ts` 가 잰다(추가 · 옮기기 — 하나씩이면 수가 달라 409).

**덜어 주는 것:** 지우기 직전 안전망 스냅샷이 남는다(I3). 다만 owner 만 복원하고, 복원은 그 뒤의 다른 작업까지 되돌린다.

**고칠 방향:** 상자가 센 **id 집합**(밑의 메뉴 id · 페이지 id)을 싣고 서버가 집합으로 견준다. 다르면 409 에 지금 집합을 싣는다. 상자를 열 때 트리를 다시 받는 것은 창을 좁힐 뿐이라 집합 견줌을 대신하지 못한다.

## R2 — 꺼진 항목의 이유에 키보드로 못 닿는다(낮음 · 새 길)

**main:**
- 상태줄은 `tabIndex=0`(할 말이 있을 때) 이었다.
- 줄 행동 항목은 그 줄을 `aria-describedby` 로 들었다.
- 꺼진 항목은 그때도 화살표가 건너뛰었으므로, 키보드 사용자에게 이유가 닿는 길은 **Tab 으로 그 줄에 서는 것**이었다.
- 근거: `git show main:apps/web/src/panels/menu-tree.tsx` 의 `MenuStatusLine` · `git show main:apps/web/src/panels/structure-tree.tsx` 의 `StructureStatusLine`.

**HEAD(실브라우저 · `reasons.bprobe.ts`):** alice 는 루트(`Page`, 자동 선택), bob 이 자식 `Text 하나`를 고른(잠근) 판.

| 무엇 | 값 |
|---|---|
| 루트 `…` 항목 6 · `+` 항목 3 | 전부 `aria-disabled` · `title` = Chrome AX `description` = «밥님이 편집 중이라 고를 수도 바꿀 수도 없습니다»(패턴은 «… 패턴을 넣을 수 없습니다») |
| 메뉴를 연 뒤 ↓ 를 항목 수 + 2 번 | 포커스가 선 항목 0(모두 꺼져 갈 곳이 없다) |
| 구조 트리 루트 줄부터 Tab 14 번 | 이유를 설명으로 든 정지점 0 — 줄 단추들의 AX 설명은 제 이름과 같다(`Page 추가` 등) |
| 같은 판에 보이는 잠금 글 | 구조 트리 줄 배지 «편집 중» · 우측 패널 «밥님이 편집 중이라 바꿀 수 없습니다» |

**옮겨지지 않은 일:**
- 상태줄이 «보이는 글»로 하던 잠금 안내는 배지와 우측 패널이 그대로 말한다.
- «보내는 중» · «고른 것 없음» · «루트라» 류는 꺼진 항목의 `title` 에만 있다. 마우스를 올려야 보인다.
- 줄째 사라진 것은 **키보드 · 낭독기의 닿음** 하나다(보고 이월 1 과 같다).

**고칠 방향:** APG 처럼 화살표가 `aria-disabled` 항목에도 서게 한다(누름은 막는다). 이것은 정본 «`…` 메뉴»의 «꺼진 항목은 건너뛴다»를 바꾸는 일이다.
