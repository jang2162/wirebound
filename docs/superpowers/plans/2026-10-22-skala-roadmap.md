# SKALA 화면설계서 대응 로드맵 — 2026-10-22

1차 목표: SKALA LMS 관리자 화면설계서 14개(120쪽 · 목록 · 등록 · 수정 · 상세 · 팝업)를 이 도구로 같은 모양으로 그린다.
설계서는 저장소 밖(사용자의 업무 문서)에 있고 저장소에 넣지 않는다. 배포된 서비스가 없어 **옛 문서 · 데이터 호환은 고려하지 않는다**(노드 모델을 바꿀 때 옮기기 마이그레이션을 짓지 않는다).

## 지금 구조로 모자란 것 (설계서와 대조)

뿌리는 셋이다 — 노드의 자식이 몸통 배열 하나뿐이다 · `Field` 가 컨트롤 하나뿐이다 · `List` 가 열 이름 목록에 모든 셀을 «—» 로 그린다.

| # | 모자란 것 | 설계서에서 |
| --- | --- | --- |
| 1 | **구역(이름 붙은 자리)** — 카드 머리 오른쪽 · 제목 옆 · 바닥, 검색폼 머리 · 몸통 · 단추 영역(지금 `[초기화][검색]` · `[저장][취소]` 는 뷰에 박혀 있다), 결과 머리줄(«검색결과 총 N건» + 오른쪽 단추 · 셀렉트), 소제목 오른쪽 단추, 탭마다 패널, 팝업 제목줄 · 바닥 | 모든 목록 · 등록 화면 |
| 2 | **조합 입력** — 한 값 칸에 조각 여럿: 입력 · 숫자 · 셀렉트 · 날짜 · **시간** · 단추 · 읽기 전용 값 · 사이 글자(`~` 부터 까지 % 점 이상) · **세그먼트 토글**(2~7칸, 미선택 가능) · 칩(지울 수 있는) · 체크박스 칩 묶음. **선택지(options) 속성이 없다** | `[readonly][사용자 검색]` · `[날짜]~[날짜]` · `[셀렉트][숫자] 일 후 [시간] 부터 …` · `[Y][N]+[입력]%+[입력]점 이상` |

| 4 | **그리드** — 열마다 셀 종류(글 · 링크 · 단추 · 셀렉트 · 입력 · 세그먼트 · 배지 · 칩 · 두 줄 · 색 글자 · 기호), 체크 · 라디오 선택 열, 2~3단 병합 머리, 합계 행, 빈 결과 행, 행 강조 · 딤드 · 음영, 고정 열 + 가로 스크롤, 정렬 표시, 페이지네이션 바 3구역(행 수 셀렉트 · 쪽 번호 · «1 - 50 (총 72 항목 중)») | 모든 목록 · 팝업 · 출석부 매트릭스 |
| 5 | **팝업** — 제목줄 ✖ · 스크롤 · 검색 · 라디오 선택 그리드 · 바닥 단추 | 검색 팝업(문서마다) · 일괄등록 · 담기 팝업 |
| 6 | **파일첨부 위젯** — 단추 3 · 파일 목록 · 드롭 안내 · 한도 문구 | 훈련생 등록 한 화면에 9번 |
| 7 | **반복 행 입력 표** — `[추가]` · 행마다 `[삭제]` · 합계 행 | 교강사 · 캠퍼스 · 기수 · 교육과정 |

| 10 | 마스터-디테일 2분할 — `Grid` 2열로 짠다(4 가 풀리면 함께) | 분반 · 성취도 |
| 11 | **화면 정보** — 화면ID · 작성자 · 작성일 · 수정일 칸이 없다 | 모든 쪽 머리 |
| 12 | **Object Description** — 표지가 노드에만 붙어 그리드 머리 칸 · 셀에 못 붙는다, 공통 설명(저장 · 취소 Case 01/02/03)을 재사용할 길이 없다 | 모든 쪽 |

**필요 없는 것:** 트리 · 달력 · 시간표 · 차트 · stepper 는 120쪽에 한 번도 나오지 않았다.

## 함께 받은 요청

- **R1 테마 패턴 기능 제거**(기본테마에 패턴 0개 — 화면에서 사라지는 것은 «테마 패턴» 묶음 머리 하나).
- **R2 속성 패널** — 순서는 속성 칸 → 몫 → 상태 보임 → **별칭(맨 아래)**. «상태 보임» 은 버튼 꼴 라디오 `[비활성][숨김][표시]`(기본값 «비활성» = 지금의 «없음», 숨김 = `except`, 표시 = `only`), «숨김» · «표시» 일 때만 상태 줄 `[기본][상태1][상태2]` 가 선다. **상태 줄은 여러 개를 켜는 토글**(라디오 아님 · 하나는 늘 켜져 있다).
- **R3 상태 설명** — 상태마다 설명 칸.
- **R4 «페이지 정보» 탭** — 오른쪽 판 «속성» 왼쪽. 페이지 이름 · 페이지 설명 · 상태 추가 · 이름 바꾸기 · 삭제 · 설명. 뷰 모드의 «페이지 설명» 탭을 이 탭으로 바꾼다(읽기만). **메뉴 트리의 상태 줄은 고르기만 하고 관리 입구는 이 탭으로 옮긴다.** 화면 정보(11)도 뒤에 이 탭에 둔다.
- **R5 자리표시자 개선** — 설계서에 없는 요소를 그리려고 이미지 · 배경색 등을 정하는 컴포넌트. 만든 임의 컴포넌트는 모듈로 재사용한다.

## 정한 것

- **A — 셀 안 컨트롤 · 조합 입력의 조각 · 구역의 내용은 자식 노드다**(속성 표가 아니다). 표지 · 별칭 · 상태 보임 · 끌어 넣기 · 모듈 저장을 그대로 쓰고, 셀 · 조각에 표지를 다는 문제(12)도 함께 풀린다.
- **B — 팝업은 «팝업 페이지»(페이지 종류)다.** 설계서에서 팝업은 화면ID 를 따로 갖는 화면이고, `openModal` 이 페이지를 가리키는 지금 방식과 맞는다.
- **C — 쪽을 나눈 긴 화면(«다음 페이지 / 이전 페이지»)은 도구에서 스크롤되는 한 화면이다.**

## 단계

1. R1 테마 패턴 제거 · R2 속성 패널 · R3 상태 설명 · R4 페이지 정보 탭
2. 노드 모델에 구역 — 카드 · 검색폼 · 입력폼 · 결과 머리줄 · 탭 패널(1)
3. 조합 입력 · 선택지 · 시간 · 세그먼트 · 칩(2) · R5 자리표시자
4. 라벨|값 폼 표(3)
5. 그리드 · 페이지네이션 바(4)
6. 팝업 페이지 · 파일첨부 · 반복 행 표(5 · 6 · 7)
7. 상태별 속성 · 화면 정보 · Object Description(8 · 11 · 12)
