# SKALA 화면설계서 대응 로드맵 — 2026-10-22

1차 목표: SKALA LMS 관리자 화면설계서 14개(120쪽 · 목록 · 등록 · 수정 · 상세 · 팝업)를 이 도구로 같은 모양으로 그린다.

## 함께 받은 요청

- **R1 테마 패턴 기능 제거**(기본테마에 패턴 0개 — 화면에서 사라지는 것은 «테마 패턴» 묶음 머리 하나).
- **R2 속성 패널** — 순서는 속성 칸 → 몫 → 상태 보임 → **별칭(맨 아래)**. «상태 보임» 은 버튼 꼴 라디오 `[비활성][숨김][표시]`(기본값 «비활성» = 지금의 «없음», 숨김 = `except`, 표시 = `only`), «숨김» · «표시» 일 때만 상태 줄 `[기본][상태1][상태2]` 가 선다. **상태 줄은 여러 개를 켜는 토글**(라디오 아님 · 하나는 늘 켜져 있다).
- **R3 상태 설명** — 상태마다 설명 칸.
- **R4 «페이지 정보» 탭** — 오른쪽 판 «속성» 왼쪽. 페이지 이름 · 페이지 설명 · 상태 추가 · 이름 바꾸기 · 삭제 · 설명. 뷰 모드의 «페이지 설명» 탭을 이 탭으로 바꾼다(읽기만). **메뉴 트리의 상태 줄은 고르기만 하고 관리 입구는 이 탭으로 옮긴다.** 화면 정보(11)도 뒤에 이 탭에 둔다.
- **R5 자리표시자 개선** — 설계서에 없는 요소를 그리려고 이미지 · 배경색 등을 정하는 컴포넌트. 만든 임의 컴포넌트는 모듈로 재사용한다.
  - **이미지는 파일 올리기다**(주소가 아니다) — 서버에 저장하고 HTML 번들 · PPTX 에 싣는다. 저장소 · 용량 한도 · 권한(프로젝트 멤버만 읽기)을 새로 짓는다.
  - 그 밖의 속성: 크기 · 배경색 · 테두리(없음/실선/점선 · 색) · 모서리 · 글(색 · 크기 · 정렬) · 안쪽 여백.
  - **자식을 넣을 수 있다** — 배경색 칸 안에 글 · 단추를 넣어 칩 · 배지 같은 임의 컴포넌트를 짓고 모듈로 저장한다.

## 정한 것

- **A — 셀 안 컨트롤 · 조합 입력의 조각 · 구역의 내용은 자식 노드다**(속성 표가 아니다). 표지 · 별칭 · 상태 보임 · 끌어 넣기 · 모듈 저장을 그대로 쓰고, 셀 · 조각에 표지를 다는 문제(12)도 함께 풀린다.
- **B — 팝업은 «팝업 페이지»(페이지 종류)다.** 설계서에서 팝업은 화면ID 를 따로 갖는 화면이고, `openModal` 이 페이지를 가리키는 지금 방식과 맞는다.
- **C — 쪽을 나눈 긴 화면(«다음 페이지 / 이전 페이지»)은 도구에서 스크롤되는 한 화면이다.**
- **3단계 설계(2026-10-24 — `docs/superpowers/specs/2026-10-24-compose-input-design.md`) 물음은 모두 추천대로다** — Q1 세그먼트 · 체크 칩은 `RadioGroup` · `CheckboxGroup` 의 테마 변형 · Q2 흔한 다른 꼴은 조각 줄 행동 «종류 바꾸기» · Q3 판 3 의 옛 `Field` 는 `0029` 가 옮긴다 · Q4 자리표시자 색은 자유 hex + 견본 · Q5 그림은 프로젝트 · 사람과 함께만 지운다 · Q6 개인 모듈의 그림은 사람 몫으로 함께 저장 · Q7 SVG 는 격리 헤더로 받는다.
- **4단계 설계(2026-10-25 — `docs/superpowers/specs/2026-10-25-form-table-design.md`) 물음은 모두 추천대로다** — Q1 열을 정한 검색폼도 라벨 왼쪽 쌍 격자 · Q2 `0031` 이 입력폼의 필드를 폼 표로 옮긴다 · Q3 사진 칸은 폼 표의 «옆 칸» 구역 · Q4 표 밖 구역 제목은 폼 표 «제목» + «머리 오른쪽» 구역.
- **5단계 설계(2026-10-25 — `docs/superpowers/specs/2026-10-25-grid-design.md`) 물음은 모두 추천대로다** — Q1 팔레트 이름 «그리드» · 배치 `Grid` 는 «격자 배치» · Q2 PPTX 의 넓은 표는 표 전체 폭으로 펼쳐 찍는다 · Q3 범위 글은 바의 총 건수 · 쪽 크기 · 지금 쪽으로 셈한다 · Q4 되풀이 행에 첫 행과 같은 글이 선다 · Q5 `0032` 가 `List` 를 `DataGrid` 로 옮긴다.
- **6단계 설계(2026-10-26 — `docs/superpowers/specs/2026-10-26-popup-attach-repeat-design.md`, 브랜치 `feat/popup`) 물음은 모두 추천대로다** — Q1 파일첨부는 꼴만(파일 목록은 사람이 적는 표본) · Q2 `0033` 이 `openModal` 이 가리키는 페이지를 팝업으로 옮긴다 · Q3 뷰 모드 · 번들의 «팝업 열기» 는 덮개 + 가운데 상자(✖ · Escape · «팝업 닫기» 로 닫고 상자 안에서 굴린다) · Q4 새 팝업의 바닥은 `[취소][저장]`(«취소» 에 «팝업 닫기») · Q5 팔레트 «반복 행 표» 프리셋 카드 · Q6 팝업은 그것을 쓰는 메뉴 밑에 «팝업» 표지 줄로 선다. 구현은 PO-A(팝업 · `0033`)와 PO-B(파일첨부 · 반복 행 표)를 나란히 돌리고 A 를 먼저 병합한다.
