(5445 · 5433 안 건드림). 탐침은 스크래치(`…/scratchpad/rv2-a5/` — `harness.mts` 가 `screen-sandbox-review.test.ts` 의 `drawWith` 를 옮긴 판:

(`apps/api/build-test/rv2-tmp-fullchrome.test.ts` — 아래 「전체 Chromium」)를 잠깐 두었다가 지웠다. 소스 변조는 하지 않았다. 끝의
`git status` 깨끗 · `git diff --stat` 빈 판.

판정 · 이월은 코디네이터가 적었다. 워커가 쓰다 만 앞부분(위)은 그대로 두었다.

## 판정

- 테마는 인스턴스 관리자만 올리는 신뢰 코드다(spec 「업로드 · 버전 · 인스턴스 관리자」). 설계서를 쓰는 편집자가 넣는 것은 데이터이고 코드로 돌지 않는다.
  화면 렌더러의 바깥 차단은 그 신뢰 위에 얹은 방어다. 운영 갈래(전체 Chromium)의 온전한 판이 0 이므로 병합했다.
- 3a 는 «전체 Chromium 에서 WebRTC UDP 를 페이지 겹 혼자 막는다» 는 뜻이라, 브라우저 겹이 주 방어라는 머리말의 전제가 운영 바이너리에서는
  서지 않는다. 브라우저 수준에서 WebRTC UDP 를 막는 길(관리 정책 파일의 `WebRtcIPHandlingPolicy` · 컨테이너 네트워크 격리 등)을 **계측으로 쓴
  브리프**(채널별 소켓 수 — 우회 기법 탐색이 아니라)로 다음 차수에 맡긴다.

## 이월

1. 전체 Chromium 에서 브라우저 겹만으로 WebRTC UDP 를 막는다(3a). 머리말 표에 서비스 워커 · AudioWorklet 을 더한다(1′).
2. K1 한도를 넘긴 장 뒤의 Chromium 프로세스 수 · 그리기 칸이 풀리는지 계측(4).
3. 페이지 겹 우회(2) — 1 이 서면 페이지 겹은 보조라 무게가 낮아진다.
