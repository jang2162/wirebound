## 남은 것 · 이월

- **Q-A(b) 스키마 `nested-page`**: 옛 문서 수를 세었다 — 저장소 JSON(자료)에서 `Page` 타입이 든 파일 **0**, 소스 · 테스트의 `type: 'Page'` 글자 **11 곳**(한 줄 안 중첩 패턴 `children: [… type: 'Page'` 0 — 뿌리로만 쓰임). 한계: 여러 줄 중첩 · **사용자 DB 에 저장된 문서**는 이 세기로 못 본다 — 도입 전에 DB 를 훑는 스크립트가 필요.
- **텍스트 칸의 외짝 서로게이트는 U+FFFD 로 조용히 바뀐다**(제목 · 프로젝트 이름 · 프리셋 이름 · 코멘트 · 스냅샷 태그, 200/201). 500 은 아니라 L-103 밖이다. 거절(400)할지 결정 필요 — `db/nul-guard.ts` 의 `NulByteError` 표(칸 목록)에 `containsLoneSurrogate` 를 같이 건다.
- **L-106 편집 · 복원 · 게시의 늦은 커밋**: 방송이 `seq` 이음이라 늦은 방송 설계가 필요(`rebroadcastPostRevision` 같은 조건).
- 복원이 지우는 페이지의 잠금(L-109 잔여): 복원이 지운 페이지 id 를 값으로 돌려줘야 놓을 수 있다.
- L-104 · L-112 · L-114 · L-115: 기본값(a)로 열림.
- 지침 후보(CLAUDE.md 「수를 셀 때는…」 절 끝에 한 문장): «**하드코딩된 개수 하한 단언(`카드 ≥ 18`)은 분모를 바꾸는 변경에서 `git grep` 으로 같이 센다** — 카탈로그 타입 수를 쓰는 build-test 가 있다.»
- 지침 후보(CLAUDE.md 「경주를 재는 케이스는…」 절): «**`withRealApi` 케이스는 `beforeEach/afterEach(resetRealData)` 를 둔다** — 안 두면 같은 실행의 `withApi` 파일의 `signup` 이 `already-exists` 로 죽는다.»
