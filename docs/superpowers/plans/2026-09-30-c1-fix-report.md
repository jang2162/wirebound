# C1 리뷰 대응 — 보고

대상: `feat/c1-shell` `498d6e40`(리뷰 `2026-09-30-c1-review.md` 의 F1). 판정은 전부 **실브라우저**(`apps/web/build-test/editor-stack.ts` — 시스템 Chrome 헤드리스, vite dev) 값이다. main 과 견준 값은 `git archive 0ef89f1d` 사본(스크래치, `pnpm install --frozen-lockfile --prefer-offline` · `pnpm build`, `apps/api/.env` 는 이 워크트리 것을 심링크 — 포트 5461)에 **같은 탐침 파일**을 돌린 것이다. 탐침은 스크래치에 두고 잴 때만 `build-test/` 에 들였다 걷었다(커밋 안 함). 낮은 무게 L1 ~ L4 는 고치지 않았다(이월).

## 고침 — `apps/web/src/shell.css`

리뷰가 잰 방향 그대로에 두 줄을 더했다.

| 줄 | 무엇 | 왜 |
|---|---|---|
| `.wb-shell-footer { flex-wrap: wrap }` | 바가 접힌다 | 도구(341px)가 제 폭을 지키고 통지가 남은 폭(63)만 받던 것을 끊는다 |
| `.wb-shell-footer-notices { flex: 1 1 320px }` | 통지 무리의 기본 폭 | 그만큼 안 남으면 도구가 통지 아래 줄로 간다 |

같이 고친 것: `test/shell-css-narrow.test.ts` 의 `WRAPPING_GROUPS` 에 `wb-shell-footer` 를 올렸다(jsdom 에서 바의 `flex-wrap` 을 잠근다). `shell/shell-footer.tsx` 머리말과 spec 「하단 바」에 «좁으면 도구가 통지 아래 줄 오른쪽 끝으로 간다»를 적었다 — 둘 다 «캔버스 칸 아래 한 줄»로만 말하고 있었다.
