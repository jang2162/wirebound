# N30 보고 — 끌기 진단 장치 `?debugDrag=1`(L-014 · L-001 의 입구)

브랜치 `feat/n30-drag-debug`(main `c2ac1cf6` 위) · 코드 커밋 `744eaddd`. 사용자 결정 Q5 = 짓는다. 장부는 안 고쳤다.

## 1. 장치 모양

### 켜는 법

| 길 | 값 | 비고 |
|---|---|---|
| 주소 | `?debugDrag=1` | 앱이 뜰 때(모듈 `apps/web/src/drag/drag-debug.ts` 적재) 한 번 읽는다 — 페이지를 옮겨 질의가 빠져도 그 탭은 켜진 채 |
| `localStorage` | 키 `wb-debug-drag` = `'1'` | 읽기는 try/catch(막힌 저장소 = 꺼짐) · `'true'` 같은 다른 값은 꺼짐 |

켜지면 첫 줄 `[wb-drag] #0 +…ms on source=query|storage dpr=… viewport=…x… ua=…`(확대 · 배율 판을 가르는 값). 끄는 법은 질의 없이 다시 열거나 키를 지우고 새로고침.

**수준은 `console.info`** — Chrome 은 `console.debug` 를 «Verbose» 로 내 기본 콘솔(Default levels)에서 숨긴다. **줄은 객체가 아니라 글 한 줄** — 콘솔의 객체는 접힌 채(`{…}`) 복사돼 사람이 붙인 글에 값이 안 남는다.

### 단계 표

| 단계 | 어디서 | 언제 · 값 |
|---|---|---|
| `on` | `drag-debug.ts` | 켜졌을 때 한 번 |
| `down` | `drag-debug.ts`(창의 붙잡는 단계 `pointerdown` — 켠 판에만 건다) | 모든 누름 · 번호(`#n`)를 올린다 · **누름을 받은 요소** |
| `press` · `press-ignored` | `use-pointer-drag.ts` | 끌기 장치가 받았다 · 무시했다(`why=button` · `why=busy` + 쥔 포인터 id) |
| `start` | `use-pointer-drag.ts` | `via=threshold`·`touch-hold` · `dist` · `capture=set`·`absent`·`threw` · `has` |
| `capture-got` · `capture-lost` · `window-blur` | `use-pointer-drag.ts`(켠 판에만 건 리스너) | 캡처 얻음 · 잃음 · 창 잃음 |
| `over` | `use-placement.ts` | 놓을 자리의 답이 **바뀔 때만**(서명 = 영역 · 부모 · 차례 · 띠 · 대상 / `none:<까닭>` — 좌표는 서명 밖) |
| `tag` | `component-palette.tsx`(이름표 ref) | 이름표가 섰다 · 상자 — 누름마다 한 번(`once` — dev `StrictMode` 가 ref 를 두 번 부른다) |
| `release` | `use-pointer-drag.ts` | 뗀 좌표 · `landed` · `shown` · `still` |
| `drop-refused` | `use-pointer-drag.ts` | 뗀 답이 보인 답과 다른 부모(`why=not-shown`) |
| `end` | `use-pointer-drag.ts`(`finish(why)`) | `why=click`·`touch-scroll`·`release`·`pointercancel`·`escape`·`unmount` · `started` |
| `drop` | `use-placement.ts` | `result=committed`(부모 · 차례 · `new:<타입>`) · `result=refused why=<까닭>` |

### 까닭 값(`DropMiss`) 목록

| 층 | 값 |
|---|---|
| 경로 층(`use-placement.ts`) | `no-document` · `stage-changed` · `collapsed` · `tree-miss` · `no-canvas` · `preview-gone` |
| `canvasHitAt`(`canvas/canvas-drop.ts`) | `no-frame-element` · `outside-canvas` · `beside-or-above-document` |
| 판정(`edit/structure-drop.ts`) | `no-root` · `target-not-in-document` · `not-container` · `root-has-no-siblings` · `parent-not-container` · `unknown-type` · `ops-unbuildable` · `locked` · `self` · `state-case` · `into-own-subtree` · `same-place` |
| 놓기만 | `commit-refused` · `unknown`(까닭을 안 알린 `null`) |

`canvasHitAt` · `structureDropTarget` · `pageEndTarget` 에 **끝에 붙은 선택 인자 `why`** 를 더했다 — 켠 판에만 경로 층이 넘기고, 먼저 온 까닭이 이긴다(`reason ??= next` — 안쪽 판정이 먼저 알린다). 답 자체는 안 바뀐다. `structureDropTarget` 은 `ops === null || blockedBy(ops) !== null` 한 줄을 둘로 갈랐다(`ops-unbuildable` · `locked`) — 같은 답이다.

## 2. 꺼진 판의 비용

| 값 | 잰 자리 |
|---|---|
| `[wb-drag]` 줄 0 · `console.info` 호출 0 | jsdom «꺼진 판» · 실브라우저 «꺼진 판»(`lines: []` · 페이지가 낸 `[canary]` 한 줄은 닿았다) |
| `dragDebug()` = `null` | jsdom «꺼진 판» |
| 끌기 한 번에 창에 건 리스너 종류 = `keydown` · `pointercancel` · `pointermove` · `pointerup`(고치기 전과 같은 넷 — `blur` · `pointerdown` 없음) | jsdom «꺼진 판»(`window.addEventListener` 엿보기) |
| 카드 요소에 건 캡처 리스너 0(켠 판은 `gotpointercapture` · `lostpointercapture`) | jsdom «꺼진 판»(`mock.contexts` 로 카드에 건 것만) |
| 놓기 결과 같음(편집 1 · `add`) | jsdom · 실브라우저 «꺼진 판» |

꺼진 판이 더 하는 일: 누름 · 끝 · `onOver` · `onDrop` 마다 모듈 변수 하나를 읽고(`dragDebug()`), `null` 을 내는 갈래마다 `why` 가 `undefined` 인 함수 하나를 부른다(`miss(undefined, '<글자 상수>')`). **`?.` 단락이라 줄의 인자(글 · 객체 · 상자 재기)는 계산되지 않는다.** 이름표 ref 는 이름표가 설 때 한 번 불려 `null` 을 보고 돌아간다. 시간 · 할당을 수로 재지는 않았다(아래 «못 잰 것»).

## 7. 사용자에게 줄 안내(세 줄)

1. 안 되던 그 에디터 주소 끝에 `?debugDrag=1` 을 붙여 다시 열고, 개발자 도구(F12) 콘솔 첫 줄에 `[wb-drag] … on source=query` 가 섰는지 본다.

## 8. 못 잰 것

- **사용자의 판 자체** — 이 장치는 재는 길을 연 것이지 L-001 을 재지 않았다. macOS 트랙패드 OS 입력 · 확장은 그대로 안 쟀다.
- **꺼진 판의 시간 · 할당을 수로** — 리스너 종류 · 줄 수 · `?.` 단락으로 «안 짓는다» 를 보였고, 끌기 한 번의 ms · 바이트는 안 쟀다.
- **운영 번들(`EDITOR_STACK_BUNDLE=build`)** — 이펙트 · 마운트 순서를 안 바꿨다(이름표에 ref 하나 · 언마운트 정리는 같은 뜻). 운영 번들에서는 `StrictMode` 가 없어 `tag` 가 원래 한 번이다.
- **Firefox · Safari** 의 콘솔 수준 · 복사 모양.
- **트리 줄 끌기**(`panels/structure-tree.tsx`)는 경로 층을 안 지나 `over` · `drop` 줄이 없다(누름 · 시작 · 뗌 · 끝은 같은 장치라 선다). 캔버스 손잡이는 경로 층을 지나 전부 선다 — 손잡이 판은 케이스로 안 쟀다.
- **캔버스 iframe 안의 누름**은 전역 `down` 이 못 본다(호스트 창의 리스너다 — `CLAUDE.md` «캔버스 문서는 same-origin iframe 이다»). 카드 · 손잡이는 호스트라 영향이 없다.
