# N2 — 문안 · 통지 · 말없는 거절(장부 T2) 보고

브랜치 `feat/n2-notices`. 코드 끝 커밋 `54b6f7cf`(앞 코드 커밋 `43f6a2b0` 에서 게이트를 돌려 기대 9건을 고쳤다 — 아래 «게이트»). 이 보고서 커밋은 문서뿐이다.

화면 값은 «jsdom»(`apps/web/test`) · «실브라우저»(`apps/web/build-test`)로 가른다. «고치기 전 값»은 고침을 되돌린 변조의 실패 값이다(아래 변조 표) — 고치기 전 커밋을 따로 되돌려 잰 것이 아니다.

## 정보 통지 자리(Q27 → 나)

실패 자리(`EditAlert` · `role="alert"`)와 갈라 **정보 통지 한 칸**을 뒀다 — `EditorState.infoNotice`(스토어) · `shell/info-notice.tsx` · `role="status"`.

- **한 칸이라 쌓이지 않는다.** 새 정보 통지가 앞의 것을 바꿔 끼운다. 새 편집 · 되돌리기 · 다시 실행(`commitOps` · `undo` · `redo`) · 페이지 옮김(`clearPage`)이 치운다. `setInfoNotice(message, { survivesLeave: true })` 한 줄만 다음 `clearPage` 한 번을 넘긴다(연쇄 삭제가 열린 페이지까지 지워 이어 판이 비워지는 판).
- **높이를 안 늘린다.** 실브라우저(창 800×500): 까닭이 다른 거절 봉투 셋을 이어 붙여도 `.wb-shell-info-notice` 가 1개, 하단 바 높이 `[92, 92, 108]`(빈 바 40 · 한 문장이 두 줄이 되는 정도) — 최대 − 최소 ≤ 24. 실패 통지(루트를 고른 Ctrl+D) 한 줄과 함께 서도 하단 바 128 · 셸 넘침 0. 그 뒤 거절 까닭을 80자에서 자르게 했다(`shorten`).
- 같은 종류로 옮긴 것: 붙이며 뺀 동작 수(L-047) · 뺀 상태 가지 · 여럿 고른 판의 순서 · 계층 · 화살표 키(`MULTI_KEY_NOTICE`, 앞서 실패 자리) · F2 · 기본 가지의 Delete · Cut · 숨어 빠진 선택 · 연쇄 삭제 뒤 안전망 스냅샷.

## 장부 열에 넣을 문장(코드를 안 바꾼 정보 항목)

- **L-060** — «기다리는 사이 선 잃음 통지(`되돌리기 이력이 초기화됐습니다`)가 붙인 뒤에도 남는 것은 설계서의 규칙(붙이기가 기다린 뒤 선 잃음을 치우지도 덮지도 않는다)이다. 그 문장은 붙이기 앞의 되돌리기 이력 이야기이고 붙인 것을 되돌릴 수 없다는 뜻이 아니다 — 문장을 바꾸는 것은 «붙인 것도 못 되돌린다고 읽히는가» 의 사용자 판정이 필요해 코드를 안 바꿨다(이 트랙이 그 읽힘을 재지는 않았다 — 값은 `editor-shortcuts-review-2.test.ts` R4 의 V2 · V4b).»
- **L-068** — «(1) 임시 뿌리 id `wb-clipboard-wrapper` 를 든 노드를 붙이면 이제 `rejected` 이고 까닭은 `id가 중복됩니다: wb-clipboard-wrapper` 로 하단 바에 선다(L-048 의 길 — 잰 값: `inspectNodesEnvelope` 의 `{"kind":"rejected","reason":"id가 중복됩니다: wb-clipboard-wrapper"}`). 까닭 문장이 «중복» 이라 읽는 사람에게는 이상하다 — 머리말의 대가 그대로. (2) 페이지 대상이 든 봉투는 붙일 때마다 `getTree` 를 한 번 읽는다 — 코드 안 바꿈. (3) 다른 테마에 없는 `variant` 가 든 봉투는 `ok` 로 읽혀 말없이 붙는다(잰 값: `variant: 'no-such-variant-in-this-theme'` 의 Button → `{"kind":"ok"}`) — lint `theme-variant` 가 말하고 화면은 안 말한다.»
- **L-132** — «별칭 문자 집합이 보지 않는 것 — U+3164(한글 채움) · U+2061(보이지 않는 연산자) · ZWJ 로 이은 이모지는 `isBlankAlias` 거짓 · `hasRejectedAliasChar` 거짓 · `tidyAlias` 가 그대로 돌려준다(잰 값: 세 글자 모두 `isBlank=false`, `rejected=false`, tidy 가 같은 글자). 라벨 · 제목은 이 표를 안 거친다.»
