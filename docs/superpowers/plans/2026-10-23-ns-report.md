## 설계 요약 — 결정과 이유

| 결정 | 이유 |
| --- | --- |
| **저장 꼴 (나)** — 몸통은 `children` 그대로, 이름 붙은 구역은 `zones: { <이름>: WbNode[] }` | (가) 자식의 `zone` 칸은 노드가 제 부모 사정을 들어 붙여넣기 · 모듈 · 들여쓰기마다 고쳐야 하고 구역 사이 옮김이 연산 둘이다. (나′) 전부 `zones` 는 `/children` 에 기대는 케이스 191 파일 · 976 줄을 다시 쓴다. (다) 구역 노드는 경로 · 잠금이 공짜지만 노드를 세는 모든 자리가 «구역 노드는 노드가 아니다» 를 지켜야 하고 MCP 가 카드마다 구역 노드 넷을 지어야 한다 |
| **자식 줄 읽기를 한 함수(`childLists`)로** | 지금 `node.children` 을 손으로 도는 자리가 열 남짓이다(`selectionConflicts` · api `sameStructure` · `walkSafely` · `nodesOnly` · 테마 lint · `visibleTree` · 복사 둘 · 렌더러 · `page-view` 깊이). 하나라도 구역을 빼먹으면 그 안 노드가 잠금을 지나거나 `structure_seq` 가 안 오른다 |
| **순회 차례 = 카탈로그의 구역 선언 차례** | `jsonb` 가 열쇠 차례를 안 지킨다 |
| **카탈로그: `children: 'none'\|'many'` → `zones: ZoneDef[]`** (+ `placement` · `bodyHost`) | 트리 · 놓기 · 렌더러가 «몸통 + 구역» 을 한 목록으로 돈다. 받는 타입 제약은 `Tabs`↔`TabPanel` 하나뿐 |
| **구역:** `Card` 제목 옆 · 머리 오른쪽 · 몸통 · 바닥 / `SearchForm` 조건 · 단추([초기화][검색]) / `EntryForm` 항목 · 단추([저장][취소]) / `List` 머리 왼쪽 · 오른쪽 / `Tabs` 몸통(`TabPanel` 만) | 로드맵 표 1 행의 자리. 접기 줄은 뷰 몫. 검색폼 머리 구역은 안 둔다 — 구역을 더하는 것은 판을 안 올려 뒤로 미뤄도 값이 없다 |
| **탭 = 새 컴포넌트 `TabPanel`**(탭 이름은 패널의 `label` · `switchTab` 은 패널 id 를 가리킨다) | 두 배열을 번호로 짝 짓지 않는다. 탭마다 상태 보임 · 표지 · 상호작용이 노드 그대로 선다. 패널의 뿌리 요소가 탭 머리라 캔버스에서 탭을 누르면 그 패널이 골라진다 |
| **결과 머리줄 = `List` 의 머리 구역** | 그리드에 붙어 함께 움직인다. 떨어진 줄은 지금도 `Flex` 다 |
| **`Section` 에 제목줄 안 단다** | Q4 — 소제목 + 오른쪽 단추는 `Card` 테두리 없는 변형 추천 |
| **뷰 계약: `ViewProps.zones` · `items` 를 더하고 SDK `<Zone>` 이 `data-wb-zone` 을 편다** | 빼는 것이 없다. 에디터는 뷰마다 다른 `data-wb-part` 대신 `data-wb-zone` 으로 구역 상자를 찾는다. `wb-theme check` 가 «내용이 든 구역을 안 그린 뷰» 를 오류로 잰다 |
| **식별자 `zones`** — 끌기 층의 «띠»(`DropZone`)를 `DropBand` 로 바꾼다 | `slot` 은 레이아웃 `Slot` · `ViewProps.slot` · `anchored-ops` 의 `kind: 'slot'` 과, `region` 은 끌기 층 `RegionsContext` 와 겹친다 |

## 사용자에게 물을 것

설계 문서 «사용자에게 물을 것» 절에 선택지 표가 있다. 요약:

1. **Q1 판 2 문서** — (가) 판 3 + 작은 옮기기 한 단계(탭 → 패널 · 폼에 기본 단추, 크기 S) **추천** / (나) 판 2 거절(로컬 DB 를 비워야 한다 — 사용자의 설계서가 든 볼륨). 공통 브리프의 «옮기기 마이그레이션을 짓지 않는다» 와 갈리는 추천이라 물었다.
2. **Q2 빈 구역의 캔버스 표시** — (가) 끄는 동안만 점선 칸 **추천**(끌지 않을 때 캔버스 = 내보낸 화면) / (나) 편집 중 늘 / (다) 트리로만.
3. **Q3 고른 노드가 지금 탭이 아닌 패널 · 접힌 검색폼 안에 있으면** — (가) 캔버스만 펼쳐 보인다(문서 안 바꿈) **추천** / (나) 사람이 `active` · `collapsed` 를 바꾼다.
4. **Q4 «소제목 + 오른쪽 단추» 줄** — (가) `Card` 테두리 없는 변형 **추천** / (나) `Section` 제목줄 / (다) 새 «머리줄» 컴포넌트. 설계서를 저장소에서 못 봐 로드맵 문구로만 판단했다.

## 구현 나누기

- **A 모델 — 원자적 한 브랜치(L ~ XL).** schema(봉투 · `childLists` · 순회 · 잠금 손 순회 · 복사 · 검증 셋 · 카탈로그 · `TabPanel` · `switchTab` · 판 3) · renderer/theme-sdk(`zones` · `items` · `<Zone>` · 기본 뷰 여섯) · system-admin CSS · 갤러리 · kit check · api `sameStructure` · web 의 순회 · 편집 연산 · 리베이스 · 기본 내용 · 트리 구역 줄(보이기만) · exporter · CLI · `/llms.txt`. 나누지 않는 까닭: 봉투가 `zones` 를 받는 순간 순회 하나라도 빠지면 구역 안 노드가 잠금을 지난다 · 뷰의 단추를 걷는 것과 기본 단추를 넣는 것이 한 몸이다.

## 지침

- **무엇이 비었나:** 노드의 자식을 손으로 도는 자리가 패키지마다 따로 있고(«설계 요약» 의 열 남짓), 그것을 한 벌로 지키는 규칙 · 케이스가 없다. 구역처럼 자식 자리를 넓히는 변경은 한 자리를 빼먹으면 잠금이 뚫린다.
- **어느 문서 어느 절:** 2부가 `childLists` 를 세우면 정본 `docs/superpowers/specs/2026-08-03-wirebound-design.md` 「페이지 스키마 노드」 절(구현 차수가 고친다)과, 그 함수의 머리말.
- **넣을 문장(정본 「페이지 스키마 노드」):** «노드의 자식 줄(몸통 `children` · 구역 `zones`)은 `packages/schema` 의 `childLists` 하나로 읽는다 — 잠금 판정 · 구조 번호 · 순회 · 복사 · 렌더러 · 내보내기가 그 함수를 부르고, `node.children` · `node.zones` 를 직접 읽는 자리는 케이스가 센다(빠진 자리의 구역 안 노드는 잠금을 지난다).»
- 지금 `.ruler/*` 에 넣을 문장은 없다 — 위 규칙은 2부가 함수를 세운 뒤에 참이 된다.
