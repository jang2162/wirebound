설계: `docs/superpowers/specs/2026-10-25-form-table-design.md`(1부 보고 `2026-10-25-ft-report.md`). 물음 Q1 ~ Q4 는 모두 (가)로 정해졌다(사용자 답 · 2026-10-25). 기준 main `8769757a` · 브랜치 `feat/form-table` · node v24.21.0 · 자기 DB 5501 · api 3101.

## 1. 몫 변수 상속 — 재현 안 됨

설계 «7» «몫 변수» 가 CSS 규칙으로 읽은 결함(몫 2 필드의 값 칸 조각이 `--wb-node-weight` 를 물려받아 늘어난다)은 **지금 소스에서 서지 않는다.** 고치지 않았다(`@property` 를 안 더했다).

| 판 | 몫 2 필드 칸 | 몫 없는 필드 칸 | 몫 2 필드 안 `Input{size: short}` | 몫 없는 필드 안 같은 조각 |
| --- | --- | --- | --- | --- |
| 지금 소스(system-admin · 번들 · 문서 폭 1280 · 열을 정한 검색폼 `columns: 3`) | 825.33 | 404.66 | **84** | 84 |
| 변조 M0 — 번들 `views.css` 에서 `--wb-node-weight: initial` 규칙(1개)을 걷음 | 825.33 | 404.66 | **825.33** | 84 |

원인: SDK 기본 CSS `structureCssBlocks` 의 ① `:where([data-wb-id]) { --wb-node-weight: initial; }` 가 모든 노드 뿌리에서 변수를 초기화한다(`packages/theme-sdk/src/default-views/structure.tsx` — `5b49444a` 부터 있었다). 값 칸 조각은 노드라 제 뿌리에서 끊기고, 몫이 있는 노드만 인라인으로 싣는다. 설계가 본 «`@property` 등록이 없다» 는 맞지만 그 자리를 이 규칙이 메운다.

남는 길: **노드가 아닌 요소**(`data-wb-id` 가 없다)는 이 규칙에 안 걸려 부모 노드의 몫을 물려받는다 — 폼 표의 빈 쌍(`filler`)이 그렇다. 몫을 준 폼 표(예: `Flex` 안 몫 2) 안의 빈 쌍이 `span calc(2 * var(--wb-node-weight, 1))` 로 4 트랙을 덮는다. 빈 쌍 규칙은 몫 변수를 안 읽고 `span 2` 로 둔다(«4»).

잠금: `apps/web/build-test/searchform-columns.test.ts` «몫을 준 필드 안의 조각은 그 몫을 물려받지 않는다» — 고치기 전에도 초록(고칠 것이 없다), M0 에 혼자 죽는다(`expected 741.33 to be less than or equal to 1` · 1 실패 · 2 건너뜀).

## 3. 결정과 이유

| 결정 | 이유 |
| --- | --- |
| SDK 기본 CSS 에 쌍 격자의 좁은 창 판(`@media (max-width: 640px)` · 특이도 0)을 둔다 — SDK 기본 CSS 의 첫 `@media` | 테마가 안 꾸민 판(스타터 테마 첫 모습 · kit fixture)에서 390 폭의 2열 폼 표가 라벨 칸 8rem 둘로 값 칸을 글자 몇 자로 눌러 한 줄 조각이 3줄로 꺾이고 날짜 칸이 넘쳤다(`shots` fixture 판 «문제 15 건» — 넘침 4 · 꺾임 5 …). 설계 «좁은 창은 테마의 몫» 은 그대로다 — 특이도 0 이라 쌍 격자를 꾸민 테마의 규칙이 늘 이긴다. 문턱은 기본테마와 같다 |
| subgrid `Field` 에 `align-items` 를 안 건다(격자 기본 `stretch`) | 설계 스케치의 `center` 면 라벨 칸이 제 글 높이로 줄어 키 큰 줄에서 라벨 바탕 · 칸 선이 끊긴다(`shots` 의 새 `pairs` 가 잡는 꼴) |
| 빈 쌍은 몫 변수를 안 읽고 `span 2` | «1» 의 남는 길 — 빈 쌍은 노드가 아니라 몫 초기화에 안 걸린다 |
| 템플릿이 옮기는 `input.tsx` 에서 CSS 상수(`zeroRule` 을 쓰는)를 `inputCssBlocks` 안으로 | `templateView` 는 `*CssBlocks` 함수 앞까지를 옮기고 SDK 가 안 내보내는 이름(`zeroRule`)을 쓰면 던진다 |
| 갤러리 «2열 · 전폭 · 빈 쌍» 의 긴 값은 `Input` 의 값이 아니라 `Text` | 한 줄 조각에 끊을 자리 없는 낱말을 실으면 SDK 기본 CSS 판에서 조각 밖으로 넘친다(그 꼴은 폼 표가 아니라 조각의 몫이다). 정보표의 긴 값은 `Text` 가 `overflow-wrap: anywhere` 로 칸 안에서 꺾는다 |
