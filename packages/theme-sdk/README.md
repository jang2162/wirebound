# @wirebound/theme-sdk

wirebound 테마의 **뷰 계약**이다 — `view` · `Root` · `Focus` · `useToken` 과, 테마가 덮지 않은 컴포넌트를 그리는 SDK 기본 뷰. 이 패키지의 판(`version`)은 테마 계약의 판이다.

## 설치

```bash
npm install @wirebound/theme-sdk react
```

테마를 짓는 도구는 [`@wirebound/theme-kit`](https://github.com/jang2162/wirebound/tree/main/packages/theme-kit)(`wb-theme`)다.
