# @wirebound/renderer

wirebound 설계서(스키마)를 React 로 그린다 — 노드마다 «테마 뷰 → SDK 기본 뷰» 차례로 뷰를 고른다.

## 설치

```bash
npm install @wirebound/renderer react
```

뷰 계약은 [`@wirebound/theme-sdk`](https://github.com/jang2162/wirebound/tree/main/packages/theme-sdk) 다.
