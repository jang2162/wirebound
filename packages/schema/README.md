# @wirebound/schema

wirebound 설계서의 **단일 진실** — 노드 타입 · 컴포넌트 카탈로그 · 검증 · JSON Patch. 런타임 의존은 zod 하나이고 브라우저와 Node 양쪽에서 돈다.

## 설치

```bash
npm install @wirebound/schema
```

[`@wirebound/cli`](https://github.com/jang2162/wirebound/tree/main/packages/cli) · [`@wirebound/mcp`](https://github.com/jang2162/wirebound/tree/main/packages/mcp) 가 이것에 기댄다. 노드 · 카탈로그 규격은 저장소의 [설계 문서](https://github.com/jang2162/wirebound/blob/main/docs/superpowers/specs/2026-08-03-wirebound-design.md) 가 소유한다.
