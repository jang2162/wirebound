# @wirebound/theme-gallery

wirebound 컴포넌트 카탈로그 × variant 표본 갤러리와 이어진 예제 페이지다. `wb-theme dev` 와 wirebound 에디터의 테마 미리보기가 이것을 그린다 — 테마 작성자는 보통 직접 깔지 않고 [`@wirebound/theme-kit`](https://github.com/jang2162/wirebound/tree/main/packages/theme-kit) 를 쓴다.

## 설치

```bash
npm install @wirebound/theme-gallery react
```
