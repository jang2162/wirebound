# base 바꿈 — wirebound

## 코드 변경 작업은 항상 워크트리에서 한다

바꾸는 절: `base/01-git.md` 「코드 변경 작업의 기본값은 워크트리다」

**코드 변경 작업은 항상 워크트리에서 한다. 병렬 작업이든 단일 작업이든 예외 없다.** 최상위 체크아웃(워크트리가 아닌 원본 디렉터리)은 혼자 쓰는 작업 공간이 아니라 **공유 자원**이다 — IntelliJ, 실행 중인 `pnpm --filter @wirebound/api dev`, vitest watch, 다른 에이전트 세션이 동시에 그 디렉터리를 보고 있다.

- **Why:** 최상위를 보는 IntelliJ·dev 서버·vitest watch·다른 세션은 사람이 켜 둔 것이라 «동시 작업이 없어 보이는» 때에도 남아 있다. 「바로 구현할 수 있는 작업」 을 가르는 판단 자체가 이탈 경로라 이 저장소는 그 갈래를 두지 않는다.
- **How to apply:** 최상위에서 직접 하는 것은 읽기 · 워크트리 관리 · 메인 세션 몫의 문서 갱신(`.ruler/*`·`docs/superpowers/plans/*`)뿐이다. `git stash` 로 옮기지 않는다 — 스택은 모든 워크트리가 함께 쓴다.
